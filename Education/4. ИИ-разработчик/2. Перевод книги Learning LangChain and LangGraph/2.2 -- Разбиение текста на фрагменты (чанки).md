## Разбиение текста на фрагменты

На первый взгляд может показаться простым разбить большой объем текста на фрагменты, но **сохранение семантически связанных (связанных по смыслу) фрагментов текста вместе — это сложный процесс**. 

Чтобы упростить разбиение больших документов на маленькие, но все еще осмысленные куски текста, **LangChain предоставляет** `RecursiveCharacterTextSplitter`, который делает следующее:

1. Берет список разделителей в порядке важности. По умолчанию это:  
    a. Разделитель абзацев: \n\n  
    b. Разделитель строк: \n  
    c. Разделитель слов: пробел
    
2. Чтобы соблюсти заданный размер фрагмента, например, 1000 символов, начинает с разбиения по абзацам.
    
3. Для любого абзаца длиннее желаемого размера фрагмента, разбивает по следующему разделителю: строкам. Продолжает, пока все фрагменты не станут меньше желаемой длины или не останется дополнительных разделителей для попытки.
    
4. Выдает каждый фрагмент как Document с метаданными исходного документа и дополнительной информацией о позиции в исходном документе.
    

Давайте посмотрим на пример:

**Python**
```python
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.document_loaders import TextLoader

loader = TextLoader("./test.txt")  # или любой другой загрузчик

docs = loader.load()

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200,
)
splitted_docs = splitter.split_documents(docs)
```

В предыдущем коде документы, созданные загрузчиком документов, разбиваются на фрагменты по 1000 символов каждый, с некоторым перекрытием между фрагментами в 200 символов для сохранения некоторого контекста. 

*Результат также является списком документов, где каждый документ имеет длину до 1000 символов*, разбитых по естественным делениям письменного текста — абзацам, новым строкам и, наконец, словам. Это использует структуру текста для сохранения каждого фрагмента как согласованного, читаемого фрагмента текста.

`RecursiveCharacterTextSplitter` также может использоваться для разбиения языков программирования и Markdown на семантические фрагменты. 
Это делается с использованием ключевых слов, специфичных для каждого языка, в качестве разделителей, что гарантирует, например, что тело каждой функции сохраняется в одном фрагменте, вместо того чтобы быть разбитым между несколькими. 

Обычно, поскольку языки программирования имеют больше структуры, чем письменный текст, меньше необходимости в использовании перекрытия между фрагментами. 

> LangChain содержит разделители для ряда популярных языков, таких как Python, JS, Markdown, HTML и многих других. 

Вот пример:
**Python**
```python
from langchain_text_splitters import (
    Language,
    RecursiveCharacterTextSplitter,
)
PYTHON_CODE = """
def hello_world():
    print("Hello, World!")
# Call the function
hello_world()
"""
python_splitter = RecursiveCharacterTextSplitter.from_language(
    language=Language.PYTHON,
    chunk_size=50,
    chunk_overlap=0,
)
python_docs = python_splitter.create_documents([PYTHON_CODE])
```

**Вывод:**
```text
[Document(page_content='def hello_world():\n    print("Hello, World!")'), 
 Document(page_content='# Call the function\nhello_world()')]
```

Обратите внимание, как мы все еще используем `RecursiveCharacterTextSplitter`, как и раньше, но теперь мы создаем его экземпляр для конкретного языка, используя метод from_language. Он принимает имя языка и обычные параметры для размера фрагмента и т.д. 

Также обратите внимание, что теперь мы используем метод `create_documents`, который принимает список строк, а не список документов, как у нас было раньше.
Этот метод полезен, когда текст, который вы хотите разбить, не поступает от загрузчика документов, поэтому у вас есть только сырые текстовые строки.

Вы также можете использовать необязательный второй аргумент для create_documents, чтобы передать список метаданных для связывания с каждой текстовой строкой. Этот список метаданных должен иметь ту же длину, что и список строк, и будет использоваться для заполнения поля metadata каждого возвращаемого Document.

Давайте посмотрим на пример для текста в Markdown, также используя аргумент metadata:
**Python**
```python
markdown_text = """
# LangChain
⚡ Building applications with LLMs through composability ⚡
## Quick Install
```bash
pip install langchain

As an open source project in a rapidly developing field, we are extremely open to contributions.  
"""

md_splitter = RecursiveCharacterTextSplitter.from_language(  
	language=Language.MARKDOWN,  
	chunk_size=60,  
	chunk_overlap=0,  
)

md_docs = md_splitter.create_documents(  
	[markdown_text],  
	[{"source": "[https://www.langchain.com](https://www.langchain.com/)"}]  
)
```

**Вывод:**
```text
[Document(page_content='# LangChain', metadata={"source": "[https://www.langchain.com](https://www.langchain.com/)"}),  
Document(page_content='⚡ Building applications with LLMs through composability ⚡', metadata={"source": "[https://www.langchain.com](https://www.langchain.com/)"}),  
Document(page_content='## Quick Install\n\n`bash', metadata={"source": "https://www.langchain.com"}), Document(page_content='pip install langchain', metadata={"source": "https://www.langchain.com"}), Document(page_content='`', metadata={"source": "[https://www.langchain.com](https://www.langchain.com/)"}),  
Document(page_content='As an open source project in a rapidly developing field, we', metadata={"source": "[https://www.langchain.com](https://www.langchain.com/)"}),  
Document(page_content='are extremely open to contributions.', metadata={"source": "[https://www.langchain.com](https://www.langchain.com/)"})]
```

Обратите внимание на две вещи:
- Текст разбивается по естественным точкам остановки в Markdown-документе; например, заголовок попадает в один фрагмент, строка текста под ним — в отдельный фрагмент, и так далее.
- Метаданные, которые мы передали во втором аргументе, прикрепляются к каждому результирующему документу, что позволяет вам отслеживать, например, откуда взялся документ и где вы можете посмотреть оригинал.
