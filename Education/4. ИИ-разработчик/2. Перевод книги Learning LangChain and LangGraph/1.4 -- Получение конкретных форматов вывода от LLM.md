Вывод в виде простого текста полезен, но могут быть случаи использования, **когда вам нужно, чтобы LLM генерировала структурированный вывод** — то есть **вывод** в машиночитаемом формате, таком как **JSON, XML, CSV или даже на языке программирования**, таком как Python или JavaScript. 

Это очень полезно, когда вы намерены передать этот вывод другому фрагменту кода, делая LLM частью вашего более крупного приложения.

## Вывод в формате JSON

Наиболее распространенный формат для генерации с помощью LLM — это JSON. JSON-вывод может (например) передаваться по сети в ваш фронтенд-код или сохраняться в базу данных.

При генерации JSON первая задача — определить схему, которой должна следовать LLM при создании вывода. Затем вы должны включить эту схему в запрос вместе с текстом, который вы хотите использовать в качестве источника. Давайте посмотрим на пример:

**Python**
```python
from langchain_openai import ChatOpenAI
from langchain_core.pydantic_v1 import BaseModel

class AnswerWithJustification(BaseModel):
    '''Ответ на вопрос пользователя вместе с обоснованием ответа.'''
    answer: str  # Ответ на вопрос пользователя
    justification: str  # Обоснование ответа
    
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

structured_llm = llm.with_structured_output(
	AnswerWithJustification
)

structured_llm.invoke(
	"What weighs more, a pound of bricks or a pound of feathers?")
```

**Вывод:**
```json
{
  "answer": "They weigh the same",
  "justification": "Both a pound of bricks and a pound of feathers weigh exactly one pound. The weight is the same, but the volume differs."
}
```

Итак, сначала определите схему. В Python это проще всего сделать с помощью Pydantic (библиотеки, используемой для валидации данных на соответствие схемам). 

**Метод `with_structured_output` будет использовать эту схему для двух целей:**
1. **Схема будет преобразована в объект JSONSchema** (JSON-формат, используемый для описания формы `[типов, имен, описаний] JSON-данных`), **который будет отправлен в LLM.** 
   Для каждой LLM LangChain выбирает наилучший способ сделать это, обычно через вызов функций или создание запроса.
    
2. Схема также будет использоваться для валидации вывода, возвращенного LLM, перед его возвратом; это гарантирует, что созданный вывод точно соответствует переданной вами схеме.

## Другие машиночитаемые форматы с парсерами вывода

Вы также можете использовать LLM или чат-модель для создания вывода в других форматах, таких как CSV или XML. Именно здесь парсеры вывода становятся полезными. Парсеры вывода — это классы, которые помогают структурировать ответы больших языковых моделей. Они выполняют две функции:

**Предоставление инструкций по форматированию**  
Парсеры вывода могут использоваться для добавления дополнительных инструкций в запрос, которые помогут направить LLM на вывод текста в формате, который она умеет парсить.

**Валидация и парсинг вывода**  
Основная функция — взять текстовый вывод LLM или чат-модели и преобразовать его в более структурированный формат, такой как список, XML или другой формат. Это может включать удаление посторонней информации, исправление неполного вывода и валидацию распарсенных значений.

Вот пример того, как работает парсер вывода:

**Python**

```python
from langchain_core.output_parsers import 
CommaSeparatedListOutputParser

parser = CommaSeparatedListOutputParser()

items = parser.invoke("apple, banana, cherry")
```

**Вывод:**
```text
['apple', 'banana', 'cherry']
```

**LangChain предоставляет множество парсеров ВЫВОДА** для различных случаев использования, включая CSV, XML и другие. Мы увидим, как комбинировать парсеры вывода с моделями и запросами в следующем разделе.
