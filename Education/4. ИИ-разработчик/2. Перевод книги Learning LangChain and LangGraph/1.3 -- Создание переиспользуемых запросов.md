В предыдущем разделе было показано, как инструкция в запросе значительно влияет на вывод модели. Запросы помогают модели понять контекст и генерировать релевантные ответы на вопросы.

Вот пример детализированного запроса:

> Ответь на вопрос на основе приведенного ниже контекста. Если на вопрос нельзя ответить, используя предоставленную информацию, ответь "Я не знаю".
> 
> Контекст: Наиболее значимые достижения в области NLP в последнее время связаны с большими языковыми моделями (LLM). Эти модели превосходят свои меньшие аналоги и стали бесценными для разработчиков, создающих приложения с NLP-возможностями. Разработчики могут получить доступ к этим моделям через библиотеку `transformers` от Hugging Face, или используя предложения OpenAI и Cohere через библиотеки `openai` и `cohere` соответственно.
> 
> Вопрос: Какие поставщики моделей предлагают LLM?
> 
> Ответ:

Хотя запрос выглядит как простая строка, сложность заключается в определении того, что должен содержать текст и как он должен варьироваться в зависимости от ввода пользователя. В этом примере значения Context и Question жестко закодированы, но что, если мы хотим передавать их динамически?

К счастью, LangChain предоставляет интерфейсы шаблонов запросов, которые упрощают создание запросов с динамическими вводными данными:

**Python**
```python
from langchain_core.prompts import PromptTemplate
template = PromptTemplate.from_template(
    """Answer the question based on the context below. If the question cannot be answered using the information provided, answer with "I don't know".
Context: {context}
Question: {question}
Answer: """
)

template.invoke({
    "context": """The most recent advancements in NLP are being driven by Large Language Models (LLMs). These models outperform their smaller counterparts and have become invaluable for developers creating applications with NLP capabilities. Developers can tap into these models through Hugging Face's `transformers` library, or by utilizing OpenAI and Cohere's offerings through the `openai` and `cohere` libraries, respectively.""",
    "question": "Which model providers offer LLMs?"
})

```

**Вывод:**
```text
StringPromptValue(
	text='Answer the question based on the context below. If the question cannot be answered using the information provided, answer with "I don\'t know".\n\nContext: The most recent advancements in NLP are being driven by Large Language Models (LLMs). These models outperform their smaller counterparts and have become invaluable for developers creating applications with NLP capabilities. Developers can tap into these models through Hugging Face\'s `transformers` library, or by utilizing OpenAI and Cohere\'s offerings through the `openai` and `cohere` libraries, respectively.
	\n\nQuestion: Which model providers offer LLMs?\n\nAnswer: ')
```

Этот пример берет **статический запрос из предыдущего блока и делает его динамическим.** Шаблон содержит структуру итогового запроса вместе с определением того, куда будут вставлены динамические вводные данные.

Таким образом, шаблон можно использовать как рецепт для создания множества статических, конкретных запросов. Когда вы форматируете запрос с некоторыми конкретными значениями — в данном случае `context` и `question` — вы получаете статический запрос, готовый для передачи в LLM.

Как видите, аргумент `question` передается динамически через функцию `invoke`. По умолчанию запросы LangChain следуют синтаксису f-строк Python для определения динамических параметров — любое слово, заключенное в фигурные скобки, например `{question}`, является заполнителем для значений, передаваемых во время выполнения. В предыдущем примере `{question}` был заменен на "Which model providers offer LLMs?".

Давайте посмотрим, как мы передадим это в модель OpenAI LLM с использованием LangChain:

**Python**
```python
from langchain_openai.llms import OpenAI
from langchain_core.prompts import PromptTemplate
# и `template`, и `model` могут быть переиспользованы множество раз

template = PromptTemplate.from_template(
    """Answer the question based on the context below. If the question cannot be answered using the information provided, answer with "I don't know".
Context: {context}
Question: {question}
Answer: """
)

model = OpenAI()
# `prompt` и `completion` — это результаты использования шаблона и модели

prompt = template.invoke({
    "context": """The most recent advancements in NLP are being driven by Large Language Models (LLMs). These models outperform their smaller counterparts and have become invaluable for developers creating applications with NLP capabilities. Developers can tap into these models through Hugging Face's `transformers` library, or by utilizing OpenAI and Cohere's offerings through the `openai` and `cohere` libraries, respectively.""",
    "question": "Which model providers offer LLMs?"
})

completion = model.invoke(prompt)
```

**Вывод:**
```text
Hugging Face's `transformers` library, OpenAI using the `openai` library, and Cohere using the `cohere` library offer LLMs.
```

Если вы хотите создать чат-приложение на основе ИИ, вместо этого можно использовать ChatPromptTemplate для предоставления динамических вводных данных на основе роли чат-сообщения:

**Python**
```python
from langchain_core.prompts import ChatPromptTemplate

template = ChatPromptTemplate.from_messages([
    ('system', '''Answer the question based on the context below. If the question cannot be answered using the information provided, answer with "I don't know".'''),
    ('human', 'Context: {context}'),
    ('human', 'Question: {question}'),
])

template.invoke({
    "context": """The most recent advancements in NLP are being driven by Large Language Models (LLMs). These models outperform their smaller counterparts and have become invaluable for developers creating applications with NLP capabilities. Developers can tap into these models through Hugging Face's `transformers` library, or by utilizing OpenAI and Cohere's offerings through the `openai` and `cohere` libraries, respectively.""",
    "question": "Which model providers offer LLMs?"
})
```

**Вывод:**
```text
ChatPromptValue(
	messages=[SystemMessage(content='Answer the question based on the context below. If the question cannot be answered using the information provided, answer with "I don\'t know".'), HumanMessage(content='Context: The most recent advancements in NLP are being driven by Large Language Models (LLMs). These models outperform their smaller counterparts and have become invaluable for developers creating applications with NLP capabilities. Developers can tap into these models through Hugging Face\'s `transformers` library, or by utilizing OpenAI and Cohere\'s offerings through the `openai` and `cohere` libraries, respectively.'),

HumanMessage(
	content='Question: Which model providers offer LLMs?')])
```

Обратите внимание, что запрос содержит инструкции в SystemMessage и два экземпляра HumanMessage, которые содержат динамические переменные `context` и `question`. Вы все равно можете отформатировать шаблон тем же способом и получить статический запрос, который можно передать в LLM для получения предсказания:

**Python**
```python
from langchain_openai.chat_models import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
# и `template`, и `model` могут быть переиспользованы множество раз

template = ChatPromptTemplate.from_messages([
    ('system', '''Answer the question based on the context below. If the question cannot be answered using the information provided, answer with "I don't know".'''),
    ('human', 'Context: {context}'),
    ('human', 'Question: {question}'),
])

model = ChatOpenAI()
# `prompt` и `completion` — это результаты использования шаблона и модели

prompt = template.invoke({
    "context": """The most recent advancements in NLP are being driven by Large Language Models (LLMs). These models outperform their smaller counterparts and have become invaluable for developers creating applications with NLP capabilities. Developers can tap into these models through Hugging Face's `transformers` library, or by utilizing OpenAI and Cohere's offerings through the `openai` and `cohere` libraries, respectively.""",
    "question": "Which model providers offer LLMs?"
})

model.invoke(prompt)
```

**Вывод:**
```text
AIMessage(
	content="Hugging Face's `transformers` library, OpenAI using the `openai` library, and Cohere using the `cohere` library offer LLMs.")
```
