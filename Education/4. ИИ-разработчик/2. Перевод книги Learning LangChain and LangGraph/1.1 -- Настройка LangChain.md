Чтобы следовать за остальной частью главы и последующими главами, мы рекомендуем сначала установить LangChain на ваш компьютер.

См. инструкции в Предисловии относительно настройки учетной записи OpenAI и выполните их, если вы еще этого не сделали. Если вы предпочитаете использовать другого поставщика БЯМ, см. раздел «Почему LangChain?» для альтернатив.

Затем перейдите на страницу API Keys на веб-сайте OpenAI (после входа в свою учетную запись OpenAI), создайте API-ключ и сохраните его — он скоро вам понадобится.

> **ПРИМЕЧАНИЕ**  
> В этой книге мы будем показывать примеры кода как на Python, так и на JavaScript (JS). LangChain предлагает одинаковую функциональность на обоих языках, так что просто выберите тот, с которым вам наиболее комфортно, и следуйте соответствующим фрагментам кода на протяжении всей книги (примеры кода для каждого языка эквивалентны).

Сначала инструкции по настройке для читателей, использующих Python:

1. Убедитесь, что у вас **установлен Python**. См. инструкции для вашей операционной системы.
    
2. Установите Jupyter, если вы хотите запускать примеры в среде блокнота. Вы можете сделать это, выполнив `pip install notebook` в вашем терминале.
    
3. **Установите библиотеку LangChain**, выполнив следующие команды в вашем терминале:
```bash
pip install langchain langchain-openai langchain-community
pip install langchain-text-splitters langchain-postgres
```

4. Возьмите API-ключ OpenAI, который вы сгенерировали в начале этого раздела, и сделайте его доступным в вашем терминальном окружении. Вы можете сделать это, выполнив:
```bash
export OPENAI_API_KEY=your-key
```

5. Не забудьте заменить `your-key` на API-ключ, который вы сгенерировали ранее.
    
6. Откройте Jupyter notebook, выполнив эту команду:
```bash
jupyter notebook
```

Теперь вы готовы следовать примерам кода на Python.
