# 2.1. Зачем нужен Output Parser

LLM обычно возвращает текст:
```python
AIMessage(
    content="Java is a programming language..."
)
```

Для человека это нормально.

Но приложению часто нужны данные:
Например:
```python
UserDTO(
    name="Alex",
    age=25
)
```

или:
```json
{
    "name": "Alex",
    "age": 25
}
```

LLM не гарантирует правильный формат.

Поэтому используется Output Parser.

---
Схема:
```
LLM

 |
 v

AIMessage

 |
 v

Output Parser

 |
 v

Структурированные данные
```

---
# 2.2. StrOutputParser
Самый простой вариант.

Он превращает:
```python
AIMessage(
content="Hello world"
)
```
в:
```python
"Hello world"
```

Пример:
```python
from langchain_core.output_parsers import StrOutputParser

parser = StrOutputParser()

chain = prompt | model | parser
```

Теперь:
```python
response = chain.invoke(
{
    "question": "Что такое JVM?"
}
)
```

Результат:
```
JVM — это виртуальная машина Java...
```

Вместо:
```python
AIMessage(
content="..."
)
```
получаем:
```python
str
```

# 2.3. JsonOutputParser

Частый сценарий — получить JSON.

Например, создаём анализатор вакансий.

Нам нужен результат:
```json
{
    "technology": "Java",
    "experience": "Junior",
    "salary": 100000
}
```

---
Создаём prompt:
```python
from langchain_core.prompts import ChatPromptTemplate


prompt = ChatPromptTemplate.from_messages(
[
    (
        "system",
        """
Проанализируй вакансию.

Верни только JSON:
{
    "technology": "",
    "experience": "",
    "salary": ""
}
"""
    ),

    (
        "human",
        "{vacancy}"
    )
]
)
```

---

Создаём parser:
```python
from langchain_core.output_parsers import JsonOutputParser

parser = JsonOutputParser()
```

---
Создаем chain:
```python
chain = prompt | model | parser
```

---
Используем:

```python
result = chain.invoke(
{
    "vacancy":
    """
    Требуется Java Junior Developer.
    Зарплата 100000 рублей.
    """
}
)
```

Результат:
```json
{
    "technology": "Java",
    "experience": "Junior",
    "salary": "100000"
}
```

Теперь это обычный Python dict.

# 2.4. PydanticOutputParser

В коммерческих приложениях часто нужен объект определенного типа.

Например:
```python
class Vacancy(BaseModel):

    technology: str
    experience: str
    salary: int
```

Создаём parser:
```python
from langchain_core.output_parsers import PydanticOutputParser


parser = PydanticOutputParser(
    pydantic_object=Vacancy
)
```

Добавляем инструкции в prompt:
```python
prompt = ChatPromptTemplate.from_messages(
	[
		(
			"system",
			"""
			Ты анализируешь вакансии.
			
			{format}
			"""
		),
		
		(
			"human",
			"{text}"
		)
	]
)
```

Передаем формат:
```python
format_instruction = (
    parser.get_format_instructions()
)
```

Создаем chain:
```python
chain = (
    prompt
    | model
    | parser
)
```

Используем:
```python
result = chain.invoke(
	{
		"text":
			"""
				Ищем Java Junior.
				Опыт 1 год.
				Зарплата 120000.
			""",
		
		"format":
		format_instruction
	}
)
```

Результат:
```python
Vacancy(
    technology="Java",
    experience="Junior",
    salary=120000
)
```

# 2.5. Вывод в модель - `with_structured_output()`

## 2.5.1. Зачем нужен `with_structured_output()`
В большинстве backend-приложений результат работы LLM нужен не в виде обычного текста, а в виде структуры данных.

Например, есть задача:
> Проанализировать вакансию и вернуть информацию о позиции.

Обычный вызов модели:

```python
response = model.invoke(
"""
Проанализируй вакансию:

Требуется Junior Java Developer.
Технологии: Java, Spring Boot, PostgreSQL.
Зарплата: 120000 рублей.
"""
)
```

Вернет:
```python
AIMessage(
	content="""
	Это вакансия Java разработчика уровня Junior.
	Основные технологии: Java, Spring Boot, PostgreSQL.
	Зарплата составляет 120000 рублей.
	"""
)
```

Для человека это удобно, но приложению такой ответ неудобен.

Нам нужен объект:
```json
{
    "position": "Java Developer",
    "level": "Junior",
    "technologies": [
        "Java",
        "Spring Boot",
        "PostgreSQL"
    ],
    "salary": 120000
}
```

Именно эту задачу решает `with_structured_output()`.

---
## 2.5.2. Что делает `with_structured_output()`

`with_structured_output()` превращает обычную Chat Model в модель, которая возвращает данные заданного формата.

Было:
```python
model = ChatOpenAI()
```

Результат:
```python
AIMessage
```

СТАЛО:
```python
structured_model = model.with_structured_output(
    Schema
)
```

Результат:
```python
Schema
```

> **Важно**:
> `with_structured_output()` ***не является отдельным Parser-классом.***
> 
> **Это метод модели**, который создаёт новый Runnable с поддержкой структурированного ответа.

## 2.5.3. Использование с Pydantic моделью

Самый распространённый вариант в коммерческой разработке — описать ожидаемый результат через Pydantic-модель.

Например:
```python
from pydantic import BaseModel

class Vacancy(BaseModel):
    position: str
    level: str
    technologies: list[str]
    salary: int | None
```

Эта модель описывает, какой объект должна вернуть LLM.

Создаём Chat Model:
```python
from langchain_openai import ChatOpenAI


model = ChatOpenAI(
    model="gpt-4.1"
)
```

Включаем структурированный вывод:
```python
structured_model = model.with_structured_output(
    Vacancy
)
```

Теперь `structured_model` работает как обычный Runnable:
```python
result = structured_model.invoke(
    "Проанализируй вакансию Java Developer"
)
```

---
Например:
```python
result = structured_model.invoke(
"""
Вакансия:

Ищем Junior Java Developer.

Требования:
- Java
- Spring Boot
- PostgreSQL

Зарплата:
120000 рублей.
"""
)
```

Результат:
```python
Vacancy(
    position="Java Developer",
    level="Junior",
    technologies=[
        "Java",
        "Spring Boot",
        "PostgreSQL"
    ],
    salary=120000
)
```

Теперь это обычный Python-объект:
```python
print(result.position)

# Java Developer
```
