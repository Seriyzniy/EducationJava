## 1. Что такое Prompt Engineering

### 1.1. Понятие Prompt
Prompt — это инструкция и данные, которые отправляются языковой модели для получения ответа.

Самый простой вариант:
```python
response = model.invoke(
    "Что такое Kafka?"
)
```

Здесь весь prompt — это одна строка.

Проблема такого подхода в коммерческой разработке:
- сложно контролировать поведение модели;
- сложно менять инструкции;
- невозможно удобно переиспользовать запрос;
- сложно поддерживать разные сценарии работы.

Например, если создаётся AI-помощник банка, недостаточно передать:
```
Как оформить кредит?
```

Модель не знает:
- какую роль она выполняет;
- каким стилем отвечать;
- какие ограничения соблюдать;
- какую структуру ответа использовать.

Поэтому создаётся более сложный prompt:
```
System:
Ты являешься банковским консультантом.
Отвечай только по банковским продуктам.
Не придумывай информацию.

User:
Как оформить кредит?
```

---
## 1.2. Из чего состоит prompt в Chat Model

В современных LLM-приложениях prompt обычно состоит из сообщений с разными ролями:
```
SystemMessage
        |
        v
Правила работы модели


HumanMessage
        |
        v
Запрос пользователя
```

Например:
```
System:
Ты являешься экспертом по Java.
Отвечай с примерами кода.

Human:
Объясни принцип работы JVM.
```

В LangChain это представляется через сообщения:
```python
from langchain_core.messages import SystemMessage, HumanMessage

messages = [
    SystemMessage(
        "Ты являешься экспертом по Java. "
        "Отвечай с примерами кода."
    ),

    HumanMessage(
        "Объясни принцип работы JVM."
    )
]
```

И отправляется в модель:
```python
response = model.invoke(messages)
```

# 2. Prompt Templates

## 2.1. Зачем нужны Prompt Templates

В реальном приложении пользователь каждый раз отправляет разные данные.

Например:
Сегодня:
```
Объясни Kafka
```

Завтра:
```
Объясни Redis
```

Послезавтра:
```
Объясни PostgreSQL
```

Нет смысла создавать новый prompt каждый раз.

Вместо этого создаётся шаблон:
```
Ты являешься экспертом по backend-разработке.

Объясни тему:
{topic}
```
`{topic}` — переменная, которая будет заменена во время выполнения.

---

В LangChain Prompt Template — это отдельный Runnable-компонент.

Он:
1. Принимает входные параметры.
2. Подставляет их в шаблон.
3. Возвращает готовый prompt.

Схема:
```
Данные
{
 topic: "Kafka"
}
        |
        v

PromptTemplate
        |
        v
Готовый prompt
"Объясни Kafka"
```

# 3. Основные виды шаблонов

## 3.1. PromptTemplate (обычный текстовый шаблон)

Используется, когда работа идёт с обычной строкой.

Пример:
Создаём шаблон:
```python
from langchain_core.prompts import PromptTemplate

template = PromptTemplate(
    template="""
Ты являешься техническим экспертом.

Объясни следующую технологию:
{technology}

Ответ дай подробно, с примерами.
""",

    input_variables=[
        "technology"
    ]
)
```

Теперь используем шаблон:
```python
prompt = template.invoke(
    {
        "technology": "Kafka"
    }
)

print(prompt)
```

Получим:
```
Ты являешься техническим экспертом.

Объясни следующую технологию:
Kafka

Ответ дай подробно, с примерами.
```


Теперь этот prompt можно отправить в модель:
```python
from langchain_openai import ChatOpenAI

model = ChatOpenAI(
    model="gpt-4.1"
)

response = model.invoke(
    prompt
)

print(response.content)
```

Цепочка:
```
technology
    |
    v

PromptTemplate

    |
    v

ChatOpenAI

    |
    v

AIMessage
```

# 3.2. ChatPromptTemplate

В современных приложениях чаще используется именно он.

Причина:
Chat Model работает не со строкой, а с сообщениями:
```
System
Human
Assistant
```

Поэтому вместо одного текста создаётся шаблон сообщений.

---
Пример:
Создаём шаблон:
```python
from langchain_core.prompts import ChatPromptTemplate

template = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            """
Ты являешься экспертом по {technology}.

Твои правила:
- объясняй простым языком;
- используй примеры;
- не пропускай важные детали.
"""
        ),

        (
            "human",
            "{question}"
        )
    ]
)
```

Теперь передаем данные:

```python
prompt = template.invoke(
    {
        "technology": "Java",
        "question": "Что такое JVM?"
    }
)
```

LangChain создаст:
```
SystemMessage:

Ты являешься экспертом по Java.

Твои правила:
- объясняй простым языком;
- используй примеры.


HumanMessage:

Что такое JVM?
```

Теперь отправляем в модель:

```python
model = ChatOpenAI(
    model="gpt-4.1"
)

response = model.invoke(
    prompt
)

print(response.content)
```

Полная цепочка:

```
{
 technology:"Java",
 question:"Что такое JVM?"
}

        |
        v

ChatPromptTemplate

        |
        v
[
 SystemMessage,
 HumanMessage
]

        |
        v

ChatOpenAI

        |
        v

AIMessage
```

# 3.3. Few Shot Prompt Template

Иногда недостаточно просто дать инструкции.
Нужно **показать модели примеры правильного поведения**.

Это называется **few-shot prompting**.

Например, нужно определить настроение текста.

Плохой вариант:
```
Определи настроение:

"Товар отличный"
```
Модель сама выбирает формат ответа.

Лучше:
```
Пример 1:

Текст:
Товар ужасного качества

Ответ:
negative


Пример 2:

Текст:
Очень быстрая доставка

Ответ:
positive


Теперь обработай:

Текст:
Качество хорошее
```

Модель видит закономерность.


В LangChain:
```python
from langchain_core.prompts import FewShotPromptTemplate

examples = [
    {
        "text": "Товар отличный",
        "label": "positive"
    },

    {
        "text": "Очень плохое качество",
        "label": "negative"
    }
]
```

Создаем шаблон:
```python
prompt = FewShotPromptTemplate(
    examples=examples,

    example_prompt=PromptTemplate(
        template="""
Текст:
{text}

Ответ:
{label}
""",
        input_variables=[
            "text",
            "label"
        ]
    ),

    prefix="""
Определи настроение текста.
Используй только positive или negative.
""",

    suffix="""
Текст:
{input}

Ответ:
""",

    input_variables=[
        "input"
    ]
)
```

Использование:
```python
result = prompt.invoke(
    {
        "input": "Доставка была очень быстрой"
    }
)
```

Полученный prompt:
```
Определи настроение текста.

Пример:

Текст:
Товар отличный

Ответ:
positive


Пример:

Текст:
Очень плохое качество

Ответ:
negative


Текст:
Доставка была очень быстрой

Ответ:
```

# 4. Использование шаблонов через LCEL

В реальном приложении обычно не вызывают отдельно:
```python
prompt.invoke()

model.invoke()
```

А соединяют их:
```python
chain = prompt | model
```

Например:
```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages(
[
    (
        "system",
        "Ты эксперт по {technology}"
    ),

    (
        "human",
        "{question}"
    )
]
)


model = ChatOpenAI(
    model="gpt-4.1"
)


chain = prompt | model
```

Теперь вызов:
```python
response = chain.invoke(
	{
	    "technology": "Spring",
	    "question": "Что такое Dependency Injection?"
	}
)

print(response.content)
```

Что происходит:
```
dict
{
	technology:"Spring",
	question:"Что такое Dependency Injection?"
}

        |
        v

ChatPromptTemplate

        |
        v

SystemMessage + HumanMessage

        |
        v

ChatOpenAI

        |
        v

AIMessage
```

# 5. Практические правила создания промптов

## 5.1. Разделяйте инструкции и данные

Плохо:
```
Ты помощник. Ответь пользователю:

Имя:
Сергей

Вопрос:
Как оформить карту?
```

Лучше:
```
System:
Ты банковский помощник.

Context:
Имя: Сергей

Human:
Как оформить карту?
```

---
## 5.2. Всегда задавайте формат ответа

Плохо:
```
Расскажи информацию о клиенте.
```

Хорошо:
```
Верни JSON:

{
"name":"",
"age":"",
"city":""
}
```

---
## 5.3. Храните промпты отдельно

В production обычно не пишут:
```
prompt = """
Очень большой текст...
"""
```

Пример структуры:
```
ai-service

 ├── prompts

 │    ├── support_prompt.yaml
 │    ├── summarization_prompt.yaml
 │    └── fraud_detection_prompt.yaml

 ├── chains

 └── services
```

Плюсы:
- проще менять поведение модели;
- можно версионировать;
- можно тестировать разные версии.
