Модуль в языке Python представляет отдельный файл с кодом, который можно повторно использовать в других программах.

---
## Создание модуля

Для создания модуля необходимо создать **файл с расширением** `.py`. Название файла будет представлять название модуля. Затем в этом файле надо определить одну или несколько функций, переменных или классов.

Допустим, основной файл программы называется `main.py`. 
![[Pasted image 20260705181652.png]]

Создадим в той же папке новый файл с именем `message.py`:
```python
# message.py
hello = "Hello all"
def print_message(text):
    print(f"Message: {text}")
```

---
## Импорт модуля (`import`)

Для использования модуля его надо импортировать с помощью оператора `import`:

```python
# main.py
import message      # подключаем модуль message

# выводим значение переменной hello
print(message.hello)        # Hello all
# обращаемся к функции print_message
message.print_message("Hello work")  # Message: Hello work
```
Для обращения к функциональности модуля используется пространство имён, которое по умолчанию совпадает с именем модуля: `message.имя_функции`.

---
## Импорт в глобальное пространство имён (`from ... import`)

С помощью ключевого слова `from` можно импортировать функциональность модуля в глобальное пространство имён текущего модуля:

```python
from message import print_message
# обращаемся к функции без указания модуля

print_message("Hello work")  # Message: Hello work
# переменная hello не доступна, так как она не импортирована
# print(hello)  # NameError
```

### Импорт нескольких объектов
```python
from message import print_message, hello
print_message("Hello work")  # Message: Hello work
print(hello)                 # Hello all
```

### Импорт всего модуля (`*`)
Импортирует все имена из модуля в глобальное пространство имён:

```python
from message import *
print_message("Hello work")  # Message: Hello work
print(hello)                 # Hello all
```

> [!WARNING] Импорт через `*` не рекомендуется  
> Он может привести к конфликтам имён и делает код менее читаемым. Лучше импортировать только то, что нужно.

---
## Конфликт имён
При импорте в глобальное пространство имён может возникнуть конфликт, если функция с таким же именем уже существует:

```python
from message import print_message

print_message("Hello work")  # Message: Hello work — из модуля

def print_message(some_text):
    print(f"Text: {some_text}")
print_message("Hello work")  # Text: Hello work — из текущего файла
```

Последнее объявление переопределяет имя.

## Псевдонимы (`as`)

Можно установить псевдонимы для модулей и их объектов с помощью ключевого слова `as`:

### Псевдоним для модуля
```python
import message as mes
print(mes.hello)                  # Hello all
mes.print_message("Hello work")   # Message: Hello work
```

### Псевдоним для отдельных объектов
```python
from message import print_message as display
from message import hello as welcome

print(welcome)              # Hello all
display("Hello work")       # Message: Hello work
```

### Избегание конфликтов с помощью псевдонимов

```python
from message import print_message as display

def print_message(some_text):
    print(f"Text: {some_text}")
display("Hello work")       # Message: Hello work — из модуля
print_message("Hello work") # Text: Hello work — из текущего файла
```

## Проверка имени модуля (`__name__`)
Каждый ==модуль имеет встроенную переменную== `__name__`, которая содержит имя модуля:

- Если **модуль является запускаемым, то его имя равно** `__main__` (также по два подчеркивания с каждой стороны). 
- Если *модуль используется в другом модуле*, то в момент выполнения *его имя* аналогично **названию файла без расширения py.** 

Переменная `__name__` указывает на имя модуля. 
> Для главного **модуля, который** непосредственно **запускается**, эта переменная ==всегда будет иметь значение== `__main__` вне зависимости от имени файла.

### Пример: использование модуля как самостоятельного и как библиотеки

```python
# message.py
hello = "Hello all"

def print_message(text):
    print(f"Message: {text}")
    
def main():
    print_message(hello)
    
if __name__ == "__main__":
    main()
```

Теперь:
- При запуске `message.py` напрямую → выполняется `main()`
    
- При импорте из `main.py` → `main()` не вызывается

### В главном файле

```python
# main.py
import message

def main():
    message.print_message("Hello work")
    
if __name__ == "__main__":
    main()
```

## Поиск модулей

Интерпретатор Python ищет модули в следующих местах (в порядке приоритета):

1. **Директория запускаемого скрипта** (главного файла)
    
2. **Переменная окружения `PYTHONPATH`**
    
3. **Стандартные пути установки Python** (системные библиотеки)
    

Проверить пути поиска можно с помощью `sys.path`:
```python
import sys
print(sys.path)
```

## Итог

|Конструкция|Описание|Пример|
|---|---|---|
|`import module`|Импорт модуля в пространство имён `module`|`import math`|
|`from module import name`|Импорт конкретного объекта в глобальное пространство|`from math import sqrt`|
|`from module import *`|Импорт всего содержимого (не рекомендуется)|`from math import *`|
|`import module as alias`|Импорт с псевдонимом для модуля|`import numpy as np`|
|`from module import name as alias`|Импорт с псевдонимом для объекта|`from math import sqrt as square_root`|
|`__name__`|Имя текущего модуля; `"__main__"` — если модуль запущен напрямую|`if __name__ == "__main__":`|
