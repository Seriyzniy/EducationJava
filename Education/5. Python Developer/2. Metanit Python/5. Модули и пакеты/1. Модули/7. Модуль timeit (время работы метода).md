## Модуль timeit

Модуль `timeit` предназначен для измерения времени выполнения небольших фрагментов кода. Это правильный способ измерения производительности, так как он автоматически учитывает особенности платформы и минимизирует влияние внешних факторов.

---

## Основная функция: `timeit.timeit()`

```python
timeit.timeit(
	stmt='pass', 
	setup='pass', 
	timer=<default timer>, 
	number=1000000, 
	globals=None)
```

|Параметр|Описание|По умолчанию|
|---|---|---|
|`stmt`|Код/функция, время выполнения которой измеряется|`'pass'`|
|`setup`|Код, выполняемый **перед** запуском `stmt` (импорты, подготовка)|`'pass'`|
|`timer`|Объект таймера (обычно не меняется)|`default_timer()`|
|`number`|Количество выполнений `stmt`|`1 000 000`|
|`globals`|Пространство имён для выполнения кода|`None`|

**Результат:** время выполнения в **секундах**.

---
## Простой пример

```python
import timeit
# Измеряем выполнение простой операции 1 000 000 раз (по умолчанию)
action = "10 + 12"
print(timeit.timeit(action))  # ~0.04 секунды
```

---
## Измерение пользовательской функции

```python
import timeit

def sum_numbers():
    result = 0
    for i in range(10000):
        result += i
    return result
    
# Через лямбду
exec_time = timeit.timeit(lambda: sum_numbers(), number=100)
print(f"Время выполнения: {exec_time} секунд")
```

## Способы задания измеряемого кода

### Способ 1: Лямбда-выражение (рекомендуется)

```python
import timeit

def my_function():
    return sum(range(100))
print(timeit.timeit(lambda: my_function(), number=1000))
```

### Способ 2: Строка с кодом

```python
import timeit

# Простое выражение
print(timeit.timeit("10 + 12"))

# Несколько инструкций через ;
print(timeit.timeit("a=10; b=12; a+b"))

# Многострочный код
code = '''
def sum_numbers():
    result = 0
    for n in range(100):
        result += n
    return result
sum_numbers()
'''
print(timeit.timeit(code, number=1000))
```

### Способ 3: Передача функции напрямую (без лямбды)

```python
import timeit

def my_function():
    return sum(range(100))
    
# timeit.timeit(my_function, number=1000)  # ❌ так НЕ РАБОТАЕТ
# Нужно передавать callable без вызова
print(timeit.timeit(my_function, number=1000))  # ✅ работает
```
## Настройка (`setup`)

Если код зависит от внешних модулей или переменных, используйте `setup`:

```python
import timeit

# Импорт модуля
action = "math.sqrt(25)"
setup = "import math"
print(timeit.timeit(action, setup=setup))

# Импорт конкретной функции
action = "sqrt(25)"
setup = "from math import sqrt"
print(timeit.timeit(action, setup=setup))

# Подготовка переменных
action = "my_list.append(5)"
setup = "my_list = []"
print(timeit.timeit(action, setup=setup, number=1000))
```

### Импорт функции из другого модуля

```python
import timeit

# Файл test.py содержит функцию sum_test()
my_action = "sum_test()"
my_setup = "from test import sum_test"
print(timeit.timeit(my_action, setup=my_setup, number=100))
```

## Использование `globals`

Передайте текущее пространство имён, чтобы функция была доступна без лямбды:

```python
import timeit

def my_function():
    return sum(range(100))
    
# Передаём глобальное пространство имён
print(timeit.timeit("my_function()", globals=globals(), number=1000))
```

---
## Ручное измерение с `default_timer()`

Для более гибкого измерения используйте `timeit.default_timer()`:

```python
import timeit

def sum_numbers():
    result = 0
    for n in range(100):
        result += n
    return result
    
# Замер времени
start = timeit.default_timer()
sum_numbers()
end = timeit.default_timer()
print(f"Время выполнения: {end - start:.6f} секунд")
```

## Класс `timeit.Timer`

Для многократного использования можно создать объект `Timer`:

```python
import timeit

def sum_numbers():
    return sum(range(100))
    
# Создаём таймер
timer = timeit.Timer(lambda: sum_numbers())

# Выполняем измерения
print(timer.timeit(number=100))   # время за 100 запусков
print(timer.repeat(repeat=5, number=100))  # 5 измерений по 100 запусков
```

### Метод `repeat()`

```python
import timeit

def sum_numbers():
    return sum(range(100))
    
timer = timeit.Timer(lambda: sum_numbers())
results = timer.repeat(repeat=5, number=1000)

print("Результаты:", results)
print("Минимум:", min(results))
print("Среднее:", sum(results) / len(results))
```

## Сравнение производительности

Пример сравнения двух способов вычисления суммы:

```python
import timeit

# Способ 1: цикл
def sum_loop(n):
    result = 0
    for i in range(n):
        result += i
    return result
    
# Способ 2: встроенная функция
def sum_builtin(n):
    return sum(range(n))
    
N = 10000
time_loop = timeit.timeit(lambda: sum_loop(N), number=100)
time_builtin = timeit.timeit(lambda: sum_builtin(N), number=100)

print(f"Цикл: {time_loop:.6f} с")
print(f"sum(): {time_builtin:.6f} с")
print(f"sum() быстрее в {time_loop / time_builtin:.2f} раз")
```

## Сравнение методов работы со списками

```python
import timeit

setup = "numbers = list(range(1000))"
methods = {
    "list comprehension": "[x * 2 for x in numbers]",
    "map": "list(map(lambda x: x * 2, numbers))",
    "loop": """
result = []
for x in numbers:
    result.append(x * 2)
"""
}

for name, code in methods.items():
    time = timeit.timeit(code, setup=setup, number=10000)
    print(f"{name:20} {time:.6f} с")
```

## Важные замечания

|Правило|Почему|
|---|---|
|**Используйте `timeit` вместо `time`**|Учитывает особенности платформы, отключает сборку мусора|
|**Не измеряйте `print()`**|Ввод/вывод слишком медленный и нестабильный|
|**Измеряйте несколько запусков**|Один запуск не показателен, используйте `repeat`|
|**Используйте `number`**|Для короткого кода увеличьте количество итераций|
|**Не измеряйте слишком маленькие фрагменты**|Получите шум вместо данных|
