Встроенный модуль `math` в Python предоставляет набор функций для выполнения математических, тригонометрических и логарифмических операций.

---
## Основные функции модуля `math`

| Функция                                       | Описание                                        | Пример                            |
| --------------------------------------------- | ----------------------------------------------- | --------------------------------- |
| `pow(num, power)`                             | Возведение `num` в степень `power`              | `math.pow(2, 3)` → `8.0`          |
| `sqrt(num)`                                   | Квадратный корень числа                         | `math.sqrt(9)` → `3.0`            |
| `ceil(num)`                                   | Округление до ближайшего **наибольшего** целого | `math.ceil(4.56)` → `5`           |
| `floor(num)`                                  | Округление до ближайшего **наименьшего** целого | `math.floor(4.56)` → `4`          |
| `factorial(num)`                              | Факториал числа                                 | `math.factorial(5)` → `120`       |
| `degrees(rad)`                                | Перевод из радиан в градусы                     | `math.degrees(3.14159)` → `180.0` |
| `radians(grad)`                               | Перевод из градусов в радианы                   | `math.radians(180)` → `3.1415...` |
| `cos(rad)`                                    | Косинус угла в радианах                         | `math.cos(0)` → `1.0`             |
| `sin(rad)`                                    | Синус угла в радианах                           | `math.sin(math.pi/2)` → `1.0`     |
| `tan(rad)`                                    | Тангенс угла в радианах                         | `math.tan(0)` → `0.0`             |
| `acos(rad)`, <br>`asin(rad)`, <br>`atan(rad)` | Арккосинус, арксинус, арктангенс                | —                                 |
| `log(n, base)`                                | Логарифм `n` по основанию `base`                | `math.log(8, 2)` → `3.0`          |
| `log10(n)`                                    | Десятичный логарифм                             | `math.log10(100)` → `2.0`         |
| `log2(n)`                                     | Двоичный логарифм (Python 3.3+)                 | `math.log2(8)` → `3.0`            |
| `exp(num)`                                    | Экспонента (`e**num`)                           | `math.exp(1)` → `2.718...`        |

---
## Примеры использования

```python
import math

# Возведение в степень
n1 = math.pow(2, 3)
print(n1)  # 8.0

# Альтернативный способ (встроенный оператор)
n2 = 2 ** 3
print(n2)  # 8

# Квадратный корень
print(math.sqrt(9))   # 3.0

# Округление
print(math.ceil(4.56))   # 5  — вверх
print(math.floor(4.56))  # 4  — вниз

# Перевод радиан ↔ градусы
print(math.degrees(3.14159))  # 180.0
print(math.radians(180))      # 3.141592653589793

# Тригонометрия
print(math.cos(math.radians(60)))  # 0.5
print(math.sin(math.radians(90)))  # 1.0
print(math.tan(math.radians(0)))   # 0.0

# Логарифмы
print(math.log(8, 2))     # 3.0
print(math.log10(100))    # 2.0
print(math.log2(8))       # 3.0
```

## Константы модуля `math`

|Константа|Описание|Значение|
|---|---|---|
|`math.pi`|Число π|`3.141592653589793`|
|`math.e`|Число e (основание натурального логарифма)|`2.718281828459045`|
|`math.tau`|Число τ = 2π (Python 3.6+)|`6.283185307179586`|
|`math.inf`|Бесконечность|`inf`|
|`math.nan`|Not a Number|`nan`|

### Пример с константами

```python
import math

radius = 30
area = math.pi * math.pow(radius, 2)
print(area)  # 2827.4333882308138
# Натуральный логарифм (основание e)
number = math.log(10, math.e)
print(number)  # 2.302585092994046
```

## Встроенные математические функции (без `import math`)

Некоторые математические функции доступны без импорта модуля `math`:

|Функция|Описание|Пример|
|---|---|---|
|`abs(num)`|Абсолютное значение числа|`abs(-5)` → `5`|
|`min(iterable)`|Минимальное значение в итерируемом объекте|`min([1, 2, 3])` → `1`|
|`max(iterable)`|Максимальное значение в итерируемом объекте|`max([1, 2, 3])` → `3`|
|`sum(iterable)`|Сумма элементов|`sum([1, 2, 3])` → `6`|
|`round(num, ndigits)`|Округление|`round(4.56, 1)` → `4.6`|
|`pow(num, power)`|Возведение в степень (аналогично `**`)|`pow(2, 3)` → `8`|
|`divmod(a, b)`|Возвращает (a//b, a%b)|`divmod(7, 3)` → `(2, 1)`|

### Примеры

```python
# Абсолютное значение (расстояние между числами)
num1, num2 = 3, 8
diff = abs(num1 - num2)
print(diff)  # 5

# Минимум и максимум в списке
numbers = [54, 23, 1, 4, 657, 2, -3, 56, 24]
print(min(numbers))  # -3
print(max(numbers))  # 657

# Сумма
print(sum(numbers))  # 818

# Округление
print(round(4.567, 2))  # 4.57
```
