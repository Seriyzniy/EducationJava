При форматировании чисел Python по умолчанию использует **англосаксонскую систему** (разделитель тысяч — запятая, десятичный разделитель — точка):

```text
1,234.567
```

В континентальной Европе и России используется другая система:
```text
1.234,567
```

Для решения проблемы форматирования под определённую культуру в Python используется встроенный модуль `locale`.

---
## Установка локали: `setlocale()`

Для установки локальной культуры используется функция `setlocale(category, locale)`:

```python
import locale
locale.setlocale(locale.LC_ALL, "de")        # для Windows
# locale.setlocale(locale.LC_ALL, "de_DE")   # для MacOS/Linux
```

### Категории (первый параметр)

|Константа|Назначение|
|---|---|
|`LC_ALL`|Все категории (числа, валюты, даты, и т.д.)|
|`LC_NUMERIC`|Форматирование чисел|
|`LC_MONETARY`|Форматирование валют|
|`LC_TIME`|Форматирование дат и времени|
|`LC_CTYPE`|Преобразование регистра символов|
|`LC_COLLATE`|Сравнение строк|

## Форматирование чисел: `format_string()`

Функция `format_string(str, num)` подставляет число вместо плейсхолдера в строку.

### Плейсхолдеры

|Плейсхолдер|Описание|
|---|---|
|`%d`|Целое число|
|`%f`|Число с плавающей точкой|
|`%e`|Экспоненциальная запись|
|`%.2f`|2 знака после запятой|

```python
import locale

# Для Windows
locale.setlocale(locale.LC_ALL, "de")

# Для MacOS/Linux:
# locale.setlocale(locale.LC_ALL, "de_DE")
number = 12345.6789

formatted = locale.format_string("%f", number)
print(formatted)    # 12345,678900

formatted = locale.format_string("%.2f", number)
print(formatted)    # 12345,68

formatted = locale.format_string("%d", number)
print(formatted)    # 12345

formatted = locale.format_string("%e", number)
print(formatted)    # 1,234568e+04
```

---
## Форматирование валюты: `currency()`

```python
money = 234.678
formatted = locale.currency(money)
print(formatted)    # 234,68 €
```

---
## Использование системной локали

Если в качестве второго параметра передать пустую строку `""`, Python будет использовать культуру текущей системы:

```python
import locale

# Используем локаль системы
locale.setlocale(locale.LC_ALL, "")
number = 12345.6789
formatted = locale.format_string("%.02f", number)
print(formatted)    # Например: 12345,68 (для России)

# Получить текущую локаль
print(locale.getlocale())
# ('Russian_Russia', '1251') — Windows
# ('ru_RU', 'UTF-8') — MacOS/Linux
```

## Коды локалей

| Страна   | Windows | MacOS/Linux |
| -------- | ------- | ----------- |
| США      | `"us"`  | `"en_US"`   |
| Германия | `"de"`  | `"de_DE"`   |
| Россия   | `"ru"`  | `"ru_RU"`   |
| Франция  | `"fr"`  | `"fr_FR"`   |
| Испания  | `"es"`  | `"es_ES"`   |

### Получение списка доступных локалей

```python
import locale
# Список всех доступных локалей
print(locale.locale_alias)
```

---
## Пример: форматирование для русской локали

```python
import locale
# Установка русской локали
locale.setlocale(locale.LC_ALL, "ru")
# или
# locale.setlocale(locale.LC_ALL, "ru_RU")

number = 1234567.89
# Форматирование с разделителями тысяч
formatted = locale.format_string("%.2f", number)
print(formatted)  # 1 234 567,89 (разделитель — пробел)

# Валюта
money = 1250.50
print(locale.currency(money))  # 1 250,50 ₽
```
---

## Особенности

### ОС Windows
- Коды: `"ru"`, `"de"`, `"us"`
- Кодировка: `1251` (для России)

### MacOS / Linux
- Коды: `"ru_RU"`, `"de_DE"`, `"en_US"` 
- Кодировка: `UTF-8`
 

### Вывод в зависимости от системы
```python
# Windows
locale.setlocale(locale.LC_ALL, "ru")
# результат: 'Russian_Russia.1251'
# MacOS/Linux
locale.setlocale(locale.LC_ALL, "ru_RU")
# результат: 'ru_RU.UTF-8'
```
