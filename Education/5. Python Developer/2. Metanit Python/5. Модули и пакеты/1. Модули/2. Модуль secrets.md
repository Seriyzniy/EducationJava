Встроенный модуль `secrets` в Python предназначен для генерации **криптографически безопасных** случайных чисел для управления секретами, такими как токены аутентификации, токены безопасности, пароли и другие чувствительные данные.

> [!WARNING] `secrets` vs `random`  
> Модуль `random` **НЕ** является криптографически безопасным и **НЕ** должен использоваться для генерации паролей, токенов и других секретных данных. Для этих целей используйте `secrets`.

---
## Генерация случайных чисел

|Функция|Описание|
|---|---|
|`secrets.choice(seq)`|Возвращает случайно выбранный элемент из непустой последовательности|
|`secrets.randbelow(exclusive_upper_bound)`|Возвращает случайное целое число в диапазоне `[0, exclusive_upper_bound)`|
|`secrets.randbits(k)`|Возвращает неотрицательное целое число с `k` случайными битами|

### Примеры

```python
import secrets

# Случайное число от 0 до 99
number = secrets.randbelow(100)
print(number)

# Число с 7 случайными битами (0-127)
bits = secrets.randbits(7)
print(bits)

# Случайный выбор из последовательности
characters = "abcdefghijklmnopqrstuvwxyz"
letter = secrets.choice(characters)
print(letter)
```

## Генерация паролей

### Простой пароль из 8 символов

```python
import secrets
import string

characters = string.ascii_letters + string.digits
password = "".join(secrets.choice(characters) for _ in range(8))

print(password)  # Пример: EZg7Xbou
```

### Пароль с разными типами символов
```python
import secrets
import string

def generate_password(length=8):
    characters = string.ascii_letters + string.digits + string.punctuation
    
    while True:
        password = "".join(secrets.choice(characters) for _ in range(length))
        # Гарантируем наличие разных типов символов
        if (any(c.islower() for c in password) # строчная буква
		        # заглавная буква
                and any(c.isupper() for c in password)  
                and any(c.isdigit() for c in password)  # цифра
                and any(c in string.punctuation for c in password)):  # спецсимвол
            return password
print(generate_password())  # Пример: y-4!v?SR
```

### Пароль с требованием к количеству цифр

```python
import secrets
import string

def generate_password(length=8):
    characters = string.ascii_letters + string.digits
    
    while True:
        password = "".join(secrets.choice(characters) for _ in range(length))
        # Гарантируем наличие разных типов символов
        if (any(c.islower() for c in password) # строчная буква
            and any(c.isupper() for c in password) # заглавная буква
            and sum(c.isdigit() for c in password) >= 3):  # не менее 3 цифр
            return password
print(generate_password())  # Пример: X9Y88vdi
```

## Генерация токенов

|Функция|Описание|Пример вывода|
|---|---|---|
|`token_bytes([nbytes])`|Случайная строка байтов|`b'\xae\xec\x15...'`|
|`token_hex([nbytes])`|Случайная строка в шестнадцатеричном формате|`ade45fc4d935...`|
|`token_urlsafe([nbytes])`|URL-безопасная строка (Base64)|`ShCFXRTCRHHsQQwo...`|

### Примеры
```python
import secrets

# Строка байтов (разумное значение по умолчанию)
token = secrets.token_bytes()
print(token)  # b'\xae\xec\x153\xdf...'

# Строка байтов длиной 10
token = secrets.token_bytes(10)
print(token)  # b"\xbdnC'`\xd5\x89^\xf2\x80"

# Шестнадцатеричный токен (16 байт = 32 символа)
token = secrets.token_hex(16)
print(token)  # ade45fc4d93547da769253467860bb1d

# URL-безопасный токен
url_token = secrets.token_urlsafe(16)
print(url_token)  # ShCFXRTCRHHsQQwoNTEFOg
```

## Сравнение `random` и `secrets`

|Аспект|`random`|`secrets`|
|---|---|---|
|**Безопасность**|❌ Небезопасный (предсказуемый)|✅ Криптографически безопасный|
|**Использование**|Игры, симуляции, тесты|Пароли, токены, ключи|
|**Источник энтропии**|Системное время + состояние|Источники из ОС (OSRandom)|
|**Скорость**|Быстрый|Медленнее|

### Пример выбора

```python
import random
import secrets

# ❌ НЕПРАВИЛЬНО — НЕ используйте random для паролей!
password = ''.join(random.choice('abcdef') for _ in range(8))
print(password)  # Предсказуемо!
# ✅ ПРАВИЛЬНО — используйте secrets для паролей
password = ''.join(secrets.choice('abcdef') for _ in range(8))
print(password)  # Безопасно!
```

## Практический пример: генерация ключа для API

```python
import secrets

def generate_api_key(length=32):
    """Генерирует безопасный API-ключ"""
    return secrets.token_hex(length)
    
api_key = generate_api_key(16)  # 32 символа
print(f"API Key: {api_key}")
```
