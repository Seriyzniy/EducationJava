Модуль `dataclasses` предоставляет декоратор `dataclass`, который позволяет создавать **data-классы** — ==классы, предназначенные для хранения данных,== **без необходимости писать шаблонный код** (конструкторы, сравнения, строковое представление и т.д.).

---
## Обычный класс vs Data-класс

### Обычный класс
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
tom = Person("Tom", 38)
print(f"Name: {tom.name}  Age: {tom.age}")  # Name: Tom  Age: 38
```

### Data-класс
```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int
tom = Person("Tom", 38)
print(f"Name: {tom.name}  Age: {tom.age}")  # Name: Tom  Age: 38
```

Декоратор `@dataclass` автоматически генерирует:
- Конструктор `__init__()`
    
- Строковое представление `__repr__()`
    
- Сравнение `__eq__()`

### Что генерирует `@dataclass`
```python
@dataclass
class Person:
    name: str
    age: int
```

Эквивалентно:
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def __repr__(self):
        return f"Person(name={self.name!r}, age={self.age!r})"
    def __eq__(self, other):
        if other.__class__ is self.__class__:
            return (self.name, self.age) == (other.name, other.age)
        return NotImplemented
```

---
## Преимущества Data-классов

### Автоматическое строковое представление

```python
tom = Person("Tom", 38)
print(tom)  # Person(name='Tom', age=38)
```

### Автоматическое сравнение объектов
```python
tom = Person("Tom", 38)
bob = Person("Bob", 42)
tomas = Person("Tom", 38)
print(tom == tomas)  # True
print(tom == bob)    # False
```

## Параметры декоратора `dataclass`

```python
def dataclass(cls=None, /, *, init=True, repr=True, eq=True, order=False,
              unsafe_hash=False, frozen=False, match_args=True,
              kw_only=False, slots=False)
```

|Параметр|Описание|По умолчанию|
|---|---|---|
|`init`|Генерация `__init__()`|`True`|
|`repr`|Генерация `__repr__()`|`True`|
|`eq`|Генерация `__eq__()` (сравнение `==`)|`True`|
|`order`|Генерация `__lt__`, `__le__`, `__gt__`, `__ge__`|`False`|
|`unsafe_hash`|Генерация `__hash__()`|`False`|
|`frozen`|Запрет изменения атрибутов (неизменяемый)|`False`|
|`slots`|Использование `__slots__` (экономия памяти)|`False`|

### Пример с параметрами

```python
from dataclasses import dataclass

@dataclass(unsafe_hash=True, order=True)
class Person:
    name: str
    age: int
    def __repr__(self):
        return f"Person. Name: {self.name}  Age: {self.age}"
tom = Person("Tom", 38)
print(tom.__hash__())   # -421667297069596717
print(tom)              # Person. Name: Tom  Age: 38
```

## Значения по умолчанию

Атрибутам можно задать значения по умолчанию:
```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int = 18
    
tom = Person("Tom", 38)
print(tom)          # Person(name='Tom', age=38)
bob = Person("Bob")
print(bob)          # Person(name='Bob', age=18)
```

> [!WARNING] Важен порядок  
> Атрибуты с значениями по умолчанию должны идти **после** обязательных атрибутов.

## Добавление методов

В data-классы можно добавлять собственные методы:
```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int
    def say_hello(self):
        print(f"{self.name} says hello")
tom = Person("Tom", 38)
tom.say_hello()  # Tom says hello
```

## Параметр `frozen` (неизменяемость)

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Person:
    name: str
    age: int
tom = Person("Tom", 38)
tom.age = 39  # TypeError! frozen=True запрещает изменение
```

## Наследование Data-классов

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int
@dataclass
class Employee(Person):
    company: str
tom = Employee("Tom", 38, "Google")
print(tom)  # Employee(name='Tom', age=38, company='Google')
```

## Параметр `order` (сортировка)

```python
from dataclasses import dataclass

@dataclass(order=True)
class Person:
    name: str
    age: int
people = [
    Person("Bob", 30),
    Person("Alice", 25),
    Person("Tom", 35)
]
sorted_people = sorted(people)
for p in sorted_people:
    print(p)
# Person(name='Alice', age=25)
# Person(name='Bob', age=30)
# Person(name='Tom', age=35)
```

По умолчанию сортировка идёт по всем полям по порядку. Можно указать ключ сортировки:

```python
from dataclasses import dataclass, field

@dataclass(order=True)
class Person:
    age: int
    name: str = field(compare=False)  # исключаем name из сравнения
people = [
    Person(30, "Bob"),
    Person(25, "Alice"),
    Person(35, "Tom")
]
print(sorted(people))  # сортировка только по age
```

## Поле `field()`

Функция `field()` позволяет тонко настраивать атрибуты:

```python
from dataclasses import dataclass, field

@dataclass
class Person:
    name: str
    age: int = field(default=18, repr=False)  # не показывать в __repr__
    city: str = field(default="Moscow")
    
tom = Person("Tom", 38, "Moscow")
print(tom)  # Person(name='Tom', city='Moscow')  (age скрыт)
```

### Параметры `field()`

|Параметр|Описание|
|---|---|
|`default`|Значение по умолчанию|
|`default_factory`|Функция для создания значения|
|`init`|Включать в `__init__`|
|`repr`|Включать в `__repr__`|
|`compare`|Включать в сравнение|
|`hash`|Включать в хеш|
|`metadata`|Дополнительные данные (словарь)|

## `__post_init__` — пост-инициализация

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int
    def __post_init__(self):
        if self.age < 0:
            raise ValueError("Age must be positive")
        if self.age > 120:
            raise ValueError("Age must be less than 120")
# tom = Person("Tom", -5)   # ValueError: Age must be positive
tom = Person("Tom", 38)      # OK
```

## Сравнение: Data-класс vs NamedTuple

|Аспект|Data-класс|NamedTuple|
|---|---|---|
|**Изменяемость**|По умолчанию изменяемый|Неизменяемый|
|**Наследование**|Да|Ограничено|
|**Методы**|Можно добавлять|Можно добавлять|
|**Значения по умолчанию**|Да|Да|
|**Производительность**|Чуть медленнее|Быстрее|
|**Синтаксис**|Аннотации типов|Наследование от tuple|
