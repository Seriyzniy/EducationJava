При работе с числами с плавающей точкой (`float`) мы сталкиваемся с тем, что в результате вычислений получаем не совсем точный результат:

```python
number = 0.1 + 0.1 + 0.1
print(number)       # 0.30000000000000004
```

Проблему может решить использование функции `round()`, которая округляет число. Однако есть и другой способ — использование встроенного модуля `decimal`.

---
## Класс Decimal

Ключевым компонентом для работы с числами в этом модуле является класс `Decimal`. Для его применения создаём объект с помощью конструктора, передавая **строковое** значение, которое представляет число:

```python
from decimal import Decimal
number = Decimal("0.1")
```

После этого объект `Decimal` можно использовать в арифметических операциях:

```python
from decimal import Decimal
number = Decimal("0.1")
number = number + number + number
print(number)       # 0.3
```

---
## Смешивание с другими типами

### Можно использовать с целыми числами
```python
number = Decimal("0.1")
number = number + 2
print(number)       # 2.1
```

### Нельзя смешивать с `float`
```python
number = Decimal("0.1")
number = number + 0.1   # TypeError!
```

---
## Точность (количество знаков после запятой)

Количество знаков в дробной части определяется строкой, переданной в конструктор:
```python
number = Decimal("0.10")
number = 3 * number
print(number)       # 0.30

number = Decimal("0.100")
number = 3 * number
print(number)       # 0.300
```

---
## Округление чисел: метод `quantize()`

Метод `quantize()` позволяет округлять числа. Первый аргумент — объект `Decimal`, указывающий формат округления:

```python
from decimal import Decimal

number = Decimal("0.444")
number = number.quantize(Decimal("1.00"))
print(number)       # 0.44

number = Decimal("0.555678")
print(number.quantize(Decimal("1.00")))       # 0.56

number = Decimal("0.999")
print(number.quantize(Decimal("1.00")))       # 1.00
```

Строка `"1.00"` означает округление **до двух знаков после запятой.**

---
## Стратегии округления

Второй аргумент `quantize()` — стратегия округления:

|Константа|Описание|
|---|---|
|`ROUND_HALF_EVEN`|К ближайшему чётному (по умолчанию)|
|`ROUND_HALF_UP`|Вверх, если после числа 5 и выше|
|`ROUND_HALF_DOWN`|Вверх, если после числа строго больше 5|
|`ROUND_CEILING`|Всегда вверх (в большую сторону)|
|`ROUND_FLOOR`|Всегда вниз (в меньшую сторону)|
|`ROUND_05UP`|Округляет 0 до 1, если после 5 и выше|

### Примеры
```python
from decimal import Decimal, ROUND_HALF_EVEN, ROUND_HALF_UP, ROUND_HALF_DOWN

from decimal import ROUND_CEILING, ROUND_FLOOR, ROUND_05UP
```

#### ROUND_HALF_EVEN (по умолчанию)

Округление **до ближайшего чётного числа**:
```python
number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_HALF_EVEN))  
# 10.02 (2 — чётное)

number = Decimal("10.035")
print(number.quantize(Decimal("1.00"), ROUND_HALF_EVEN))  
# 10.04 (4 — чётное)
```

#### ROUND_HALF_UP
Округляет вверх, если после числа 5 или больше:
```python
number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_HALF_UP))    
# 10.03


number = Decimal("10.024")
print(number.quantize(Decimal("1.00"), ROUND_HALF_UP))    
# 10.02
```

#### ROUND_HALF_DOWN
Округляет вверх, только если после числа больше 5:
```python
number = Decimal("10.026")
print(number.quantize(Decimal("1.00"), ROUND_HALF_DOWN))  
# 10.03


number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_HALF_DOWN))  
# 10.02
```

#### ROUND_CEILING
Округляет в большую сторону всегда:
```python
number = Decimal("10.021")
print(number.quantize(Decimal("1.00"), ROUND_CEILING))    
# 10.03


number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_CEILING))    
# 10.03
```

#### ROUND_FLOOR
Округляет в меньшую сторону всегда:
```python
number = Decimal("10.021")
print(number.quantize(Decimal("1.00"), ROUND_FLOOR))      
# 10.02

number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_FLOOR))      
# 10.02
```

#### ROUND_05UP
Округляет 0 до 1, если после числа 5 и выше:

```python
number = Decimal("10.005")
print(number.quantize(Decimal("1.00"), ROUND_05UP))       
# 10.01

number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_05UP))       
# 10.02
```

## Контекст и глобальные настройки

Можно задать глобальные настройки точности с помощью `getcontext()`:

```python
from decimal import Decimal, getcontext

getcontext().prec = 6  # 6 знаков всего (включая целую часть)
number = Decimal(1) / Decimal(7)
print(number)  # 0.142857
```

---
## Сравнение `float` и `Decimal`

|Аспект|`float`|`Decimal`|
|---|---|---|
|**Точность**|Двоичная, с погрешностями|Десятичная, точная|
|**Скорость**|Быстрый|Медленнее|
|**Память**|Меньше|Больше|
|**Использование**|Общие вычисления|Финансовые расчёты, точность важна|
|**Смешивание с другими типами**|С `int`, `float`|С `int`, но не с `float`|
