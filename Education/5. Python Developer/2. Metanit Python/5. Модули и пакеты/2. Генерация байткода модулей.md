## Компиляция и выполнение Python-скриптов

При выполнении скрипта на языке Python выполнение разбивается на две стадии:

1. **Компиляция** — файл с кодом (`.py`) компилируется в промежуточный байт-код
    
2. **Интерпретация** — скомпилированный байт-код выполняется интерпретатором
    

Нам не надо явным образом генерировать байт-код — он создаётся **неявно** при выполнении скрипта.

---
## Кэширование байт-кода (файлы `.pyc`)

Если программа импортирует внешние модули/библиотеки, и они импортируются **в первый раз**, то их скомпилированный байт-код сохраняется в файле с расширением `.pyc` и кэшируется в каталоге `__pycache__`:

```text
project/
├── app.py              # основной файл (байт-код НЕ сохраняется)
├── user.py             # импортируемый модуль
└── __pycache__/        # кэш байт-кода
    └── user.cpython-311.pyc   # скомпилированный байт-код
```

**Правила работы с кэшем:**
- Если в исходный файл вносятся изменения → Python **перекомпилирует** файл
    
- Если изменений нет → загружается ранее скомпилированный байт-код (ускорение загрузки)
    
- Байт-код **основного скрипта** (главного файла) **не сохраняется** и перекомпилируется каждый раз при запуске
    

---
## Пример

### Модуль `user.py`

```python
# user.py
def printUser(username, userage):
    print(f"Name: {username}  Age: {userage}")
```

### Главный модуль `app.py`

```python
# app.py
import user

username = "Tom"
userage = 39
user.printUser(username, userage)
```

### Результат
При выполнении `app.py` в папке проекта будет создан каталог `__pycache__`, а в нём файл байт-кода для модуля `user.py`:

```text
__pycache__/
└── user.cpython-311.pyc   # для Python 3.11
```

Название файла содержит версию интерпретатора, чтобы избежать конфликтов между разными версиями Python.

---
## Ручная компиляция байт-кода

Хотя файлы `.pyc` создаются автоматически, можно сгенерировать байт-код вручную.

### 1. Компиляция одного файла (`py_compile`)
```python
import py_compile

py_compile.compile("user.py")   # передаём путь к скрипту
```

После выполнения в папке появится каталог `__pycache__` с файлом `user.cpython-311.pyc`.

### 2. Компиляция всех файлов в папке (`compileall`)

Из командной строки:
```bash
# Компилируем все .py файлы в папке и подпапках
python -m compileall c:\python\files

# Компилируем только файлы в указанной папке (без подпапок)
python -m compileall c:\python\files -l
```

---
## Важные моменты

| Файл                                  | ==Сохраняется ли байт-код?==                                                |
| ------------------------------------- | --------------------------------------------------------------------------- |
| **Главный скрипт** (запускаемый файл) | **Нет** — перекомпилируется при каждом запуске                              |
| **Импортируемые модули**              | **Да** — сохраняется в `__pycache__/` и используется при повторных запусках |
### Почему главный скрипт не сохраняется?

Потому что он запускается напрямую и предполагается, что его код может часто меняться. Кэширование импортируемых модулей даёт основной выигрыш в производительности.
