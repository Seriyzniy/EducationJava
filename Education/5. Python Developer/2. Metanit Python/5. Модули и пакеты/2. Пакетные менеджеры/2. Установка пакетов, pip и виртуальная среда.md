По умолчанию *вместе с установкой интерпретатора Python также устанавливается множество дополнительных пакетов/библиотек.* 

**Кроме встроенных пакетов существует огромное количество пакетов, которые развиваются сообществом** и которые мы также можем использовать при разработке приложения.

Для управления пакетами (их установки или удаления) необходим такой инструмент как **менеджер пакетов**. Существует множество менеджеров пакетов, например, `pip`, `conda`, `pixi`, `uv` и другие.

В этой статье мы рассмотрим использование менеджера `pip`, поскольку он является стандартным и наиболее распространённым способом для управления пакетами, и обычно он устанавливается вместе с интерпретатором Python.

`pip` загружает пакеты из репозитория **PyPI** (Python Package Index), который является самым большим репозиторием пакетов Python. Репозиторий доступен по адресу: [https://pypi.org/](https://pypi.org/).

## Проверка наличия pip
```bash
pip --version
```

Если pip установлен, вы увидите версию менеджера пакетов:
```text
pip 24.0 from /usr/lib/python3/dist-packages/pip (python 3.12)
```

Если pip не установлен, выполните:
```bash
python -m ensurepip --upgrade
```

Для обновления pip:
```bash
python -m pip install --upgrade pip
```

## Виртуальная среда (venv)

Виртуальная среда **позволяет изолировать пакеты для каждого проекта, избегая конфликтов между версиями пакетов.**

### Зачем нужна виртуальная среда?

Без виртуальной среды все пакеты устанавливаются глобально. 

Если для двух проектов нужны разные версии одного пакета, возникает конфликт. Виртуальная среда решает эту проблему, создавая изолированное окружение для каждого проекта.

### Виртуальная среда в Windows
На Windows использовать виртуальную среду необязательно, но тоже является рекомендуемым подходом при работы с пакетами Python. 

Виртуальная среда позволяет изолировать пакеты от системных установок Python.

### Установка модуля venv (Linux)
На некоторых дистрибутивах Linux модуль `venv` может отсутствовать. Установка на Ubuntu/Debian:
```bash
sudo apt install python3-venv
```

---
## Создание виртуальной среды
```bash
python3 -m venv myvenv
```
- `python3 -m venv` — запуск модуля venv
    
- `myvenv` — название виртуальной среды (может быть любым)


После выполнения в текущей папке создается подкаталог `myvenv`:
```text
myvenv/
├── bin/              # исполняемые файлы (Linux/MacOS)
├── Scripts/          # исполняемые файлы (Windows)
├── include/          # заголовочные файлы
├── lib/              # установленные пакеты
├── lib64 -> lib      # ссылка (Linux)
└── pyvenv.cfg        # конфигурация среды
```

---
## Активация виртуальной среды

Перед использованием виртуальную среду необходимо активировать. Каждый раз при работе с проектом нужно активировать связанную с ним виртуальную среду.

### Windows (командная строка)
```bash
myvenv\Scripts\activate.bat
```

### Windows (PowerShell)
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
myvenv\Scripts\Activate.ps1
```

### Linux / MacOS
```bash
source myvenv/bin/activate
```

### Признак активации
После активации слева от текущего пути появляется название виртуальной среды в круглых скобках:
```text
(myvenv) eugene@Eugene:/python/metanit$
```

---
## Деактивация виртуальной среды
```bash
deactivate
```

## Управление пакетами с помощью pip

### Установка пакета
```bash
pip install название_пакета
```

```bash

python -c "import matplotlib; print(matplotlib.__version__)"
```

## Использование установленных пакетов

Пример программы `app.py` с использованием matplotlib:

```python
import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]

rates = [13.58, 15.33, 14.26, 13.92, 12.74, 12.2, 13.44, 15.63, 15.74, 17.08, 17.18, 16.66]

plt.xlabel("month")
plt.ylabel("rate")
plt.plot(months, rates)
plt.show()
```

### Запуск программы
```bash
python app.py
```

### Результат
Откроется окно с графиком, отображающим изменение популярности Python по месяцам.

## Основные команды pip

|Команда|Описание|
|---|---|
|`pip install package`|Установка пакета|
|`pip install package==1.2.3`|Установка конкретной версии|
|`pip install --upgrade package`|Обновление пакета|
|`pip uninstall package`|Удаление пакета|
|`pip list`|Список всех установленных пакетов|
|`pip show package`|Информация о пакете|
|`pip freeze`|Список пакетов в формате requirements.txt|
|`pip install -r requirements.txt`|Установка пакетов из файла|

---
## Работа с requirements.txt

### Создание файла зависимостей
```bash
pip freeze > requirements.txt
```

### Установка зависимостей из файла
```bash
pip install -r requirements.txt
```
