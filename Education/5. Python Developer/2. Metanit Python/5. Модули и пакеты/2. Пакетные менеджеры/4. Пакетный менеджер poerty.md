## 1. Описание и назначение

### Что такое Poetry?
**Poetry** — это современный менеджер пакетов и инструмент управления Python-проектами.

Он объединяет функциональность сразу нескольких инструментов:

- управление зависимостями;
- создание и использование виртуального окружения;
- разрешение конфликтов версий библиотек;
- сборку Python-пакетов;
- публикацию пакетов на PyPI (при необходимости).

Для Python Poetry является аналогом **Maven** или **Gradle** в мире Java.

---
### Какие проблемы решает Poetry?

До появления Poetry разработчику приходилось использовать сразу несколько инструментов:

|Инструмент|Назначение|
|---|---|
|`pip`|установка библиотек|
|`venv`|создание виртуального окружения|
|`requirements.txt`|хранение списка зависимостей|
|`setup.py`|описание проекта|
|`setuptools`|сборка пакета|

Poetry объединяет всё это в один инструмент.

---
### Основные файлы проекта

После инициализации проекта появляются два основных файла.

#### **pyproject.toml**
Главный конфигурационный файл проекта.
Содержит:
- информацию о проекте;
- версию Python;
- список зависимостей;
- dev-зависимости;
- настройки сборки;
- точки входа (scripts).

Пример:
```
[tool.poetry]name = "ai-agent"version = "0.1.0"[tool.poetry.dependencies]python = "^3.12"langchain = "^0.3"fastapi = "^0.116"[tool.poetry.group.dev.dependencies]pytest = "^8.4"ruff = "^0.12"
```

---
### **poetry.lock**
Lock-файл.

Содержит **точные версии** всех библиотек и их зависимостей.

Например:
```
langchain==0.3.15↓использует↓requests==2.32.4↓использует↓urllib3==2.5.0
```

Благодаря этому все разработчики проекта используют одинаковые версии библиотек.

Файл **обязательно добавляется в Git**.

---
### Что коммитится в Git

Коммитятся:
```
pyproject.toml
poetry.lock
```

Не коммитятся:

```
.venv
__pycache__
.idea
.vscode
```

## 2. Основные команды

Для повседневной разработки достаточно уверенно владеть следующими командами:

|Команда|Назначение|
|---|---|
|`poetry install`|Установить зависимости проекта|
|`poetry add <package>`|Добавить библиотеку|
|`poetry remove <package>`|Удалить библиотеку|
|`poetry update`|Обновить зависимости|
|`poetry show`|Посмотреть список библиотек|
|`poetry show --tree`|Посмотреть дерево зависимостей|
|`poetry run python main.py`|Запустить приложение|
|`poetry run pytest`|Запустить тесты|
|`poetry env info`|Информация о виртуальном окружении|

---
### Создать новый проект
```
poetry new my_project
```

Создает структуру нового проекта.

---
### Подключить Poetry к существующему проекту
```
poetry init
```

Создает файл
```
pyproject.toml
```

и задает вопросы о проекте.

---
### Установить зависимости
```
poetry install
```

Используется:
- после клонирования проекта;
- после получения изменений из Git;
- если изменился `poetry.lock`.

---
### Добавить библиотеку
```
poetry add langchain
```

Установить конкретную версию
```
poetry add "langchain>=0.3"
```
или
```
poetry add langchain@^0.3
```

---
### Добавить библиотеку только для разработки
```
poetry add --group dev pytest
```

Такие библиотеки обычно не устанавливаются в production.

---
### Удалить библиотеку
```
poetry remove langchain
```

Poetry автоматически обновит оба файла:
```
pyproject.tomlpoetry.lock
```

---
### Обновить зависимости
```
poetry update
```

Обновляет библиотеки до новых совместимых версий и пересоздает `poetry.lock`.

---
### Посмотреть установленные библиотеки
```
poetry show
```

Например:
```
fastapilangchainpydantichttpx
```

---
### Посмотреть дерево зависимостей
```
poetry show --tree
```

Например:
```
langchain├── pydantic├── requests│   ├── urllib3│   └── charset-normalizer└── httpx
```

Очень полезная команда при анализе проекта.

---
### Запустить программу
```
poetry run python main.py
```

Команда автоматически использует виртуальное окружение проекта.

---
### Запустить тесты

```
poetry run pytest
```

---
### Выполнить произвольную команду
```
poetry run <команда>
```

Например
```
poetry run python script.py
```
или
```
poetry run ruff check .
```

---
### Получить информацию о виртуальном окружении
```
poetry env info
```

Показывает:
- путь к виртуальному окружению;
- используемую версию Python;
- информацию об интерпретаторе.
