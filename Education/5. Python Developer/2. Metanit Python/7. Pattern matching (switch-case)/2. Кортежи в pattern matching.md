В Python кортежи активно используются в конструкции `match` для сопоставления с образцом. Это позволяет не только проверять структуру данных, но и извлекать отдельные элементы.

---
## Итог

| Синтаксис        | Описание                                       | Пример                      |
| ---------------- | ---------------------------------------------- | --------------------------- |
| `(a, b)`         | Точное соответствие двум элементам             | `case (x, y):`              |
| `(a, )`          | Кортеж из одного элемента                      | `case ("quit",):`           |
| `(a, b, *rest)`  | Кортеж с произвольным количеством элементов    | `case (x, y, *rest):`       |
| `(a, _)`         | Пропуск второго элемента                       | `case (name, _):`           |
| (a \| b, c)      | Альтернативные значения для элемента           | case ("Tom" \| "Bob", age): |
| (a, b) \| (c, d) | Альтернативные кортежи                         | case (1,2) \| (3,4):        |
| `(a, b, *_)`     | Кортеж с 2+ элементами, остальное игнорируется | `case (x, y, *_):`          |

**Рекомендации:**

- Используйте `match` с кортежами для обработки команд и структурированных данных
    
- Применяйте `*rest` для захвата переменного количества элементов
    
- Используйте `_` для игнорирования ненужных значений
    
- Объединяйте шаблоны через `|` для сокращения кода

---
## Базовое сопоставление с кортежами

```python
def print_data(user):
    match user:
        case ("Tom", 37):
            print("default user")
        case ("Tom", age):
            print(f"Age: {age}")
        case (name, 22):
            print(f"Name: {name}")
        case (name, age):
            print(f"Name: {name}  Age: {age}")
        
print_data(("Tom", 37))   # default user
print_data(("Tom", 28))   # Age: 28
print_data(("Sam", 22))   # Name: Sam
print_data(("Bob", 41))   # Name: Bob  Age: 41
print_data(("Tom", 33, "Google"))  # не соответствует ни одному шаблону
```
---
## Альтернативные значения в элементах

С помощью оператора `|` можно указать несколько допустимых значений для элемента:

```python
def print_data(user):
    match user:
        case ("Tom" | "Tomas" | "Tommy", 37):
            print("default user")
        case ("Tom", age):
            print(f"Age: {age}")
        case (name, 22):
            print(f"Name: {name}")
        case (name, age):
            print(f"Name: {name}  Age: {age}")
        
print_data(("Tom", 37))     # default user
print_data(("Tomas", 37))   # default user
print_data(("Tom", 28))     # Age: 28
print_data(("Sam", 37))     # Name: Sam  Age: 37
```

---
## Альтернативные шаблоны кортежей

Можно объединять целые кортежи через `|`:

```python
def print_data(user):
    match user:
        case ("Tom", 37) | ("Sam", 22):
            print("default user")
        case (name, age):
            print(f"Name: {name}  Age: {age}")
        
print_data(("Tom", 37))   # default user
print_data(("Sam", 22))   # default user
print_data(("Mike", 28))  # Name: Mike  Age: 28
```

---
## Пропуск элементов с помощью `_`

Если какой-то элемент не важен, используйте `_` (прочерк):

```python
def print_data(user):
    match user:
        case ("Tom", 37):
            print("default user")
        case (name, _):      # второй элемент не важен
            print(f"Name: {name}")
            
print_data(("Tom", 37))   # default user
print_data(("Sam", 25))   # Name: Sam
print_data(("Bob", 41))   # Name: Bob
```

### Игнорирование всех элементов

```python
def print_data(user):
    match user:
        case ("Tom", 37):
            print("default user")
        case ("Sam", _):
            print("Name: Sam")
        case (_, _):         # любой двухэлементный кортеж
            print("Undefined user")
        
print_data(("Tom", 37))   # default user
print_data(("Sam", 25))   # Name: Sam
print_data(("Bob", 41))   # Undefined user
```

> [!NOTE] `_` соответствует значению, но не извлекает его.

## Кортежи разной длины

Можно сопоставлять кортежи с разным количеством элементов:

```python
def print_data(user):
    match user:
        case (name, age):
            print(f"Name: {name}  Age: {age}")
        case (name, age, company):
            print(f"Name: {name}  Age: {age}  Company: {company}")
        case (name, age, company, lang):
            print(f"Name: {name}  Age: {age}  Company: {company} Language: {lang}")
            
print_data(("Tom", 37))                     # Name: Tom  Age: 37
print_data(("Sam", 22, "Microsoft"))        # Name: Sam  Age: 22  Company: Microsoft
print_data(("Bob", 41, "Google", "english")) # Name: Bob  Age: 41  Company: Google Language: english
```

---
## Кортежи с неопределённым количеством элементов (`*`)

С помощью `*` можно захватить все оставшиеся элементы кортежа:

```python
def print_data(user):
    match user:
        case ("Tom", 37, *rest):
            print(f"Rest: {rest}")
        case (name, age, *rest):
            print(f"{name} ({age}): {rest}")
        
print_data(("Tom", 37))                 # Rest: []
print_data(("Tom", 37, "Google"))       # Rest: ['Google']
print_data(("Bob", 41, "Microsoft", "english"))  # Bob (41): ['Microsoft', 'english']
```

### Игнорирование остальных элементов

Если остальные элементы не нужны, используйте `*_`:

```python
def print_data(user):
    match user:
        case ("Tom", 37, *_):
            print("Default user")
        case (name, age, *_):
            print(f"{name} ({age})")
        
print_data(("Tom", 37))                  # Default user
print_data(("Tom", 37, "Google"))        # Default user
print_data(("Bob", 41, "Microsoft", "english"))  # Bob (41)
```
