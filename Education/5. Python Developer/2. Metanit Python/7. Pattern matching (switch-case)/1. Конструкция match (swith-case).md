Начиная с версии **Python 3.10** появилась конструкция `match`, реализующая **сопоставление с образцом** (pattern matching). 

Она похожа на `if/elif/else`, но гораздо мощнее — позволяет не только сравнивать значения, но и извлекать данные из составных типов.

## Синтаксис

```python
match выражение:
    case шаблон_1:
        действие_1
    case шаблон_2:
        действие_2
    # ...
    case _:
        действие_по_умолчанию
```

- `match` — ключевое слово, после которого идёт выражение для сравнения
    
- `case` — блок с шаблоном. Если шаблон совпадает, выполняются инструкции блока
    
- `case _` — шаблон по умолчанию (если ни один case не подошёл)
    

---
## Простые примеры

### Сопоставление со строковыми литералами

```python
def print_hello(language):
    match language:
        case "russian":
            print("Привет")
        case "english":
            print("Hello")
        case "german":
            print("Hallo")
        case _:
            print("Undefined")
            
print_hello("english")   # Hello
print_hello("spanish")   # Undefined
```

### Однострочные `case`
```python
def print_hello(language):
    match language:
        case "russian": print("Привет")
        case "english": print("Hello")
        case "german":  print("Hallo")
        case _:         print("Undefined")
```

## Несколько значений в одном `case`

С помощью оператора `|` можно объединить несколько значений в одном шаблоне:

```python
def print_hello(language):
    match language:
        case "russian":
            print("Привет")
        case "american english" | "british english" | "english":
            print("Hello")
        case _:
            print("Undefined")
            
print_hello("english")           # Hello
print_hello("american english")  # Hello
print_hello("spanish")           # Undefined
```

## Сопоставление с числами

```python
def operation(a, b, code):
    match code:
        case 1:
            return a + b
        case 2:
            return a - b
        case 3:
            return a * b
        case _:
            return 0
print(operation(10, 5, 1))   # 15
print(operation(10, 5, 2))   # 5
print(operation(10, 5, 3))   # 50
print(operation(10, 5, 4))   # 0
```

## Сопоставление с кортежами и списками

`match` умеет "разбирать" последовательности на составляющие:

```python
def process_point(point):
    match point:
        case (0, 0):
            print("Начало координат")
        case (0, y):
            print(f"Точка на оси Y: y={y}")
        case (x, 0):
            print(f"Точка на оси X: x={x}")
        case (x, y):
            print(f"Точка с координатами: x={x}, y={y}")
process_point((0, 0))    # Начало координат
process_point((0, 5))    # Точка на оси Y: y=5
process_point((3, 0))    # Точка на оси X: x=3
process_point((3, 4))    # Точка с координатами: x=3, y=4
```

```python
def describe_list(lst):
    match lst:
        case []:
            print("Пустой список")
        case [x]:
            print(f"Один элемент: {x}")
        case [x, y]:
            print(f"Два элемента: {x}, {y}")
        case [x, *rest]:
            print(f"Первый: {x}, остальные: {rest}")
            
describe_list([])              # Пустой список
describe_list([5])             # Один элемент: 5
describe_list([1, 2])          # Два элемента: 1, 2
describe_list([1, 2, 3, 4])    # Первый: 1, остальные: [2, 3, 4]
```

## Извлечение данных с привязкой к переменным

В шаблонах можно использовать имена, которые будут "захватывать" значения:

```python
def greet(person):
    match person:
        case ("user", name):
            print(f"Привет, пользователь {name}!")
        case ("admin", name):
            print(f"Добро пожаловать, администратор {name}!")
        case _:
            print("Неизвестный тип")
            
greet(("user", "Tom"))      # Привет, пользователь Tom!
greet(("admin", "Bob"))     # Добро пожаловать, администратор Bob!
```

## Использование `if` в `case` (условия-стражи)

В `case` можно добавить дополнительное условие с помощью `if`:

```python
def classify_number(n):
    match n:
        case 0:
            print("Ноль")
        case 1:
            print("Один")
        case _ if n < 0:
            print("Отрицательное число")
        case _ if n > 0:
            print("Положительное число")
        
classify_number(0)     # Ноль
classify_number(-5)    # Отрицательное число
classify_number(10)    # Положительное число
```

## Сопоставление с объектами классов

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
def process(obj):
    match obj:
        case Point(x=0, y=0):
            print("Начало координат")
        case Point(x=0, y=y):
            print(f"На оси Y: {y}")
        case Point(x=x, y=0):
            print(f"На оси X: {x}")
        case Point(x=x, y=y):
            print(f"x={x}, y={y}")
        case _:
            print("Не точка")
    
p1 = Point(0, 0)
p2 = Point(0, 5)
p3 = Point(3, 4)
process(p1)  # Начало координат
process(p2)  # На оси Y: 5
process(p3)  # x=3, y=4
```
