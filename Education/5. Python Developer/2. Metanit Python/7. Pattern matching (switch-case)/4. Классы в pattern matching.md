### Основные команды

|Конструкция|Описание|
|---|---|
|`case ClassName(attr=value):`|Проверка атрибута на точное значение|
|`case ClassName(attr=var):`|Извлечение значения атрибута в переменную|
|`case ClassName(attr=value \| value2):`|Альтернативные значения для атрибута|
|`case ClassName(attr=var, attr2=var2):`|Извлечение нескольких атрибутов|
|`case ClassName(value, value2):`|Позиционное сопоставление (требуется `__match_args__`)|
|`case ClassName(attr=var, **rest):`|Извлечение атрибута и остальных в словарь|
|`case ClassName(attr=_) \| ClassName2(attr=_):`|Альтернативные шаблоны классов|
|`case _:`|Обработка всех остальных случаев|

---

### Сопоставление с объектами классов

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
def print_person(person):
    match person:
        case Person(name="Tom", age=37):
            print("Default Person")
        case Person(name=name, age=37):
            print(f"Name: {name}")
        case Person(name="Tom", age=age):
            print(f"Age: {age}")
        case Person(name=name, age=age):
            print(f"Name: {name}  Age: {age}")
print_person(Person("Tom", 37))  # Default Person
print_person(Person("Tom", 22))  # Age: 22
print_person(Person("Sam", 37))  # Name: Sam
print_person(Person("Bob", 41))  # Name: Bob  Age: 41
```

> [!NOTE] Шаблон — это НЕ вызов конструктора!  
> `Person(name="Tom", age=37)` в `case` — это шаблон для сопоставления, а не создание объекта.

### Частичное сопоставление

Можно проверять только часть атрибутов:

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
def print_person(person):
    match person:
        case Person(name="Tom"):
            print("Default Person")
        case Person(name=person_name):
            print(f"Name: {person_name}")
        case _:
            print("Not a Person")
print_person(Person("Tom", 37))  # Default Person
print_person(Person("Sam", 37))  # Name: Sam
print_person("Tom")              # Not a Person
```

### Альтернативные значения для атрибута (`|`)

```python
def print_person(person):
    match person:
        case Person(name="Tom" | "Tomas" | "Tommy"):
            print("Default Person")
        case Person(name=person_name):
            print(f"Name: {person_name}")
        case _:
            print("Not a Person")
            
print_person(Person("Tom", 37))    # Default Person
print_person(Person("Tomas", 37))  # Default Person
print_person(Person("Bob", 37))    # Name: Bob
```

### Альтернативные шаблоны классов (`|`)

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
class Student:
    def __init__(self, name):
        self.name = name
        
def print_person(person):
    match person:
        case Person(name="Tom") | Student(name="Tomas"):
            print("Default Person/Student")
        case Person(name=name) | Student(name=name):
            print(f"Name: {name}")
        case _:
            print("Not a Person or Student")
print_person(Person("Tom", 37))     # Default Person/Student
print_person(Student("Tomas"))      # Default Person/Student
print_person(Person("Bob", 41))     # Name: Bob
print_person(Student("Mike"))       # Name: Mike
```

### Позиционные параметры (`__match_args__`)

Чтобы использовать позиционное сопоставление, нужно определить `__match_args__` в классе:

```python
class Person:
    __match_args__ = ("name", "age")  # порядок атрибутов для позиционного сопоставления
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
def print_person(person):
    match person:
        case Person("Tom", 37):
            print("Default Person")
        case Person(person_name, 37):
            print(f"Name: {person_name}")
        case Person("Tom", person_age):
            print(f"Age: {person_age}")
        case Person(person_name, person_age):
            print(f"Name: {person_name}  Age: {person_age}")
        
print_person(Person("Tom", 37))  # Default Person
print_person(Person("Tom", 22))  # Age: 22
print_person(Person("Sam", 37))  # Name: Sam
print_person(Person("Bob", 41))  # Name: Bob  Age: 41
```

### Получение остальных атрибутов (`**rest`)

```python
class Person:
    __match_args__ = ("name", "age")
    def __init__(self, name, age, city="Unknown"):
        self.name = name
        self.age = age
        self.city = city
        
def print_person(person):
    match person:
        case Person(name="Tom", **rest):
            print(f"Tom: {rest}")
        case Person(name=name, **rest):
            print(f"{name}: {rest}")
            
print_person(Person("Tom", 37))           
# Tom: {'age': 37, 'city': 'Unknown'}

print_person(Person("Tom", 37, "Moscow")) 
# Tom: {'age': 37, 'city': 'Moscow'}

print_person(Person("Bob", 41))           
# Bob: {'age': 41, 'city': 'Unknown'}
```

### Игнорирование атрибутов (`_`)

```python
def print_person(person):
    match person:
        case Person(name="Tom", age=_):
            print("Tom (возраст не важен)")
        case Person(name=name, age=_):
            print(f"Person: {name}")
            
print_person(Person("Tom", 37))  # Tom (возраст не важен)
print_person(Person("Tom", 22))  # Tom (возраст не важен)
print_person(Person("Sam", 37))  # Person: Sam
```
