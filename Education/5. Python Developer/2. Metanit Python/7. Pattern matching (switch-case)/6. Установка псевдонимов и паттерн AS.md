Оператор `as` позволяет установить **псевдоним** для значения шаблона или для всего шаблона целиком. Это удобно, когда нужно сохранить совпавшее значение для дальнейшего использования.


```python
case шаблон [as переменная] [if условие]:
    # использование переменной
```


> [!WARNING] Порядок `as` и `if`  
> В одном `case` нельзя использовать `as` и `if` одновременно в произвольном порядке. `as` относится к шаблону и ставится после шаблона, `if` — после `as` (если нужно условие):

```python
case Person(name="Tom", age=age) as tom if age >= 18:
    # сначала шаблон, потом as, потом if
```

---
### Базовый пример: псевдоним для альтернативных значений

```python
def print_person(person):
    match person:
        case "Tom" | "Tomas" | "Tommy" as name:
            print(f"Name: {name}")
        case _:
            print("Undefined")
            
print_person("Tom")     # Name: Tom
print_person("Tomas")   # Name: Tomas
print_person("Bob")     # Undefined
```

Здесь шаблон соответствует трём строкам, и независимо от того, какая именно передана, она сохраняется в переменную `name`.

---
### Псевдонимы для отдельных частей шаблона

```python
def print_person(person):
    match person:
        case ("Tom" | "Tomas" as name, 37 | 38 as age):
            print(f"Name: {name}  Age: {age}")
        case _:
            print("Undefined")
print_person(("Tomas", 38))  # Name: Tomas  Age: 38
```

---
### Псевдоним для всего шаблона

```python
def print_person(person):
    match person:
        case ("Bob" | "Robert", 41 | 42) as bob:
            print(f"Name: {bob[0]}  Age: {bob[1]}")
        case _:
            print("Undefined")
            
print_person(("Robert", 41))  # Name: Robert  Age: 41
```

Здесь псевдоним `bob` **ссылается на весь кортеж**, и мы обращаемся к его элементам по индексу.

### Псевдонимы с объектами классов

```python
class Person:
    __match_args__ = ("name", "age")
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
def print_family(family):
    match family:
        case (Person() as husband, Person() as wife):
            print(f"Husband. Name: {husband.name}  Age: {husband.age}")
            print(f"Wife. Name: {wife.name}  Age: {wife.age}")
        case _:
            print("Undefined")
            
print_family((Person("Tom", 37), Person("Alice", 33)))
# Husband. Name: Tom  Age: 37
# Wife. Name: Alice  Age: 33
```

Здесь:
- `husband` — псевдоним для первого объекта `Person`
    
- `wife` — псевдоним для второго объекта `Person`
    
- Через псевдонимы мы обращаемся к атрибутам объектов

### Псевдонимы с дополнительной проверкой (guard)

```python
class Person:
    __match_args__ = ("name", "age")
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
def print_person(person):
    match person:
        case Person(name="Tom", age=age) as tom if age >= 18:
            print(f"{tom.name} совершеннолетний, возраст: {age}")
        case Person(name="Tom", age=age) as tom:
            print(f"{tom.name} несовершеннолетний, возраст: {age}")
        case _:
            print("Не Tom")
            
print_person(Person("Tom", 25))  # Tom совершеннолетний, возраст: 25
print_person(Person("Tom", 15))  # Tom несовершеннолетний, возраст: 15
```

### Псевдонимы для кортежей и списков

```python
def process_data(data):
    match data:
        case [first, second, *rest] as full_list:
            print(f"Первый: {first}, Второй: {second}, Остальные: {rest}")
            print(f"Весь список: {full_list}")
        case _:
            print("Не список")
            
process_data([10, 20, 30, 40, 50])
# Первый: 10, Второй: 20, Остальные: [30, 40, 50]
# Весь список: [10, 20, 30, 40, 50]
```

### Псевдонимы для словарей

```python
def print_dict(data):
    match data:
        case {"name": name, "age": age} as person:
            print(f"Name: {name}, Age: {age}")
            print(f"Весь словарь: {person}")
        case _:
            print("Неизвестный формат")
            
print_dict({"name": "Tom", "age": 30, "city": "Moscow"})
# Name: Tom, Age: 30
# Весь словарь: {'name': 'Tom', 'age': 30, 'city': 'Moscow'}
```
