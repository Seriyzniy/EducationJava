## Проверка типа объекта (`isinstance()`)

При работе с объектами бывает необходимо в зависимости от их типа выполнить те или иные операции. 

С помощью встроенной функции `isinstance()` мы можем проверить тип объекта:
```python
isinstance(object, type)
```

Первый параметр представляет объект, а **второй — тип, на принадлежность к которому выполняется проверка.** Если объект представляет указанный тип, функция возвращает `True`.

### Пример с иерархией классов

```python
class Person:
    def __init__(self, name):
        self.__name = name
        
    @property
    def name(self):
        return self.__name
        
    def do_nothing(self):
        print(f"{self.name} does nothing")
        
class Employee(Person):
    def work(self):
        print(f"{self.name} works")
        
class Student(Person):
    def study(self):
        print(f"{self.name} studies")
        
def act(person):
    if isinstance(person, Student):
        person.study()
    elif isinstance(person, Employee):
        person.work()
    elif isinstance(person, Person):
        person.do_nothing()
        
tom = Employee("Tom")
bob = Student("Bob")
sam = Person("Sam")
act(tom)    # Tom works
act(bob)    # Bob studies
act(sam)    # Sam does nothing
```

Здесь класс `Employee` определяет метод `work()`, а класс `Student` — метод `study()`. 

Функция `act` проверяет с помощью `isinstance`, представляет ли параметр `person` определённый тип, и в зависимости от результатов проверки обращается к соответствующему методу объекта.

## Проверка принадлежности классу (`issubclass()`)

Для проверки, **является ли один класс подклассом другого**, используется функция `issubclass()`:

```python
print(issubclass(Employee, Person))   # True
print(issubclass(Student, Person))    # True
print(issubclass(Person, Employee))   # False
print(issubclass(Employee, object))   # True (все классы наследуют от object)
```

## Сравнение `isinstance()` и `type()`

| Функция                | Описание                                                         | Пример                                                    |
| ---------------------- | ---------------------------------------------------------------- | --------------------------------------------------------- |
| `isinstance(obj, cls)` | Проверяет, является ли `obj` экземпляром `cls` или его подкласса | `isinstance(tom, Person)` → `True`                        |
| `type(obj) is cls`     | Проверяет точное соответствие типа (**без учёта наследования**)  | `type(tom) is Person` → `False` (если `tom` — `Employee`) |

```python
tom = Employee("Tom")

print(isinstance(tom, Person)) # True (Employee наследует от Person)

print(type(tom) is Person)       # False (точный тип — Employee)

print(type(tom) is Employee)     # True
```
