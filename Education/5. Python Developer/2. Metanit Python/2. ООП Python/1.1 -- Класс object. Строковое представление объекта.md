Начиная с 3-й версии в языке программирования Python **все классы неявно имеют один общий суперкласс** — `object`. Все классы по умолчанию наследуют его методы.

Одним из наиболее используемых методов класса `object` является метод **`__str__()`**. Когда необходимо получить строковое представление объекта или вывести объект в виде строки, Python вызывает именно этот метод. При определении класса хорошей практикой считается переопределение этого метода.

---

## Проблема: неинформативное строковое представление

Возьмём класс `Person` и выведем его строковое представление:

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def display_info(self):
        print(f"Name: {self.name}  Age: {self.age}")
tom = Person("Tom", 23)
print(tom)
```

При запуске программа выведет что-то наподобие:
```text
<__main__.Person object at 0x10a63dc00>
```

Это не очень информативная информация об объекте. Мы можем выйти из положения, определив в классе `Person` дополнительный метод, который выводит данные объекта — в примере выше это метод `display_info`.

---
## Решение: переопределение метода `__str__()`

Есть и другой выход — определить в классе `Person` метод `__str__()` (по два подчёркивания с каждой стороны):

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
    def display_info(self):
        print(self)
        # print(self.__str__())     # или так
        
    def __str__(self):
        return f"Name: {self.name}  Age: {self.age}"
        
tom = Person("Tom", 23)
print(tom)              # Name: Tom  Age: 23
tom.display_info()      # Name: Tom  Age: 23
```

Метод `__str__` должен возвращать строку. В данном случае мы возвращаем базовую информацию о человеке. Если нам потребуется использовать эту информацию в других методах класса, мы можем использовать выражение `self.__str__()`.

## Метод `__repr__()` — представление для разработчиков

В Python также существует метод **`__repr__()`**, который предназначен для предоставления **технического** строкового представления объекта, удобного для разработчиков и отладки.

### Различия между `__str__()` и `__repr__()`

|Характеристика|`__str__()`|`__repr__()`|
|---|---|---|
|**Назначение**|Для конечных пользователей (читаемое представление)|Для разработчиков (техническое представление)|
|**Вызов**|`print(obj)`, `str(obj)`|`repr(obj)`, в интерактивном режиме|
|**Цель**|Удобочитаемость|Однозначность, возможность восстановления объекта|
|**Если не определён**|Используется `__repr__()`|Возвращает `<класс объект по адресу>`|
|**Пример**|`"Name: Tom Age: 23"`|`"Person('Tom', 23)"`|

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
    def __str__(self):
        return f"Name: {self.name}  Age: {self.age}"
        
    def __repr__(self):
        return f"Person('{self.name}', {self.age})"
        
tom = Person("Tom", 23)
print(tom)           # Name: Tom  Age: 23     (__str__)
print(str(tom))      # Name: Tom  Age: 23     (__str__)
print(repr(tom))     # Person('Tom', 23)      (__repr__)
# В интерактивном режиме:
# >>> tom
# Person('Tom', 23)                           (__repr__)
```

## МЕТОДЫ КЛАССА object
### Основные методы класса `object
- **`__init__(self[, ...])`**  
Это конструктор объекта, который вызывается при создании экземпляра класса (операция `Class()`). Он инициализирует состояние создаваемого объекта. Реализация по умолчанию, унаследованная от `object`, просто ничего не делает, позволяя создавать экземпляры даже для пустых классов.

- **`__new__(cls[, ...])`**  
Это статический метод, который отвечает за **создание** нового экземпляра класса. Он вызывается **перед** `__init__`. В `object` он просто создаёт новый пустой объект. Обычно его переопределяют только в специализированных случаях, например, для реализации паттерна "Одиночка" (Singleton) или при работе с неизменяемыми типами.

- **`__str__(self)`**  
Вызывается функциями `str()` и `print()` для получения "неформального" или удобочитаемого строкового представления объекта. Реализация по умолчанию возвращает строку с именем класса и адресом в памяти (например, `<__main__.MyClass object at 0x...>`).

- **`__repr__(self)`**  
Предназначен для получения формального строкового представления объекта, которое обычно используется для отладки и должно быть максимально информативным и однозначным. Идеально, чтобы по этой строке можно было восстановить объект (вызов `eval(repr(obj))` создал бы его копию). Эталонная реализация в `object` похожа на `__str__`.

- **`__eq__(self, other)`**  
Определяет поведение оператора сравнения `==`. Реализация по умолчанию в `object` сравнивает **идентичность** объектов, то есть работает так же, как оператор `is`. Два разных объекта с одинаковыми атрибутами будут считаться неравными.

- **`__hash__(self)`**  
Возвращает хеш-значение объекта. Хеш используется для работы с множествами (`set`) и в качестве ключей словарей (`dict`). По умолчанию хеш объекта основан на его идентичности (как и в `__eq__`), поэтому для пользовательских классов требуется соблюдать правило: если два объекта равны (`__eq__` возвращает `True`), их хеши также должны быть равны. При переопределении `__eq__` следует переопределять и `__hash__`.

- **Методы сравнения (`__lt__`, `__le__`, `__gt__`, `__ge__`, `__ne__`)**  
Это "богатые" методы сравнения, которые определяют поведение операторов `<`, `<=`, `>`, `>=` и `!=` соответственно. В классе `object` эти методы не переопределены, и их вызов приведёт к ошибке, если вы явно не реализуете их в своём классе.

### Методы для работы с атрибутами

Эти методы позволяют перехватывать и контролировать доступ к атрибутам объекта. Они используются для динамической обработки, валидации, логирования и создания прокси-объектов.


- **`__getattr__(self, name)`**  
Вызывается **только если атрибут `name` не найден** обычным способом. Позволяет динамически обрабатывать отсутствующие атрибуты.

```python
class DynamicObject:
    def __getattr__(self, name):
        return f"Атрибут '{name}' не найден"
obj = DynamicObject()
print(obj.any_attr)  # Атрибут 'any_attr' не найден
```


- **`__getattribute__(self, name)`**  
Вызывается **всегда** при любой попытке получить атрибут `name` (даже если он существует). Используйте осторожно, чтобы избежать бесконечной рекурсии — внутри используйте `object.__getattribute__(self, name)`.
```python
class LoggerObject:
    def __getattribute__(self, name):
        print(f"Запрошен атрибут: {name}")
        return object.__getattribute__(self, name)
    def __init__(self):
        self.value = 42
obj = LoggerObject()
print(obj.value)
# Запрошен атрибут: value
# 42
```


- **`__setattr__(self, name, value)`**  
Вызывается **всегда** при попытке установить атрибут `name`. Используется для валидации и контроля присваиваний. Для реальной установки используйте `object.__setattr__(self, name, value)`.

```python
class ValidatedObject:
    def __setattr__(self, name, value):
        if name == "age" and value < 0:
            raise ValueError("Возраст не может быть отрицательным")
        object.__setattr__(self, name, value)
obj = ValidatedObject()
obj.age = 25      # OK
# obj.age = -5    # ValueError
```


- **`__delattr__(self, name)`**  
Вызывается при попытке удалить атрибут (`del obj.name`). Позволяет контролировать удаление атрибутов.

```python
class ProtectedObject:
    def __delattr__(self, name):
        if name == "secret":
            raise AttributeError("Нельзя удалить секретный атрибут")
        object.__delattr__(self, name)
obj = ProtectedObject()
obj.secret = 123
# del obj.secret  # AttributeError: Нельзя удалить секретный атрибут
```


- **`__dir__(self)`**  
Вызывается при вызове `dir(obj)`. Позволяет кастомизировать список атрибутов, которые отображаются для объекта.
```python
class CustomDir:
    def __dir__(self):
        return ["custom_attr1", "custom_attr2"]
    
obj = CustomDir()
print(dir(obj))  # ['custom_attr1', 'custom_attr2']
```

### Как узнать точный список методов

Самый простой и точный способ увидеть все методы класса `object` в вашей версии Python — использовать встроенную функцию `dir()`:

```python
print(dir(object))
# ['__class__', '__delattr__', '__dir__', '__doc__', '__eq__', '__format__', ...]
```
