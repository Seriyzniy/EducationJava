Множество (`set`) представляет набор, который хранит **только уникальные элементы**. 

Для определения множества используются **фигурные скобки**:

```python
users = {"Tom", "Bob", "Alice", "Tom"}
print(users)  # {'Alice', 'Bob', 'Tom'} — дубликат удалён
```

---
## Создание множества

### Из списка или кортежа (функция `set()`)
```python
people = ["Mike", "Bill", "Ted"]
users = set(people)
print(users)  # {'Mike', 'Bill', 'Ted'}
```

### Пустое множество
```python
users = set()  # Нельзя использовать {}, это создаст словарь!
```

### Длина множества
```python
users = {"Tom", "Bob", "Alice"}
print(len(users))  # 3
```

---
## Добавление элементов
```python
users = set()
users.add("Sam")
users.add("Tom")
users.add("Sam")  # не будет добавлен (дубликат)
print(users)  # {'Tom', 'Sam'}
```

---
## Удаление элементов

### `remove()` — удаляет элемент, ошибка если отсутствует

```python
users = {"Tom", "Bob", "Alice"}
if "Tom" in users:
    users.remove("Tom")
```
### `discard()` — удаляет элемент, ошибки при отсутствии

```python
users.discard("Tim")  # элемент отсутствует — ничего не происходит

users.discard("Tom")  # элемент есть — удаляется
```

### `clear()` — удаляет все элементы
```python
users.clear()
```
---
## Перебор множества

```python
users = {"Tom", "Bob", "Alice"}
for user in users:
    print(user)
```

> [!NOTE] Порядок не гарантируется  
> Множества не сохраняют порядок элементов.

---
## Операции с множествами

### Копирование
```python
users = {"Tom", "Bob", "Alice"}
students = users.copy()
```

### Объединение (`union` или `|`)
```python
users = {"Tom", "Bob", "Alice"}
users2 = {"Sam", "Kate", "Bob"}
users3 = users.union(users2)

# или
users3 = users | users2
print(users3)  # {'Tom', 'Bob', 'Alice', 'Sam', 'Kate'}
```

### Пересечение (`intersection` или `&`)
```python
users = {"Tom", "Bob", "Alice"}
users2 = {"Sam", "Kate", "Bob"}

users3 = users.intersection(users2)
# или
users3 = users & users2
print(users3)  # {'Bob'}
```

### Разность (`difference` или `-`)
```python
users = {"Tom", "Bob", "Alice"}
users2 = {"Sam", "Kate", "Bob"}
users3 = users.difference(users2)
# или
users3 = users - users2
print(users3)  # {'Tom', 'Alice'}
```

### Симметрическая разность (`symmetric_difference` или `^`)

Возвращает **все** элементы обоих множеств, **кроме общих**:
```python
users = {"Tom", "Bob", "Alice"}
users2 = {"Sam", "Kate", "Bob"}

users3 = users.symmetric_difference(users2)

# или
users3 = users ^ users2
print(users3)  # {'Tom', 'Alice', 'Sam', 'Kate'}
```

## Отношения между множествами

### `issubset()` — является ли подмножеством
```python
users = {"Tom", "Bob", "Alice"}
superusers = {"Sam", "Tom", "Bob", "Alice", "Greg"}
print(users.issubset(superusers))   # True
print(superusers.issubset(users))   # False
```

### `issuperset()` — является ли надмножеством
```python
print(users.issuperset(superusers))   # False
print(superusers.issuperset(users))   # True
```

---
## Frozenset (неизменяемое множество)

`frozenset` — это неизменяемая версия множества. После создания его нельзя изменить.

```python
users = frozenset({"Tom", "Bob", "Alice"})
```

### Поддерживаемые операции

|Операция|Описание|
|---|---|
|`len(s)`|Количество элементов|
|`x in s`|Проверка наличия|
|`x not in s`|Проверка отсутствия|
|`s.issubset(t)`|Подмножество|
|`s.issuperset(t)`|Надмножество|
|`s.union(t)`|Объединение|
|`s.intersection(t)`|Пересечение|
|`s.difference(t)`|Разность|
|`s.copy()`|Копия|

> [!WARNING] frozenset нельзя изменять  
> Методы `add()`, `remove()`, `discard()`, `clear()` отсутствуют.

---
## Сравнение операций

|Операция|Метод|Оператор|
|---|---|---|
|Объединение|`set.union(other)`|`\|`|
|Пересечение|`set.intersection(other)`|`&`|
|Разность|`set.difference(other)`|`-`|
|Симметрическая разность|`set.symmetric_difference(other)`|`^`|
|Подмножество|`set.issubset(other)`|`<=`|
|Надмножество|`set.issuperset(other)`|`>=`|

## Основные методы множеств

|Метод|Описание|
|---|---|
|`add(x)`|Добавляет элемент|
|`remove(x)`|Удаляет элемент (ошибка если нет)|
|`discard(x)`|Удаляет элемент (без ошибки)|
|`clear()`|Удаляет все элементы|
|`copy()`|Копия множества|
|`union(other)`|Объединение|
|`intersection(other)`|Пересечение|
|`difference(other)`|Разность|
|`symmetric_difference(other)`|Симметрическая разность|
|`issubset(other)`|Проверка на подмножество|
|`issuperset(other)`|Проверка на надмножество|

## Пример: уникальные значения

```python
# Удаление дубликатов из списка
numbers = [1, 2, 3, 2, 1, 4, 5, 4]
unique = set(numbers)
print(unique)  # {1, 2, 3, 4, 5}
print(list(unique))  # [1, 2, 3, 4, 5] (порядок может быть другим)

# Общие элементы в двух списках
list1 = [1, 2, 3, 4, 5]
list2 = [4, 5, 6, 7, 8]
common = set(list1) & set(list2)
print(common)  # {4, 5}
```
