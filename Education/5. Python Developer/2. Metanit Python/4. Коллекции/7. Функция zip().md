Встроенная функция `zip()` в Python позволяет объединить элементы из нескольких коллекций (списков, словарей, кортежей, строк) в один набор кортежей:

```python
zip(*iterables)
```

**Принцип работы:**
- Возвращает итератор на набор кортежей
    
- **1-й кортеж содержит 1-е элементы** из каждой коллекции
    
- **2-й кортеж содержит 2-е элементы** из каждой коллекции
    
- И так далее
    
- **Останавливается** на самой короткой коллекции


---
## Простой пример

```python
names = ["Tom", "Bob", "Sam"]
ages = [41, 46, 35]

for user in zip(names, ages):
    print(user)
# ('Tom', 41)
# ('Bob', 46)
# ('Sam', 35)
```

### Сразу в переменные
```python
for name, age in zip(names, ages):
    print(f"Name: {name}  Age: {age}")
# Name: Tom  Age: 41
# Name: Bob  Age: 46
# Name: Sam  Age: 35
```

---
## Особенности `zip()`

### Результат — итератор (zip-объект), а не список
```python
users = zip(names, ages)
print(users)  # <zip object at 0x...>
```

### Без аргументов — пустой итератор
```python
for tup in zip():
    print(tup)  # ничего не выведет
```

### С одной коллекцией — кортежи из одного элемента
```python
for tup in zip([5, 6, 7]):
    print(tup)
# (5,)
# (6,)
# (7,)
```

### Разная длина коллекций — останавливается на самой короткой

```python
list1 = [1, 2, 3]
list2 = ["a", "b"]
for tup in zip(list1, list2):
    print(tup)
# (1, 'a')
# (2, 'b')   # (3, 'c') не будет, т.к. list2 короче
```

## Практические примеры

### 1. Объединение списков в список кортежей

```python
names = ["Tom", "Bob", "Sam"]
ages = [41, 46, 35]

users = list(zip(names, ages))

print(users)  # [('Tom', 41), ('Bob', 46), ('Sam', 35)]
```

### 2. Объединение трёх и более списков

```python
names = ["Tom", "Bob", "Sam"]
ages = [41, 46, 35]
companies = ["Sber", "VK", "Yandex"]

users = list(zip(names, ages, companies))

print(users)
# [('Tom', 41, 'Sber'), ('Bob', 46, 'VK'), ('Sam', 35, 'Yandex')]
```

### 3. Разложение списка кортежей (распаковка)
```python
users = [("Tom", 41), ("Bob", 46), ("Sam", 35)]
names, ages = zip(*users)

print(names)  # ('Tom', 'Bob', 'Sam')
print(ages)   # (41, 46, 35)
```

### 4. Создание словаря из двух списков
```python
keys = ["name", "age", "city"]
values = ["Tom", 41, "Volgograd"]

user = dict(zip(keys, values))

print(user)  # {'name': 'Tom', 'age': 41, 'city': 'Volgograd'}
```

### 5. Одновременный перебор нескольких списков
```python
names = ["Tom", "Bob", "Sam"]
ages = [41, 46, 35]

for name, age in zip(names, ages):
    print(f"Name: {name}  Age: {age}")
```

### 6. Сравнение элементов двух списков
```python
list1 = [1, 2, 3]
list2 = [1, 4, 3]
comparison = [a == b for a, b in zip(list1, list2)]

print(comparison)  # [True, False, True]
```

### 7. Работа с диапазонами
```python
numbers = range(1, 4)
letters = ["a", "b", "c"]

result = list(zip(numbers, letters))

print(result)  # [(1, 'a'), (2, 'b'), (3, 'c')]
```

---
## Итог
```python
zip(iterable1, iterable2, ...)
```

|Особенность|Описание|
|---|---|
|**Возвращает**|Итератор кортежей|
|**Длина результата**|= длине самой короткой коллекции|
|**Преобразование**|`list(zip(...))` — список кортежей; `dict(zip(...))` — словарь|
|**Распаковка**|`zip(*list_of_tuples)` — разложение на отдельные кортежи|
