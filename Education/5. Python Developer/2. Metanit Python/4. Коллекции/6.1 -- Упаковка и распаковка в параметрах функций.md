Одной из распространённых сфер, где применяются упаковка и распаковка — это параметры функций. В определениях различных функций нередко можно увидеть параметры `*args` и `**kwargs`.

> [!NOTE] Термины `args` и `kwargs` — это соглашения по программированию на Python  
> Вместо них можно использовать любые имена. `*args` — позиционные аргументы, `**kwargs` — именованные (ключевые) аргументы.

---
## `*args` — упаковка позиционных аргументов

Оператор `*` позволяет передать в функцию несколько значений, и все они будут упакованы в **кортеж**:

```python
def fun(*args):
    print(args[0])   # обращение к первому элементу
    print(args)      # весь кортеж
    
fun("Python", "C++", "Java", "C#")
# Python
# ('Python', 'C++', 'Java', 'C#')
```

### Пример: функция с переменным количеством аргументов
```python
def sum(*args):
    result = 0
    for arg in args:
        result += arg
    return result
    
print(sum(1, 2, 3))          # 6
print(sum(1, 2, 3, 4))       # 10
print(sum(1, 2, 3, 4, 5))    # 15
```

---
## `**kwargs` — упаковка именованных аргументов

Оператор `**` упаковывает аргументы, переданные по имени, в **словарь**. Имена параметров служат ключами:

```python
def fun(**kwargs):
    print(kwargs)   # выводим словарь
    
fun(name="Tom", age="38", company="Google")
# {'name': 'Tom', 'age': '38', 'company': 'Google'}

fun(language="Python", version="3.11")
# {'language': 'Python', 'version': '3.11'}
```

### Перебор ключей и значений

```python
def fun(**kwargs):
    for key in kwargs:
        print(f"{key} = {kwargs[key]}")
        
fun(name="Tom", age="38", company="Google")
# name = Tom
# age = 38
# company = Google
```

## Распаковка аргументов

Операторы `*` и `**` могут использоваться не только для упаковки, но и для **распаковки** аргументов при вызове функции.

### `*` — распаковка кортежа/списка в позиционные аргументы

**Проблема без распаковки:**
```python
def sum(*args):
    result = 0
    for arg in args:
        result += arg
    return result
numbers = (1, 2, 3, 4, 5)
print(sum(numbers))  # TypeError! Кортеж передаётся как один элемент
```

**Решение с распаковкой:**
```python
numbers = (1, 2, 3, 4, 5)
print(sum(*numbers))  # 15 — элементы кортежа распакованы
```

---
### Распаковка кортежа в параметры функции
```python
def print_person(name, age, company):
    print(f"Name: {name}, Age: {age}, Company: {company}")
    
person = ("Tom", 38, "Google")
print_person(*person)  # Name: Tom, Age: 38, Company: Google
```

---
### `**` — распаковка словаря В ИМЕНОВАННЫЕ АРГУМЕНТЫ

```python
def print_person(name, age, company):
    print(f"Name: {name}, Age: {age}, Company: {company}")
tom = {"name": "Tom", "age": 38, "company": "Google"}
print_person(**tom)  # Name: Tom, Age: 38, Company: Google
```

Ключи словаря должны совпадать с именами параметров функции.

## Сочетание параметров

`*args` и `**kwargs` могут использоваться вместе с обычными параметрами:

```python
def sum(num1, num2, *nums):
    result = num1 + num2
    for n in nums:
        result += n
    return result
print(sum(1, 2, 3))       # 6  (1+2+3)
print(sum(1, 2, 3, 4))    # 10 (1+2+3+4)
```

---
## Полный порядок параметров

```python
def func(a, b, c=10, *args, d=20, **kwargs):
    print(f"a={a}, b={b}, c={c}")
    print(f"args={args}")
    print(f"d={d}")
    print(f"kwargs={kwargs}")
    
func(1, 2, 3, 4, 5, d=30, name="Tom", age=25)
# a=1, b=2, c=3
# args=(4, 5)
# d=30
# kwargs={'name': 'Tom', 'age': 25}
```

**Порядок параметров в сигнатуре функции:**
1. Обязательные параметры (`a`, `b`)
    
2. Необязательные параметры со значениями по умолчанию (`c=10`)
    
3. `*args` — сбор всех лишних позиционных аргументов
    
4. Именованные параметры (например, `d=20`)
    
5. `**kwargs` — сбор всех лишних именованных аргументов

## Итог

|Конструкция|Назначение|Пример|
|---|---|---|
|`*args` в определении|Упаковка позиционных аргументов в кортеж|`def func(*args):`|
|`**kwargs` в определении|Упаковка именованных аргументов в словарь|`def func(**kwargs):`|
|`*iterable` при вызове|Распаковка коллекции в позиционные аргументы|`func(*[1, 2, 3])`|
|`**dict` при вызове|Распаковка словаря в именованные аргументы|`func(**{'a': 1, 'b': 2})`|
