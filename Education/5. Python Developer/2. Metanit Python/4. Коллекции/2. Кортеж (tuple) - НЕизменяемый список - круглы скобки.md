Кортеж (`tuple`) представляет последовательность элементов, которая во многом похожа на список, за тем исключением, что кортеж является **неизменяемым** (`immutable`) типом. 

Мы не можем добавлять, удалять или изменять элементы в кортеже.

---
## Создание кортежа

Для создания кортежа используются **круглые скобки**, внутри которых через запятую перечисляются элементы:

```python
tom = ("Tom", 23)
print(tom)  # ('Tom', 23)
```

Можно опустить скобки — Python автоматически создаст кортеж:
```python
tom = "Tom", 23
print(tom)  # ('Tom', 23)
```

Кортеж из одного элемента требует запятую после элемента:
```python
tom = ("Tom",)
print(tom)  # ('Tom',)
```

Если запятую не поставить, это будет просто строка в скобках:
```python
tom = ("Tom")
print(type(tom))  # <class 'str'>
```

### Создание кортежа из других коллекций
```python
data = ["Tom", 37, "Google"]
tom = tuple(data)
print(tom)  # ('Tom', 37, 'Google')
```

### Длина кортежа
```python
tom = ("Tom", 37, "Google")
print(len(tom))  # 3
```

---
## Обращение к элементам кортежа

Доступ к элементам осуществляется по индексу (как в списке):

```python
tom = ("Tom", 37, "Google", "software developer")
print(tom[0])   # Tom
print(tom[1])   # 37
print(tom[-1])  # software developer
```

> [!WARNING] Кортеж неизменяем  
> Следующая запись вызовет ошибку:
> 
> ```python
> tom[1] = "Tim"  
> # TypeError: 'tuple' object does not support item assignment
> ```

---
## Распаковка кортежа

Кортеж можно разложить на отдельные переменные:

```python
name, age, company, position = ("Tom", 37, "Google", "software developer")

print(name)      # Tom
print(age)       # 37
print(position)  # software developer
print(company)   # Google
```

**Количество переменных должно совпадать с количеством элементов**:
```python
name, age = ("Tom", 37, "Google")  
# ValueError: too many values to unpack
```

Если нужно пропустить некоторые значения, используется `_`:
```python
name, _, company, _ = ("Tom", 37, "Google", "developer")
print(name)     # Tom
print(company)  # Google
```

---
## Срезы (получение подкортежа)

```python
tom = ("Tom", 37, "Google", "software developer")
print(tom[1:3])    # (37, 'Google')
print(tom[:3])     # ('Tom', 37, 'Google')
print(tom[1:])     # (37, 'Google', 'software developer')
print(tom[:-1])    # ('Tom', 37, 'Google')
```

## Кортеж как параметр и результат функций

### Возврат нескольких значений (неявный кортеж)

```python
def get_user():
    name = "Tom"
    age = 22
    company = "Google"
    return name, age, company  # автоматически упаковывается в кортеж
    
user = get_user()
print(user)  # ('Tom', 22, 'Google')
```

### Распаковка кортежа в аргументы функции (`*`)
```python
def print_person(name, age, company):
    print(f"Name: {name}  Age: {age}  Company: {company}")
    
tom = ("Tom", 22)
print_person(*tom, "Microsoft")  # Name: Tom  Age: 22  Company: Microsoft

bob = ("Bob", 41, "Apple")
print_person(*bob)  # Name: Bob  Age: 41  Company: Apple
```

---
## Перебор кортежа

### Цикл `for`
```python
tom = ("Tom", 22, "Google")
for item in tom:
    print(item)
```

### Цикл `while`
```python
tom = ("Tom", 22, "Google")
i = 0

while i < len(tom):
    print(tom[i])
    i += 1
```

---
## Проверка наличия элемента (`in`)
```python
user = ("Tom", 22, "Google")
if "Tom" in user:
    print("Пользователя зовут Tom")
else:
    print("Пользователь имеет другое имя")
```

---
## Сравнение списков и кортежей

|Характеристика|Список (`list`)|Кортеж (`tuple`)|
|---|---|---|
|**Изменяемость**|Изменяемый (`mutable`)|Неизменяемый (`immutable`)|
|**Синтаксис**|`[1, 2, 3]`|`(1, 2, 3)`|
|**Скорость**|Медленнее|Быстрее (меньше накладных расходов)|
|**Память**|Больше|Меньше|
|**Использование**|Динамические коллекции|Фиксированные структуры|
|**Методы**|Много (`append`, `remove`, `sort` и т.д.)|Только `count`, `index`|

## Где использовать кортежи

```python
# 1. Ключи в словарях (неизменяемы, в отличие от списков)
coordinates = {}
coordinates[(10, 20)] = "Point A"  # OK — кортеж можно использовать как ключ
# coordinates[[10, 20]] = "Point B" # Ошибка — список нельзя

# 2. Возврат нескольких значений из функции
def get_user():
    return "Tom", 25, "Google"

# 3. Хранение фиксированных данных (дни недели, месяцы)
DAYS = ("Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday")

# 4. Использование в качестве аргументов с *
def add(a, b):
    return a + b
nums = (5, 3)
print(add(*nums))  # 8

# 5. NamedTuple (с именованными полями)
from collections import namedtuple

Person = namedtuple('Person', ['name', 'age', 'city'])
tom = Person("Tom", 25, "Moscow")
print(tom.name)  # Tom
print(tom.age)   # 25
```
