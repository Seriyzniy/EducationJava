**Распаковка** (unpacking, также называемая деструктуризацией) — это разложение коллекции (кортежа, списка и т.д.) на отдельные значения.

---
## Множественное присваивание (распаковка)
```python
x, y = 1, 2
print(x)  # 1
print(y)  # 2

# То же самое с кортежем
x, y = (1, 2)
print(x)  # 1
print(y)  # 2
```

### Распаковка кортежей и списков
```python
# Кортеж
name, age, company = ("Tom", 38, "Google")
print(name)     # Tom
print(age)      # 38
print(company)  # Google

# Список
people = ["Tom", "Bob", "Sam"]
first, second, third = people
print(first)   # Tom
print(second)  # Bob
print(third)   # Sam
```

### Распаковка словарей (ключи)
```python
dictionary = {"red": "красный", "blue": "синий", "green": "зеленый"}
r, b, g = dictionary
print(r)  # red
print(b)  # blue
print(g)  # green
print(dictionary[g])  # зеленый
```

## Распаковка в циклах
```python
people = [
    ("Tom", 38, "Google"),
    ("Bob", 42, "Microsoft"),
    ("Sam", 29, "JetBrains")
]
for name, age, company in people:
    print(f"Name: {name}, Age: {age}, Company: {company}")
```

### Функция `enumerate()`
```python
people = ["Tom", "Bob", "Sam"]
for index, name in enumerate(people):
    print(f"{index}.{name}")
# 0.Tom
# 1.Bob
# 2.Sam
```

## Игнорирование значений (`_`)
```python
person = ("Tom", 38, "Google")
name, _, company = person
print(name)     # Tom
print(company)  # Google
print(_)        # 38 (но обычно так не делают)
```

## Упаковка значений и оператор `*` (НА ПЕРЕМЕННОЙ)

Оператор `*` упаковывает значения в коллекцию:
```python
num1, num2, num3 = 1, 2, 3

*numbers, = num1, num2, num3
print(numbers)  # [1, 2, 3]
```

### Сбор оставшихся элементов
```python
head, *tail = [1, 2, 3, 4, 5]
print(head)  # 1
print(tail)  # [2, 3, 4, 5]

*head, tail = [1, 2, 3, 4, 5]
print(head)  # [1, 2, 3, 4]
print(tail)  # 5

head, *middle, tail = [1, 2, 3, 4, 5]
print(head)    # 1
print(middle)  # [2, 3, 4]
print(tail)    # 5

first, second, *other = [1, 2, 3, 4, 5]
print(first)   # 1
print(second)  # 2
print(other)   # [3, 4, 5]
```

### Выборочные элементы с игнорированием
```python
first, _, third, *_, last = [1, 2, 3, 4, 5, 6, 7, 8]
print(first)  # 1
print(third)  # 3
print(last)   # 8
```

### Упаковка ключей словаря
```python
red, *other, green = {"red": "красный", "blue": "синий", "yellow": "желтый", "green": "зеленый"}
print(red)    # red
print(green)  # green
print(other)  # ['blue', 'yellow']
```

## Распаковка с операторами `*` и `**` (НА ЗНАЧЕНИЯХ СПРАВА ОТ ПЕРЕМЕННОЙ)

### `*` — распаковка списков, кортежей, строк, множеств
```python
nums1 = [1, 2, 3]
nums2 = (4, 5, 6)
nums3 = [*nums1, *nums2]
print(nums3)  # [1, 2, 3, 4, 5, 6]

# Распаковка строки
chars = [*"hello"]
print(chars)  # ['h', 'e', 'l', 'l', 'o']
```

### `**` — распаковка словарей
```python
dictionary1 = {"red": "красный", "blue": "синий"}
dictionary2 = {"green": "зеленый", "yellow": "желтый"}
dictionary3 = {**dictionary1, **dictionary2}

print(dictionary3)
# {'red': 'красный', 'blue': 'синий', 'green': 'зеленый', 'yellow': 'желтый'}
```

## Итог

|Оператор|Назначение|Пример|
|---|---|---|
|`=` (множественное присваивание)|Распаковка коллекции в переменные|`a, b = [1, 2]`|
|`*` (в присваивании)|Упаковка оставшихся элементов в список|`head, *tail = [1, 2, 3]`|
|`*` (при создании коллекции)|Распаковка элементов в новую коллекцию|`[*list1, *list2]`|
|`**` (при создании словаря)|Распаковка словаря в новый словарь|`{**dict1, **dict2}`|
|`*` (при вызове функции)|Распаковка коллекции в позиционные аргументы|`func(*tuple)`|
|`**` (при вызове функции)|Распаковка словаря в именованные аргументы|`func(**dict)`|
|`_`|Игнорирование значения|`a, _, c = (1, 2, 3)`|
