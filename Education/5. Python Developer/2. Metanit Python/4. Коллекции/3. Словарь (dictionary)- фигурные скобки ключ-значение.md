Словарь (`dict`) в языке Python хранит коллекцию элементов, где каждый элемент имеет **уникальный ключ** и ассоциированное с ним некоторое **значение**.

---
## Определение словаря
Синтаксис: в фигурных скобках через запятую перечисляются пары `ключ: значение`.
```python
users = {1: "Tom", 2: "Bob", 3: "Bill"}
emails = {"tom@gmail.com": "Tom", "bob@gmail.com": "Bob"}
objects = {1: "Tom", "2": True, 3: 100.6}
```

### Пустой словарь
```python
objects = {}
objects = dict()
```

---
## Преобразование списков и кортежей в словарь

```python
# Из списка списков
users_list = [
    ["+111123455", "Tom"],
    ["+384767557", "Bob"],
    ["+958758767", "Alice"]
]
users_dict = dict(users_list)
print(users_dict)  # {'+111123455': 'Tom', '+384767557': 'Bob', '+958758767': 'Alice'}

# Из кортежа кортежей
users_tuple = (
    ("+111123455", "Tom"),
    ("+384767557", "Bob")
)
users_dict = dict(users_tuple)
```

## Получение и изменение элементов

### Доступ по ключу
```python
users = {
    "+11111111": "Tom",
    "+33333333": "Bob",
    "+55555555": "Alice"
}
print(users["+11111111"])  # Tom
users["+33333333"] = "Bob Smith"  # изменение
users["+44444444"] = "Sam"  # добавление (если ключа нет)
```

> [!WARNING] Ошибка при отсутствии ключа  
> Обращение к несуществующему ключу вызывает `KeyError`.

### Проверка наличия ключа (`in`)

```python
key = "+44444444"
if key in users:
    print(users[key])
else:
    print("Элемент не найден")
```

### Метод `get()` (безопасное получение)
```python
user1 = users.get("+55555555")           # Alice
user2 = users.get("+33333333", "Unknown")  # Bob
user3 = users.get("+44444444", "Unknown")  # Unknown
```

---
## Удаление элементов

### `del`
```python
del users["+55555555"]
```

### `pop()` — удаляет и возвращает значение
```python
user = users.pop("+55555555")  # Alice
user = users.pop("+44444444", "Unknown")  # Unknown (без ошибки)
```

### `clear()` — удаляет все элементы
```python
users.clear()
```

---
## Копирование и объединение

### `copy()` — копия словаря
```python
users = {"+1111111": "Tom", "+3333333": "Bob"}
students = users.copy()
```

### `update()` — объединение словарей
```python
users = {"+1111111": "Tom", "+3333333": "Bob"}
users2 = {"+2222222": "Sam", "+6666666": "Kate"}

users.update(users2)  # добавляем элементы из users2 в users
print(users)
# {'+1111111': 'Tom', '+3333333': 'Bob', '+2222222': 'Sam', '+6666666': 'Kate'}
```

### Объединение с сохранением исходных словарей
```python
users3 = users.copy()
users3.update(users2)
```

---
## Перебор словаря

### Перебор ключей
```python
for key in users:
    print(f"Phone: {key}  User: {users[key]}")
```

### Перебор ключей и значений через `items()`
```python
for key, value in users.items():
    print(f"Phone: {key}  User: {value}")
```

### Перебор только ключей (`keys()`)
```python
for key in users.keys():
    print(key)
```

### Перебор только значений (`values()`)
```python
for value in users.values():
    print(value)
```

## Комплексные словари (вложенные)

Словари могут содержать другие словари, списки и любые другие объекты:
```python
users = {
    "Tom": {
        "phone": "+971478745",
        "email": "tom12@gmail.com"
    },
    "Bob": {
        "phone": "+876390444",
        "email": "bob@gmail.com",
        "skype": "bob123"
    }
}
```

### Доступ к вложенным элементам
```python
print(users["Tom"]["email"])           # tom12@gmail.com
users["Tom"]["email"] = "supertom@gmail.com"
```

### Безопасный доступ во вложенном словаре
```python
# Проверка через in
if "skype" in users["Tom"]:
    print(users["Tom"]["skype"])
else:
    print("skype is not found")
    
# Через get()
tom_skype = users["Tom"].get("skype", "Undefined")
print(tom_skype)  # Undefined
```

## Основные методы словарей

|Метод|Описание|
|---|---|
|`dict[key]`|Получение значения по ключу (ошибка если ключа нет)|
|`dict.get(key, default)`|Получение значения (None или default если ключа нет)|
|`dict[key] = value`|Добавление или изменение элемента|
|`del dict[key]`|Удаление элемента по ключу|
|`dict.pop(key, default)`|Удаление и возврат значения|
|`dict.clear()`|Очистка словаря|
|`dict.copy()`|Копия словаря|
|`dict.update(other_dict)`|Объединение словарей|
|`dict.items()`|Возвращает пары (ключ, значение)|
|`dict.keys()`|Возвращает все ключи|
|`dict.values()`|Возвращает все значения|
|`key in dict`|Проверка наличия ключа|
|`len(dict)`|Количество элементов|

## Пример: использование словарей

```python
# Подсчёт частоты слов
text = "apple banana apple orange banana apple"
words = text.split()

counts = {}
for word in words:
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1
print(counts)  # {'apple': 3, 'banana': 2, 'orange': 1}

# Более короткий вариант через get()
for word in words:
    counts[word] = counts.get(word, 0) + 1
```
