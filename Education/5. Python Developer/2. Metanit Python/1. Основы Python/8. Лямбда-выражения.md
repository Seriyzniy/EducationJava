## Лямбда-выражения

Лямбда-выражения в языке Python представляют небольшие **анонимные функции**, которые определяются с помощью оператора `lambda`. Формальное определение:

```python
lambda [параметры] : инструкция
```

> [!NOTE] Анонимные функции  
> Лямбда-выражения не имеют имени, как обычные функции, определенные через `def`. 
> 
> Они существуют как объекты, которые можно присвоить переменной, передать в другую функцию или вернуть из функции.

---
### Базовый синтаксис

Определим простейшее лямбда-выражение:

```python
message = lambda: print("hello")
message()   # hello
```

Здесь лямбда-выражение присваивается переменной `message`. Оно не имеет параметров, ничего не возвращает и просто выводит строку "hello" на консоль. Через переменную `message` мы можем вызвать это лямбда-выражение как обычную функцию. Фактически оно аналогично следующей функции:

```python
def message():
    print("hello")
```

---
### Лямбда с параметрами

Если лямбда-выражение имеет параметры, они определяются после ключевого слова `lambda`. Если лямбда-выражение возвращает результат, он указывается после двоеточия:

```python
square = lambda n: n * n
print(square(4))    # 16
print(square(5))    # 25
```
В данном случае лямбда-выражение принимает один параметр - `n`. Справа от двоеточия идет возвращаемое значение - `n * n`. Это лямбда-выражение аналогично следующей функции:

```python
def square2(n):
    return n * n
```

Аналогичным образом можно создавать лямбда-выражения с несколькими параметрами:

```python
sum = lambda a, b: a + b
print(sum(4, 5))    # 9
print(sum(5, 6))    # 11
```
---
### Ограничения лямбда-выражений

> [!WARNING] Лямбда-выражения ограничены одним выражением  
> В лямбда-выражении можно указать **только одно выражение**. Нельзя использовать блоки с несколькими инструкциями, циклы, условные конструкции `if/elif/else` (кроме тернарного оператора) и т.д.

```python
# ✅ Так можно
is_even = lambda x: x % 2 == 0

# ✅ Тернарный оператор тоже работает
abs_value = lambda x: x if x >= 0 else -x

# ❌ Так НЕЛЬЗЯ — несколько инструкций
# lambda x: x = x + 1; return x  # Ошибка!

# ❌ Нельзя использовать if/elif/else в классическом виде
# lambda x: if x > 0: return x  # Ошибка!
```

---
### Использование в качестве параметра функции

Лямбда-выражения особенно удобны, когда нужно передать функцию в качестве параметра:

```python
def do_operation(a, b, operation):
    result = operation(a, b)
    print(f"result = {result}")
    
do_operation(5, 4, lambda a, b: a + b)  # result = 9
do_operation(5, 4, lambda a, b: a * b)  # result = 20
do_operation(5, 4, lambda a, b: a - b)  # result = 1
```

В данном случае нам нет необходимости определять отдельные функции через `def`, чтобы передать их в качестве параметра.

---
### Возвращение лямбда-выражений из функций

Лямбда-выражения можно возвращать из других функций:

```python
def select_operation(choice):
    if choice == 1:
        return lambda a, b: a + b
    elif choice == 2:
        return lambda a, b: a - b
    else:
        return lambda a, b: a * b
        
operation = select_operation(1)   # operation = sum
print(operation(10, 6))           # 16

operation = select_operation(2)   # operation = subtract
print(operation(10, 6))           # 4

operation = select_operation(3)   # operation = multiply
print(operation(10, 6))           # 60
```

### Практическое применение: сортировка

Одно из самых частых применений лямбда-выражений — сортировка данных:
```python
# Сортировка списка чисел
numbers = [3, 1, 4, 1, 5, 9, 2]
sorted_numbers = sorted(numbers, key=lambda x: x)
print(sorted_numbers)  # [1, 1, 2, 3, 4, 5, 9]

# Сортировка списка строк по длине
words = ["apple", "kiwi", "banana", "cherry"]
sorted_words = sorted(words, key=lambda word: len(word))
print(sorted_words)  # ['kiwi', 'apple', 'cherry', 'banana']

# Сортировка словаря по значению
data = {"Alice": 30, "Bob": 25, "Charlie": 35}
sorted_by_age = sorted(data.items(), key=lambda item: item[1])
print(sorted_by_age)  # [('Bob', 25), ('Alice', 30), ('Charlie', 35)]

# Сортировка списка словарей
people = [
    {"name": "Tom", "age": 30},
    {"name": "Alice", "age": 25},
    {"name": "Bob", "age": 35}
]
sorted_people = sorted(
	people, 
	key=lambda person: person["age"])
	
print(sorted_people)
# [{'name': 'Alice', 'age': 25}, {'name': 'Tom', 'age': 30}, {'name': 'Bob', 'age': 35}]
```
