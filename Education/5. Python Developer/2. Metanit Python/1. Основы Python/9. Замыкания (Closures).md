Замыкание (closure) представляет функцию, которая запоминает свое лексическое окружение даже в том случае, когда она выполняется вне своей области видимости.

---
### Компоненты замыкания

Технически замыкание включает три компонента:

1. **Внешняя функция**, которая определяет некоторую область видимости и в которой определены некоторые переменные и параметры — лексическое окружение
    
2. **Переменные и параметры** (лексическое окружение), которые определены во внешней функции
    
3. **Вложенная функция**, которая использует переменные и параметры внешней функции

---
### Простой пример замыкания

Для определения замыканий в Python применяются локальные функции:

```python
def outer():        # внешняя функция
    n = 5           # лексическое окружение - локальная переменная
    def inner():    # локальная функция
        nonlocal n
        n += 1      # операции с лексическим окружением
        print(n)
        
    return inner
fn = outer()        # fn = inner, так как outer возвращает функцию inner
# вызываем внутреннюю функцию inner
fn()    # 6
fn()    # 7
fn()    # 8
```

**Как это работает:**

1. Функция `outer()` определяет локальную переменную `n` — это лексическое окружение для внутренней функции.
    
2. Внутри `outer()` определена локальная функция `inner()`, которая обращается к своему лексическому окружению — переменной `n`, увеличивает её значение и выводит на консоль.
    
3. Локальная функция возвращается функцией `outer()`.
    
4. В программе вызываем `outer()` и получаем в переменную `fn` локальную функцию `inner` вместе с её окружением.
 

Переменная `fn` и представляет собой **замыкание**, объединяющее две вещи: функцию и окружение, в котором она была создана. Несмотря на то, что мы вызываем локальную функцию вне её окружающей функции, она запомнила своё лексическое окружение и может к нему обращаться и изменять его.

---
### Замыкания с параметрами

Кроме внешних переменных, к лексическому окружению также относятся параметры окружающей функции:

```python
def multiply(n):
    def inner(m):
        return n * m
    return inner
    
fn = multiply(5) # ПУНКТ 1

print(fn(5))    # 25 (5 из ПУНКТ 1, и 5 из текущего параметра)
print(fn(6))    # 30 (5 из ПУНКТ 1, и 6 из текущего параметра)
print(fn(7))    # 35 (5 из ПУНКТ 1, и 7 из текущего параметра)
```

Здесь внешняя функция `multiply()` возвращает локальную функцию `inner`, которая запоминает окружение, в котором она была создана — в частности, значение параметра `n`. Локальная функция принимает свой параметр `m` и возвращает произведение `n` и `m`.

При вызове `multiply(5)` переменная `fn` получает локальную функцию `inner` с лексическим окружением, где `n = 5`. При вызове `fn(6)` число 6 передаётся параметру `m`, и функция возвращает `5 * 6 = 30`.

---
### Замыкания через лямбда-выражения

Тот же код можно сократить с помощью лямбда-выражений:

```python
def multiply(n):
    return lambda m: n * m
fn = multiply(5)
print(fn(5))    # 25
print(fn(6))    # 30
print(fn(7))    # 35
```

Лямбда-функция также захватывает переменную `n` из лексического окружения.

---
### Создание нескольких замыканий

Каждый вызов внешней функции создаёт **собственное** лексическое окружение:

```python
def multiply(n):
    return lambda m: n * m
    
fn1 = multiply(5)
fn2 = multiply(10)

print(fn1(4))   # 20 (5 * 4)
print(fn2(4))   # 40 (10 * 4)
```

Здесь `fn1` и `fn2` — два разных замыкания, каждое со своим значением `n`.
