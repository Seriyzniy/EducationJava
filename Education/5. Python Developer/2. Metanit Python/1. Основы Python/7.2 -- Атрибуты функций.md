**Атрибуты функций** — это механизм, который позволяет прикреплять произвольные данные к объектам функций. В Python функции — это объекты (как и всё остальное), и они могут иметь пользовательские атрибуты, которые хранятся вместе с функцией.

```python
def my_function():
    pass
# Добавляем атрибуты
my_function.author = "Alice"
my_function.version = 1.0

# Читаем атрибуты
print(my_function.author)   # Alice
print(my_function.version)  # 1.0
```

---
### Для чего это нужно?

Атрибуты функций полезны в нескольких сценариях:
1. **Хранение метаданных о функции** — версия, автор, описание, дата создания
    
2. **Кэширование результатов** — запоминание вычисленных значений (мемоизация)
    
3. **Счетчики вызовов** — отслеживание, сколько раз функция была вызвана
    
4. **Настройка поведения** — конфигурация, которая влияет на работу функции
    
5. **Декораторы** — передача данных между декораторами и функциями
    
6. **Регистрация функций** — сбор функций в единый реестр

## Встроенные атрибуты функций

У каждой функции в Python есть специальные (магические) атрибуты:

|Атрибут|Описание|
|---|---|
|`__name__`|Имя функции|
|`__doc__`|Докстринг (строка документации)|
|`__module__`|Имя модуля, в котором определена функция|
|`__defaults__`|Значения по умолчанию для аргументов|
|`__code__`|Объект байт-кода функции|
|`__annotations__`|Аннотации типов|
|`__dict__`|Словарь пользовательских атрибутов|

```python
def example(a: int, b: str = "hello") -> bool:
    """Пример функции с аннотациями"""
    return True
    
print(example.__name__)        # example
print(example.__doc__)         # Пример функции с аннотациями
print(example.__annotations__) # {'a': <class 'int'>, 'b': <class 'str'>, 'return': <class 'bool'>}
print(example.__defaults__)    # ('hello',)
print(example.__dict__)        # {}
```

### Сравнение: атрибуты vs глобальные переменные

**Атрибуты (рекомендуемый способ):**
```python
def process():
    process.counter += 1
    return process.counter
process.counter = 0
```

**Глобальные переменные (не рекомендуется):**
```python
counter = 0
def process():
    global counter
    counter += 1
    return counter
```

Атрибуты лучше, потому что:
- Данные привязаны к функции, а не к глобальной области видимости
    
- Не нужен `global`
    
- Меньше шансов случайно изменить значение из другого места
    
- Легче тестировать и поддерживать

## Пользовательские атрибуты
### Примеры использования

#### 1. Хранение метаданных

```python
def calculate_sum(a, b):
    """Суммирует два числа"""
    return a + b
calculate_sum.author = "John Doe"
calculate_sum.version = "1.2.0"
calculate_sum.created = "2024-01-15"
print(calculate_sum.author)   # John Doe
print(calculate_sum.version)  # 1.2.0
```

#### 2. Счетчик вызовов

```python
def counter():
    counter.calls = getattr(counter, 'calls', 0) + 1
    print(f"Функция вызвана {counter.calls} раз")
    
counter()  # Функция вызвана 1 раз
counter()  # Функция вызвана 2 раз
counter()  # Функция вызвана 3 раз
```
Более удобный вариант — через декоратор:

```python
def count_calls(func):
    def wrapper(*args, **kwargs):
        wrapper.calls += 1
        print(f"Вызов №{wrapper.calls}: {func.__name__}")
        return func(*args, **kwargs)
        
    wrapper.calls = 0
    
    return wrapper
    
@count_calls
def say_hello(name):
    print(f"Hello, {name}!")
    
say_hello("Tom")   # Вызов №1: say_hello
say_hello("Bob")   # Вызов №2: say_hello

print(say_hello.calls)  # 2
```

#### 3. Кэширование результатов (мемоизация)

```python
def expensive_function(n):
    # Проверяем, есть ли уже результат в кэше
    if hasattr(expensive_function, 'cache'):
        if n in expensive_function.cache:
            print(f"Берём из кэша для {n}")
            return expensive_function.cache[n]
    else:
        expensive_function.cache = {}
    
    # Вычисляем (имитация тяжёлой работы)
    print(f"Вычисляем для {n}")
    result = n * n
    
    # Сохраняем в кэш
    expensive_function.cache[n] = result
    return result
    
print(expensive_function(5))  # Вычисляем для 5 -> 25
print(expensive_function(5))  # Берём из кэша для 5 -> 25
print(expensive_function(3))  # Вычисляем для 3 -> 9
```

#### 4. Декоратор с настройками

```python
def retry(max_attempts):
    def decorator(func):
        func.max_attempts = max_attempts
        func.attempts = 0
        
        def wrapper(*args, **kwargs):
            while func.attempts < func.max_attempts:
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    func.attempts += 1
                    print(f"Попытка {func.attempts} не удалась")
            raise Exception("Превышено число попыток")
        return wrapper
    return decorator
    
@retry(max_attempts=3)
def unstable_operation():
    import random
    if random.random() > 0.5:
        raise ValueError("Случайная ошибка")
    return "Успешно!"
# Атрибуты доступны напрямую у декорированной функции
print(unstable_operation.max_attempts)  # 3
```

#### 5. Регистрация и группировка функций

```python
# Создаём реестр команд
commands = {}

def register_command(name):
    def decorator(func):
        func.command_name = name
        commands[name] = func
        return func
    return decorator
    
@register_command("add")
def add(a, b):
    return a + b
    
@register_command("multiply")
def multiply(a, b):
    return a * b
    
@register_command("subtract")
def subtract(a, b):
    return a - b
    
# Используем реестр
print(commands)  
# {'add': <function add at 0x...>, 'multiply': <function multiply at 0x...>, ...}

cmd_name = "add"
if cmd_name in commands:
    result = commands[cmd_name](5, 3)
    print(result)  # 8
    
# Атрибуты тоже доступны
print(add.command_name)       # add
print(multiply.command_name)  # multiply
```

#### 6. Документация и теги

```python
def api_endpoint(path, method="GET"):
    def decorator(func):
        func.endpoint_path = path
        func.http_method = method
        func.is_api = True
        return func
        
    return decorator
    
@api_endpoint("/users", method="GET")
def get_users():
    return ["Alice", "Bob"]
    
@api_endpoint("/users", method="POST")
def create_user():
    return {"status": "created"}
    
# Автоматическая документация
def print_api_docs(func):
    if hasattr(func, 'is_api') and func.is_api:
        print(f"Endpoint: {func.endpoint_path}")
        print(f"Method: {func.http_method}")
        print(f"Function: {func.__name__}")
        print("---")
        
print_api_docs(get_users)
print_api_docs(create_user)
```
