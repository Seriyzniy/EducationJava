Переменные предназначены для хранения данных. Название переменной в Python должно начинаться с алфавитного символа или со знака подчеркивания и может содержать алфавитно-цифровые символы и знак подчеркивания. 

# Ключевые слова
И кроме того, название переменной не должно совпадать с названием ключевых слов языка Python. 

Ключевых слов не так много, их легко запомнить:
## 1. Управляющие конструкции (ветвления и циклы)

**`if`, `elif`, `else`**
- Стандартная условная конструкция. В Python нет `switch/case` (до версии 3.10), поэтому цепочки `if/elif` используются повсеместно.
    
- **Обратите внимание:** в Python нет фигурных скобок, поэтому `elif` и `else` пишутся на том же уровне отступа, что и `if`.
    

**`for`**
- Цикл по итерируемым объектам (спискам, строкам, файлам). В отличие от Java, это **не** цикл со счетчиком (`for (int i=0; i<10; i++)`). В Python он всегда перебирает элементы коллекции.
    
- Пример: `for x in [1, 2, 3]: print(x)`.
    

**`while`**
- Стандартный цикл с предусловием. Выполняется, пока условие истинно.
    

**`break`**
- Немедленно прерывает выполнение текущего цикла (`for` или `while`).
    

**`continue`**
- Немедленно переходит к следующей итерации цикла, пропуская оставшийся код в текущей итерации.
    

**`pass`**
- ==Это "заглушка".== Буквально ничего не делает. Используется там, где синтаксис требует написать код, но вы пока не хотите его писать (например, пустое тело функции или класса).
    
- В Java вы бы поставили пустые фигурные скобки `{}`.
    

---
## 2. Работа с функциями и исключениями

**`def`**
- Ключевое слово для **определения** функции. В Python всё — объект, поэтому `def` создает объект функции и присваивает ему имя.
    

**`return`**
- Возвращает значение из функции. Если не указать `return` явно, функция вернет `None` (аналог `void` в Java, но с конкретным значением-заглушкой).
    

**`lambda`**
- Это способ создать **анонимную функцию** (функцию без имени) в одну строку.
    
- В Java это аналог лямбда-выражений (`(x, y) -> x + y`). В Python пишется: `lambda x, y: x + y`.
    
- Часто используется внутри `map()`, `filter()` или для передачи короткой логики в другую функцию.
    

**`try`, `except`, `finally`**
- Блок для перехвата исключений.
    
- `except` ==перехватывает ошибки== (вместо `catch` из Java).
    
- `finally` выполняется в любом случае (закрытие ресурсов).
    
- В Python также есть `else` для блока `try` (выполняется, если исключений не было).
    

**`raise`**
- ==Генерирует исключение вручную== (аналог `throw` в Java).
    

**`assert`**
- ==Проверяет истинность условия==. Если условие ложно — программа падает с ошибкой `AssertionError`.
    
- Используется для отладки и самопроверок в коде. В Java аналог — ключевое слово `assert`.

## 3. Объектно-ориентированное программирование (ООП)

**`class`**
- Объявление класса. В Python всё внутри класса (включая методы) пишется с отступом.
    

**`def`** (внутри класса)
- Объявляет ==методы экземпляра==. Первый аргумент любого метода (обычно называется `self`) — это ссылка на сам объект (аналог `this` в Java, но передается **явно**).


**`self`** (не является ключевым словом, но это строгое соглашение!)
- ==Ссылка на текущий экземпляр класса==. В отличие от Java, где `this` неявный, **в Python вы обязаны написать `self` в списке аргументов метода.**

**`is`**
- Проверяет, ссылаются ли две переменные на **один и тот же объект** в памяти (==сравнение по ссылке==). В Java это аналог `==` для ссылочных типов.
- Для сравнения значений (как `equals()` в Java) в Python используется `==`.

## 4. Модули и пространства имен

**`import`**
- Импортирует модуль целиком. Например: `import math` или `import os`.
    

**`from ... import ...`**
- Импортирует конкретные имена из модуля. Например: `from math import sqrt`. Это позволяет вызывать `sqrt(4)` вместо `math.sqrt(4)`.
    

**`as`**
- Создает п==севдоним (алиас) для импортируемого модуля== или функции.
    
- Пример: `import numpy as np` (стандарт в научном Python). Или `from os import path as p`.
    

**`global`**
- Объявляет, что внутри функции переменная относится к глобальной области видимости (уровня модуля). 
  Без этого оператора присваивание внутри функции создаст **локальную** переменную.
    

**`nonlocal`**
- Используется внутри вложенных функций. Позволяет *изменять переменные из* **ближайшей объемлющей** (не глобальной, но и не локальной) *области видимости*. 
  В Java аналога нет (там доступны только `final` переменные из замыканий).
    

**`del`**
- Удаляет ссылку на объект или удаляет элемент из коллекции/словаря.
    
- Пример: `del my_list[0]` (удалить первый элемент) или `del x` (удалить саму переменную `x`).

## 5. Логические операторы и типы

**`and`, `or`, `not`**
- Логические операторы. В Python они работают с любыми типами, не только с булевыми (`True`/`False`). Они возвращают не строго `True/False`, а **последний вычисленный объект**.
    
- _Нюанс для Java-разработчика:_ `and` и `or` — это слова, а не `&&` и `||`.
    

**`True`, `False`, `None`**
- Булевы значения и аналог `null` в Java.
    
- `None` — это объект-одиночка, обозначающий "ничего". Проверяют через `is`: `if x is None:` (а не через `==`, хотя это и работает).
    

**`in`**
- Проверяет, ==содержится ли элемент в коллекции ==(списке, строке, словаре).
    
- Также используется в цикле `for` для перебора.


**`not`**
- Логическое отрицание.

## 6. Специфические конструкции Python (самое важное для вас!)

**`with`**
- Менеджер контекста. Гарантирует, что ресурс будет правильно открыт и закрыт, даже если в блоке произошла ошибка.
    
- В Java 7+ это аналог **`try-with-resources`**.
    
- Пример: `with open('file.txt') as f: data = f.read()` — файл закроется автоматически.
    

**`yield`**
- Это **главное отличие от Java**. Если функция содержит `yield`, она превращается в **генератор**.
    
- Вместо `return` (который завершает функцию), `yield` возвращает значение, но **сохраняет состояние** функции. При следующем вызове функция продолжит работу с того же места.
    
- Позволяет экономить память, возвращая данные по одному элементу, а не весь список целиком (как `Stream` в Java, но проще).
    

**`yield from`** (составное)
- Делегирует выполнение другому генератору (появился в Python 3.3). Используется реже.
    

**`lambda`** (мы упоминали ранее)
- Анонимная функция. Синтаксис: `lambda args: expression`.

## 7. Асинхронность 

**`async`** и **`await`**
- Это асинхронное программирование (аналог `CompletableFuture` или `async/await` в JavaScript/C#).
    
- `async def` объявляет асинхронную функцию (корутину).
    
- `await` приостанавливает выполнение, пока ожидается результат другой корутины.
    
- **Пока не трогайте**, это сложная тема. Сначала освойте синхронный Python.

## 8. Мягкие ключевые слова (Python 3.10+)

Как мы обсуждали чуть раньше, это `match`, `case`, `_` и `type`.

- `match`/`case` — структурное сопоставление с образцом (**мощный аналог** `switch` в Java, но на стероидах).
    
- `_` — в этом контексте означает **"всё остальное"** (**wildcard**).
    
- `type` — определение псевдонима типа (например, 
  `type UserId = int`), в обычном коде это остается встроенной функцией `type(obj)`.

# Переменные
## 1. Переменные

**Правила именования:**
- Начинаются с буквы или подчёркивания `_`
    
- Далее могут содержать буквы, цифры и подчёркивания
    
- Регистрозависимы (`name` и `Name` — разные переменные)
    
- Не могут совпадать с ключевыми словами


**Стили именования:**

|Стиль|Пример|
|---|---|
|Camel case|`userName`|
|Underscore notation (рекомендуемый в Python)|`user_name`|

**Присваивание и изменение:**
```python
name = "Tom"        # создание
print(name)         # Tom

name = "Bob"        # изменение
print(name)         # Bob
```

## Строки (`str`)
Тип str представляет строки. Строка представляет последовательность символов, заключенную в одинарные или двойные кавычки, например "hello" и 'hello'. 

В Python 3.x строки представляют набор символов в кодировке Unicode:

### **Способы записи:**
```python
# Одинарные или двойные кавычки
message = "Hello World!"
name = 'Tom'

# Многострочные (тройные кавычки)
text = '''Первая строка
Вторая строка
Третья строка
'''
```
При использовани тройных одинарных кавычек не стоит путать их с комментариями: **если текст в тройных одинарных кавычках присваивается переменной, то это строка**, а не комментарий.

---
### **Разбивка длинной строки:**
```python
text = ("Laudate omnes gentes laudate "
        "Magnificat in secula ")
```

---
### **Управляющие последовательности:**

| Последовательность | Значение          |
| ------------------ | ----------------- |
| `\\`               | Обратный слеш     |
| `\'`               | Одинарная кавычка |
| `\"`               | Двойная кавычка   |
| `\n`               | Новая строка      |
| `\t`               | Табуляция         |

```python
text = "Message:\n\"Hello World\""
# Вывод:
# Message:
# "Hello World"
```

---
### **Сырые строки (префикс `r`):**
```python
# Без r — \n интерпретируется как перенос строки
path = "C:\python\name.txt"   # C:\python
                                # ame.txt
# С r — всё как есть
path = r"C:\python\name.txt"  # C:\python\name.txt
```

---
### **Вставка значений в строку (f-строки):**
Python позволяет встравивать в строку значения других переменных. Для этого внутри строки переменные размещаются в фигурных скобках {}, а перед всей строкой ставится символ f:
```python
userName = "Tom"
userAge = 37
user = f"name: {userName}  age: {userAge}"

print(user)   # name: Tom  age: 37
```

## Динамическая типизация

> [!NOTE] Динамическая типизация
> В Python переменная не привязана к типу жёстко. 
> 
> ==ТИП ОПРЕДЕЛЯЕТСЯ ЗНАЧЕНИЕМ== и может меняться во время выполнения.

```python
userId = "abc"      # тип str
userId = 234        # теперь тип int
```

**Проверка типа:**
С помощью *встроенной функции type()* динамически можно узнать текущий тип переменной:
```python
print(type(userId))   # <class 'str'> или <class 'int'>
```
