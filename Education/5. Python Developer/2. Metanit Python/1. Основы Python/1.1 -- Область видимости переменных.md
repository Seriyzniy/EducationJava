## Область видимости переменных

Область видимости (scope) определяет контекст переменной, в рамках которого ее можно использовать. В Python есть два основных типа контекста: глобальный и локальный.

---
## Глобальный контекст

Глобальный контекст подразумевает, что переменная является глобальной — она определена вне любой из функций и доступна любой функции в программе:

```python
name = "Tom"
def say_hi():
    print("Hello", name)
def say_bye():
    print("Good bye", name)
say_hi()   # Hello Tom
say_bye()  # Good bye Tom
```

Здесь переменная `name` является глобальной и имеет глобальную область видимости. Обе определенные здесь функции могут свободно ее использовать.

---
## Локальный контекст

В отличие от глобальных переменных, локальная переменная определяется внутри функции и доступна только из этой функции, то есть имеет локальную область видимости:

```python
def say_hi():
    name = "Sam"
    surname = "Johnson"
    print("Hello", name, surname)
def say_bye():
    name = "Tom"
    print("Good bye", name)
say_hi()   # Hello Sam Johnson
say_bye()  # Good bye Tom
```

В данном случае в каждой из двух функций определяется локальная переменная `name`. И хотя эти переменные называются одинаково, это две разных переменных, каждая из которых доступна только в рамках своей функции. Также в функции `say_hi()` определена переменная `surname`, которая также является локальной, поэтому в функции `say_bye()` мы ее использовать не сможем.

---
## Скрытие переменных

Есть еще один вариант определения переменной, к**огда локальная переменная скрывает глобальную** ***с тем же именем:***

```python
name = "Tom"

def say_hi():
    name = "Bob"     # скрываем значение глобальной переменной
    print("Hello", name)
    
def say_bye():
    print("Good bye", name)
    
say_hi()   # Hello Bob
say_bye()  # Good bye Tom
```

Здесь определена глобальная переменная `name`. Однако в функции `say_hi` определена локальная переменная с тем же именем `name`. Функция `say_bye` использует глобальную переменную, а функция `say_hi` использует локальную переменную, которая скрывает глобальную.

---
## Ключевое слово `global`

Если мы **хотим изменить в локальной функции глобальную переменную**, а не определить локальную, необходимо использовать ключевое слово `global`:

```python
name = "Tom"

def say_hi():
    global name
    name = "Bob"        # изменяем значение глобальной переменной
    print("Hello", name)
    
def say_bye():
    print("Good bye", name)
    
say_hi()   # Hello Bob
say_bye()  # Good bye Bob
```

> [!WARNING] Важно  
> Без `global` присваивание внутри функции создает **новую локальную** переменную, а не изменяет глобальную.

---
## Ключевое слово `nonlocal`

Выражение `nonlocal` прикрепляет идентификатор к переменной из **ближайшего окружающего контекста** 
(==ЗА ИСКЛЮЧЕНИЕМ ГЛОБАЛЬНОГО КОНТЕКСТА==). 

Обычно `nonlocal` применяется во вложенных функциях, когда надо прикрепить идентификатор к переменной или параметру окружающей внешней функции.

### Проблема без `nonlocal`

```python
def outer():  # внешняя функция
    n = 5
    def inner():    # вложенная функция
        print(n)
        
    inner()     # 5
    print(n)    # 5
    
outer()  # 5 5
```

Здесь вложенная функция `inner()` просто выводит значение переменной `n` из внешней функции.

```python
def outer():  # внешняя функция
    n = 5
    def inner():    # вложенная функция
        n = 25      # создается НОВАЯ локальная переменная
        print(n)
    inner()     # 25
    print(n)    # 5
outer()  # 25 5
```

При присвоении значения во вложенной функции `n = 25` создается новая локальная переменная `n`, которая скрывает переменную `n` из окружающей функции `outer`.

### Решение с `nonlocal`

Чтобы **указать, что идентификатор во вложенной функции представляет переменную из окружающей функции**, применяется выражение `nonlocal`:

```python
def outer():  # внешняя функция
    n = 5
    
    def inner():    # вложенная функция
		# указываем, что n - это переменная из окружающей функции
        nonlocal n  
        n = 25
        print(n)
        
    inner()     # 25
    print(n)    # 25
outer()  # 25 25
```

Теперь изменение `n` внутри `inner()` влияет на переменную `n` из `outer()`.

---
## Сравнение `global` и `nonlocal`

|Ключевое слово|Область действия|Пример использования|
|---|---|---|
|`global`|Изменяет переменную на уровне модуля (глобальную)|`global x; x = 10`|
|`nonlocal`|Изменяет переменную из ближайшей внешней (не глобальной) функции|`nonlocal x; x = 10`|

---
## Правило LEGB (порядок поиска переменных)

Python ищет переменные в следующем порядке:

|Буква|Название|Описание|
|---|---|---|
|**L**|Local|Локальная область видимости (внутри функции)|
|**E**|Enclosing|Объемлющие функции (содержащие эту функцию)|
|**G**|Global|Глобальная область видимости (уровень модуля)|
|**B**|Built-in|Встроенные имена (например, `print`, `len`)|
