### Аннотации функций (Python 3.0+)

Аннотации позволяют добавлять метаданные к параметрам и возвращаемому значению функции. Python не использует их самостоятельно — это информация для сторонних инструментов и разработчиков.

#### Синтаксис

```python
def f(a: 'foo', b) -> 'bar':
    pass
```
- `a: 'foo'` — аннотация параметра `a`
    
- `-> 'bar'` — аннотация возвращаемого значения
    

Аннотации сохраняются в атрибуте `__annotations__` функции:

```python
def f(a: 'foo', b) -> 'bar':
    pass
    
print(f.__annotations__)
# {'a': 'foo', 'return': 'bar'}
```

#### Характеристики

|Аспект|Описание|
|---|---|
|**Синтаксис**|`параметр: выражение` для параметров, `-> выражение` для возврата|
|**Хранение**|В словаре `__annotations__`|
|**Использование**|Только для сторонних инструментов (статический анализ, документация)|
|**Поведение Python**|Игнорирует аннотации, не проверяет типы|

### Подсказки типов (Python 3.5+)
В Python 3.5 введены **соглашения для аннотаций типов** (PEP 484) и модуль `typing`.

#### Модуль `typing`
Предоставляет **стандартные типы для аннотаций**:

```python
from typing import List, Dict, Optional, Union, Tuple

def process_items(items: List[str]) -> Dict[str, int]:
    result = {}
    for item in items:
        result[item] = len(item)
    return result
    
def get_user(id: int) -> Optional[Dict[str, str]]:
    # может вернуть None
    pass
    
def combine(a: Union[int, str], b: Tuple[int, int]) -> str:
    return str(a) + str(b)
```

#### Основные типы из `typing`

|Тип|Описание|Пример|
|---|---|---|
|`List[T]`|Список элементов типа T|`List[str]`|
|`Dict[K, V]`|Словарь с ключами K и значениями V|`Dict[str, int]`|
|`Tuple[T1, T2, ...]`|Кортеж с элементами указанных типов|`Tuple[int, str]`|
|`Optional[T]`|T или None|`Optional[int]`|
|`Union[T1, T2, ...]`|Один из перечисленных типов|`Union[int, str]`|
|`Any`|Любой тип|`Any`|
|`Callable`|Функция|`Callable[[int, int], int]`|

---
### Статус модуля `typing`

|Особенность|Описание|
|---|---|
|**Статус**|Экспериментальный (provisional)|
|**Изменения**|Может быть изменён или удалён в будущих версиях|
|**Использование**|Рекомендуется только в экспериментальных проектах|
|**Совместимость**|Инструменты вроде `mypy` обеспечивают проверку типов|

### Аннотации переменных (Python 3.6+)

PEP 526 ввёл синтаксис для аннотирования переменных (не только параметров функций):

```python
# Аннотация переменной
name: str = "Tom"
age: int = 25
scores: List[int] = [10, 20, 30]

# Аннотация без инициализации
count: int
```
