Декораторы в Python представляют функцию, которая в качестве параметра получает функцию и в качестве результата также возвращает функцию. 


> [!NOTE] Декоратор - обертка над обычной функцией
> ```python
> декоратор(функция1):
> 	функция2:
> 		# что-то
> 		# вызов обычной функции (функция1)
> 		# возможный return внутри функця2
> 	return функция 2
> ```


Декораторы позволяют модифицировать выполняемую функцию, значения ее параметров и ее результат **без изменения исходного кода** этой функции.

---
## Простейший декоратор

Рассмотрим простейший пример:

```python
# определение функции декоратора
def select(input_func):
	# определяем функцию, которая будет выполняться вместо оригинальной
    def output_func():  
	    # перед выводом оригинальной функции выводим звездочки
        print("*****************")  
        input_func()  # вызов оригинальной функции
        # после вывода оригинальной функции выводим звездочки
        print("*****************")  
        
    return output_func # возвращаем новую функцию

# определение оригинальной функции
@select         # применение декоратора select
def hello():
    print("Hello METANIT.COM")
# вызов оригинальной функции
hello()


# ----------- ВЫВОД -----------
# *****************
# Hello METANIT.COM
# *****************

```

**Как это работает:**
1. ==Декоратор== `select()` ==получает функцию== `hello()` как параметр `input_func`
    
2. Внутри декоратора определяется новая функция `output_func()`, которая:
    - Выводит разделитель
        
    - Вызывает оригинальную функцию
        
    - Снова выводит разделитель
        
3. Декоратор возвращает `output_func()`
    
4. Синтаксис `@select` перед определением `hello()` означает: `hello = select(hello)`

### Синтаксический сахар
Декоратор `@` — это синтаксический сахар. Следующие две записи эквивалентны:
```python
# Через синтаксический сахар
@decorator
def func():
    pass

# Без сахара
def func():
    pass
func = decorator(func)
```

## Декоратор с параметрами функции

Декоратор может перехватывать передаваемые в функцию аргументы:

```python
# определение функции декоратора
def check(input_func):
	# через *args получаем значения параметров оригинальной функции
    def output_func(*args):      
        input_func(*args)  # вызов оригинальной функции
        
    return output_func
    
# определение оригинальной функции
@check
def print_person(name, age):
    print(f"Name: {name}  Age: {age}")
    
# вызов оригинальной функции
print_person("Tom", 38)
```

Здесь функция `print_person()` принимает два параметра: `name` и `age`. Декоратор `check()` возвращает локальную функцию `output_func()`, которая принимает набор значений в виде `*args` — это те значения, которые передаются в оригинальную функцию. В данном случае `*args` будет содержать значения параметров `name` и `age`.

## Модификация параметров в декораторе

Декоратор может проверять и при необходимости изменять значения параметров:

```python
# определение функции декоратора
def check(input_func):
    def output_func(*args):
        name = args[0]
        age = args[1] # получаем значение второго параметра
        
        if age < 0:
	    # если возраст отрицательный, изменяем его значение на 1
            age = 1 
            
        input_func(name, age)  # передаем функции значения для параметров
    return output_func
    
# определение оригинальной функции
@check
def print_person(name, age):
    print(f"Name: {name}  Age: {age}")
    
# вызов оригинальной функции
print_person("Tom", 38)
print_person("Bob", -5)

# ----------- ВЫВОД -----------
# Name: Tom  Age: 38
# Name: Bob  Age: 1
```

`args` представляет набор значений, и, используя индексы, мы можем получить значения параметров по позиции и что-то с ними сделать. В данном случае, если возраст меньше 0, устанавливаем значение 1.

## Получение результата функции

Подобным образом можно получить результат функции и при необходимости изменить его:

```python
# определение функции декоратора
def check(input_func):
    def output_func(*args):
	    # передаем функции значения для параметров
        result = input_func(*args)  
        
        if result < 0:
            result = 0 # если результат функции меньше нуля, возвращаем 0
        return result
        
    return output_func
    
# определение оригинальной функции
@check
def sum(a, b):
    return a + b
# вызов оригинальной функции
result1 = sum(10, 20)
print(result1)          # 30
result2 = sum(10, -20)
print(result2)          # 0
```

Здесь определена функция `sum()`, которая возвращает сумму чисел. В декораторе `check` проверяем результат функции и, если он меньше нуля, возвращаем 0.

## Декоратор с аргументами

Иногда декоратору нужно передать свои собственные параметры (например, для настройки поведения). В этом случае создается фабрика декораторов — функция, которая возвращает декоратор:

```python
def repeat(times):  # фабрика декораторов (принимает аргументы)
    
    def decorator(func): # собственно декоратор (принимает функцию)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        
        return wrapper
    
    return decorator
    
@repeat(3)   # примененяем декоратор с аргументом 3
def say_hello(name):
    print(f"Hello, {name}!")
say_hello("Tom")
# Hello, Tom!
# Hello, Tom!
# Hello, Tom!
```

**Структура:**

1. Внешняя функция `repeat(times)` — фабрика, запоминает аргументы
    
2. Средняя функция `decorator(func)` — принимает функцию
    
3. Внутренняя функция `wrapper(*args, **kwargs)` — заменяет оригинальную

## Сохранение метаданных функции

При использовании декоратора теряются метаданные оригинальной функции (`__name__`, `__doc__`). Для их сохранения используется `functools.wraps`:

```python
import functools

def logger(func):
    @functools.wraps(func)   # сохраняет метаданные
    def wrapper(*args, **kwargs):
        print(f"Вызов функции: {func.__name__}")
        return func(*args, **kwargs)
        
    return wrapper

@logger
def add(a, b):
    """Суммирует два числа"""
    return a + b
print(add.__name__)   # add (без wraps было бы wrapper)
print(add.__doc__)    # Суммирует два числа
```

## Несколько декораторов на одну функцию

Можно применить несколько декораторов к одной функции. Они выполняются **снизу вверх** (от ближайшего к функции к дальнему):

```python
def bold(func):
    def wrapper(*args, **kwargs):
        return f"<b>{func(*args, **kwargs)}</b>"
    return wrapper
    
def italic(func):
    def wrapper(*args, **kwargs):
        return f"<i>{func(*args, **kwargs)}</i>"
    return wrapper
    
@bold
@italic
def hello(name):
    return f"Hello, {name}!"
print(hello("Tom"))   # <b><i>Hello, Tom!</i></b>
```

Порядок применения: сначала `italic` (ближайший к функции), затем `bold` (внешний).

## Примеры использования декораторов

### 1. Логирование вызовов

```python
import functools
from datetime import datetime

def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        print(f"[{timestamp}] Вызов {func.__name__} с args={args}, kwargs={kwargs}")
        
        result = func(*args, **kwargs)
        
        print(f"[{timestamp}] Результат: {result}")
        return result
    return wrapper

@log_calls
def calculate(a, b, operation="add"):
    if operation == "add":
        return a + b
    elif operation == "multiply":
        return a * b
    
calculate(5, 3)
calculate(5, 3, operation="multiply")
```

### 2. Измерение времени выполнения

```python
import functools
import time

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        end = time.perf_counter()
        print(f"{func.__name__} заняла {end - start:.6f} секунд")
        return result
    return wrapper
@timer
def slow_function():
    time.sleep(1)
    return "Готово"
slow_function()  # slow_function заняла 1.000123 секунд
```

### 3. Проверка прав доступа

```python
def require_admin(func):
    @functools.wraps(func)
    def wrapper(user, *args, **kwargs):
        if not user.get("is_admin", False):
            raise PermissionError(
	            "Требуются права администратора")
        return func(user, *args, **kwargs)
    return wrapper

@require_admin
def delete_user(user, user_id):
    print(f"Пользователь {user_id} удален")

admin = {"name": "Alice", "is_admin": True}
user = {"name": "Bob", "is_admin": False}
delete_user(admin, 123)   # Пользователь 123 удален
delete_user(user, 456)    # PermissionError: Требуются права администратора
```
