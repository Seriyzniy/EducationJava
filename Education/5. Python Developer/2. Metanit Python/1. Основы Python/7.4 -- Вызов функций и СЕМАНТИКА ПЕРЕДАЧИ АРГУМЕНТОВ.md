### Синтаксис вызова
```python
объект_функции(аргументы)
```

- `объект_функции` — ссылка на вызываемый объект (обычно имя функции)
    
- `()` — оператор вызова
    
- `аргументы` — разделённые запятыми выражения
    

> [!WARNING] Не забывайте скобки!  
> `func` — ссылка на функцию  
> `func()` — вызов функции

---
### Передача аргументов: по ссылке на объект

В Python аргументы передаются **по ссылке на объект** (call by shared reference).

|Особенность|Описание|
|---|---|
|**Что передаётся**|Ссылка на объект, а не переменная|
|**Изменение переменной**|Не влияет на вызывающий код|
|**Изменение объекта**|Влияет на вызывающий код (если объект изменяемый)|

```python
def f(x, y):
    x = 23
    y.append(42)
    
a = 77
b = [99]
f(a, b)

print(a, b)  # 77 [99, 42]
```

**Объяснение:**
- `x = 23` — изменяет локальную переменную, `a` остаётся `77`
    
- `y.append(42)` — изменяет объект списка, `b` теперь `[99, 42]`

### Виды аргументов

#### 1. Позиционные аргументы
Аргументы, передаваемые по порядку следования:

```python
def f(a, b, c=23, d=42, *x):
    print(a, b, c, d, x)
    
f(1, 2, 3, 4, 5, 6)  # (1, 2, 3, 4, (5, 6))
```

#### 2. Именованные аргументы
```python
def divide(divisor, dividend):
    return dividend // divisor
    
print(divide(12, 94))               # 7
print(divide(dividend=94, divisor=12))  # 7
```

Именованные аргументы позволяют менять порядок и делать код понятнее.

---
### Комбинирование позиционных и именованных

```python
def f(middle, begin='init', end='finis'):
    return begin + middle + end
    
print(f('tini', end=' '))   # 'inittini'
# begin использует значение по умолчанию
```

### Специальные формы: `*seq` и `**dct`

#### `*seq` — распаковка итерируемого объекта в позиционные аргументы

```python
def sum_args(*numbers):
    return sum(numbers)
    
d = {'a': 10, 'b': 20, 'c': 30}
print(sum_args(*d.values()))  # 60
```

#### `**dct` — распаковка словаря в именованные аргументы

```python
def greet(name, age):
    print(f"Name: {name}, Age: {age}")
    
data = {'name': 'Tom', 'age': 25}
greet(**data)  # Name: Tom, Age: 25
```

#### Множественное использование `*` и `**` (Python 3.5+, PEP 448)

```python
def func(a, b, c):
    print(a, b, c)
    
args1 = (1, 2)
args2 = {'c': 3}
func(*args1, **args2)  # 1 2 3

# Смешивание
func(0, *args1, **args2)  # 0 1 2 3? Ошибка, неверное количество
```

### Правила вызова

| Правило                      | Описание                            |
| ---------------------------- | ----------------------------------- |
| **Обязательные параметры**   | Должны получить ровно одно значение |
| **Необязательные параметры** | Могут получить 0 или 1 значение     |
| **Позиционные аргументы**    | Сначала, затем именованные          |
| **`*seq`**                   | После позиционных, перед `**dct`    |
| `**dct`                      | Всегда последняя                    |

```python
def f(a, b, c=10, *args, d=20, **kwargs):
    print(a, b, c, args, d, kwargs)
    
f(1, 2, 3, 4, 5, d=30, x=40, y=50)
# 1 2 3 (4, 5) 30 {'x': 40, 'y': 50}
```

### Примеры

#### Передача списка через `*`

```python
def add(a, b, c):
    return a + b + c
    
numbers = [10, 20, 30]
print(add(*numbers))  # 60
```

#### Передача словаря через `**`

```python
def print_person(name, age, city):
    print(f"{name}, {age}, {city}")
    
person = {'name': 'Alice', 'age': 30, 'city': 'Moscow'}
print_person(**person)  # Alice, 30, Moscow
```

### Итог

|Способ|Синтаксис|Пример|
|---|---|---|
|**Позиционные**|`func(a, b, c)`|`add(1, 2, 3)`|
|**Именованные**|`func(a=1, b=2)`|`add(b=2, a=1)`|
|**Распаковка списка**|`func(*list)`|`add(*[1, 2, 3])`|
|**Распаковка словаря**|`func(**dict)`|`add(**{'a':1, 'b':2, 'c':3})`|
|**Комбинация**|`func(a, *list, **dict)`|`add(1, *[2, 3])`|
