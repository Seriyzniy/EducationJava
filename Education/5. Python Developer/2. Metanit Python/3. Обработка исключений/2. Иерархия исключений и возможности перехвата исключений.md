В предыдущей статье мы рассматривали обработку исключений в общем виде. Однако на практике важно уметь обрабатывать **разные типы исключений** по-разному, в зависимости от ситуации.

---
## Встроенные типы исключений

В Python существует иерархия встроенных исключений. Основные базовые типы:

| Тип                   | Описание                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------ |
| **`BaseException`**   | **Базовый тип** для всех встроенных исключений                                                         |
| **`Exception`**       | Базовый тип, от которого обычно наследуют **пользовательские исключения**                              |
| **`ArithmeticError`** | **Базовый** тип для арифметических ошибок (`OverflowError`, `ZeroDivisionError`, `FloatingPointError`) |
| **`LookupError`**     | Базовый тип д**ля ошибок доступа по индексу/ключу** (`IndexError`, `KeyError`)                         |

### Наиболее частые исключения

|Тип|Когда возникает|
|---|---|
|**`ValueError`**|Функция получает аргумент правильного типа, но с некорректным значением|
|**`TypeError`**|Операция применяется к значению недопустимого типа|
|**`IndexError`**|Индекс при обращении к коллекции вне допустимого диапазона|
|**`KeyError`**|В словаре отсутствует ключ|
|**`ZeroDivisionError`**|Деление на ноль|
|**`FileNotFoundError`**|Файл не найден (подтип `OSError`)|
|**`ModuleNotFoundError`**|Модуль не найден при импорте|
|**`OverflowError`**|Результат арифметической операции слишком велик|
|**`RecursionError`**|Превышена допустимая глубина рекурсии|
|**`NotImplementedError`**|Метод класса не реализован|
|**`OSError`**|Ошибка операционной системы (нет доступа к файлу, диск заполнен и т.д.)|

---
## Обработка конкретных типов исключений

Указываем тип после `except`:
```python
try:
    number = int(input("Введите число: "))
    print("Введенное число:", number)
except ValueError:
    print("Ошибка: введено не число")
```

---

## Обработка нескольких типов исключений

### Разные блоки `except` для разных типов

```python
try:
    number1 = int(input("Введите первое число: "))
    number2 = int(input("Введите второе число: "))
    print("Результат деления:", number1 / number2)
    
except ValueError:
    print("Ошибка: введено не число")
except ZeroDivisionError:
    print("Ошибка: деление на ноль")
except BaseException:
    print("Общая ошибка")
```

При возникновении исключения Python ищет подходящий блок `except` сверху вниз.

> [!WARNING] Порядок блоков важен!  
> Если сначала поставить `except BaseException`, то все исключения будут перехватываться им, и более конкретные блоки никогда не сработают.

```python
# ❌ Неправильно — более общий блок перехватит всё
try:
    # код
except Exception:
    print("Общая ошибка")
except ValueError:    # Этот блок никогда не сработает
    print("Ошибка значения")
```

---
### Один блок `except` для нескольких типов

Используем кортеж с типами исключений:

```python
try:
    number1 = int(input("Введите первое число: "))
    number2 = int(input("Введите второе число: "))
    print("Результат деления:", number1 / number2)
    
except (ZeroDivisionError, ValueError):
    print("Ошибка: деление на ноль или некорректный ввод")
```

## Получение информации об исключении - `as`

С помощью ключевого слова `as` можно получить объект исключения и использовать его в блоке `except`:

```python
try:
    number = int(input("Введите число: "))
    print("Введенное число:", number)
except ValueError as e:
    print("Сведения об исключении:", e)
```

**Пример выполнения:**

```text
Введите число: fdsf
Сведения об исключении: invalid literal for int() with base 10: 'fdsf'
```

## Обработка иерархии исключений

Если обрабатывать родительский тип, то все дочерние тоже будут перехвачены:

```python
try:
    numbers = [1, 2, 3]
    print(numbers[10])  # IndexError (наследник LookupError)
except LookupError as e:
    print("Ошибка доступа по индексу/ключу:", e)
```

## Создание собственных исключений

```python
class AgeTooLowError(Exception):
    """Исключение для слишком маленького возраста"""
    pass
    
class AgeTooHighError(Exception):
    """Исключение для слишком большого возраста"""
    pass
    
def set_age(age):
    if age < 0:
        raise ValueError("Возраст не может быть отрицательным")
    if age < 18:
        raise AgeTooLowError("Минимальный возраст — 18 лет")
    if age > 120:
        raise AgeTooHighError("Максимальный возраст — 120 лет")
    print(f"Возраст установлен: {age}")

try:
    set_age(15)
except AgeTooLowError as e:
    print("Слишком молод:", e)
except AgeTooHighError as e:
    print("Слишком стар:", e)
except ValueError as e:
    print("Некорректное значение:", e)
```

## Пример с несколькими исключениями

```python
def process_data(data):
    try:
        # Преобразование
        value = int(data)
        # Работа со словарём
        config = {"factor": 10, "multiplier": 5}
        result = config["factor"] / value
        # Работа со списком
        items = [1, 2, 3]
        print(items[value])  # может быть IndexError
        return result
    except ValueError:
        print("Ошибка: данные не являются числом")
        return None
    except ZeroDivisionError:
        print("Ошибка: деление на ноль")
        return None
    except KeyError:
        print("Ошибка: ключ не найден в словаре")
        return None
    except IndexError:
        print("Ошибка: индекс вне диапазона")
        return None
    except Exception as e:
        print(f"Неизвестная ошибка: {e}")
        return None
print(process_data("5"))    # ValueError (деление на ноль?)
print(process_data("0"))    # ZeroDivisionError
print(process_data("abc"))  # ValueError
```
