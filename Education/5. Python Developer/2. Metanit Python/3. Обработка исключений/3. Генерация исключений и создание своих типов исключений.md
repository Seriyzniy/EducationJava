## Генерация исключений с помощью `raise`

Иногда возникает необходимость вручную сгенерировать то или иное исключение. Для этого применяется оператор `raise`:

```python
try:
    age = int(input("Введите возраст: "))
    if age > 110 or age < 1:
        raise Exception("Некорректный возраст")
    print("Ваш возраст:", age)
except ValueError:
    print("Введены некорректные данные")
except Exception as e:
    print(e)
print("Завершение программы")
```

**Как это работает:**
1. Оператору `raise` передаётся объект исключения (в данном случае `Exception`)
    
2. В конструктор можно передать сообщение, которое затем выводится пользователю
    
3. Если условие выполняется (возраст вне диапазона), генерируется исключение
    
4. Управление переходит к блоку `except`, обрабатывающему `Exception`
    

**Пример выполнения:**
```text
Введите возраст: 100500
Некорректный возраст
Завершение программы
```

---
### `raise` без аргументов

Можно использовать `raise` без аргументов внутри блока `except` — это пробрасывает текущее исключение выше:

```python
try:
    number = int(input("Введите число: "))
    result = 100 / number
except ZeroDivisionError:
    print("Логирование: деление на ноль")
    raise  # пробрасываем исключение дальше
```

## Создание своих типов исключений

В Python можно создавать собственные типы исключений с помощью наследования от `Exception` (или других встроенных типов).

### Базовый синтаксис
```python
class MyCustomError(Exception):
    pass

# Использование
try:
    raise MyCustomError("Что-то пошло не так")
except MyCustomError as e:
    print(e)
```

## Полный пример: класс `Person` с валидацией возраста

### Определение класса исключения

```python
class PersonAgeException(Exception):
    def __init__(self, age, minage, maxage):
        self.age = age
        self.minage = minage
        self.maxage = maxage
        
    def __str__(self):
        return f"Недопустимое значение: {self.age}. " \
               f"Возраст должен быть в диапазоне от 
               {self.minage} до {self.maxage}"
```

В функции `__str__` определяем текстовое представление класса - по сути сообщение об ошибке.
### Определение класса `Person`

```python
class Person:
    def __init__(self, name, age):
        self.__name = name
        minage, maxage = 1, 110
        if minage <= age <= maxage:
            self.__age = age
        else:
            raise PersonAgeException(age, minage, maxage)
    def display_info(self):
        print(f"Имя: {self.__name}  Возраст: {self.__age}")
```

### Использование
```python
try:
    tom = Person("Tom", 37)
    tom.display_info()  # Имя: Tom  Возраст: 37
    bob = Person("Bob", -23)   # генерируется исключение
    bob.display_info()
except PersonAgeException as e:
    print(e)  # Недопустимое значение: -23. Возраст должен быть в диапазоне от 1 до 110
```
