При программировании на Python мы можем столкнуться с двумя типами ошибок:

1. **Синтаксические ошибки (syntax error)** — возникают из-за нарушения синтаксиса языка. IDE обычно подсвечивает их до запуска программы.
    
2. **Ошибки выполнения (runtime error)** — возникают во время выполнения программы. Их ещё называют **исключениями** (exceptions).


Пример исключения:
```python
string = "hello"
number = int(string)  # ValueError: invalid literal for int() with base 10: 'hello'
```

При возникновении исключения работа программы прерывается. Чтобы избежать этого, в Python используется конструкция `try..except`.

---
## Базовый синтаксис `try..except`

```python
try:
    # код, в котором может возникнуть исключение
except [Тип_исключения]:
    # код, который выполняется при возникновении исключения
```

Весь основной код помещается в блок `try`. Если в нём возникает исключение, выполнение переходит в блок `except`.

### Пример
```python
try:
    number = int(input("Введите число: "))
    print("Введенное число:", number)
except:
    print("Преобразование прошло неудачно")
    
print("Завершение программы")
```

**При вводе строки:**
```text
Введите число: hello
Преобразование прошло неудачно
Завершение программы
```

**При вводе числа:**
```text
Введите число: 22
Введенное число: 22
Завершение программы
```

---
## Обработка конкретных типов исключений

Можно указать, какое именно исключение должен перехватывать блок `except`:

```python
try:
    number = int(input("Введите число: "))
    result = 100 / number
    print("Результат:", result)
    
except ValueError:
    print("Ошибка: введено не число")
except ZeroDivisionError:
    print("Ошибка: деление на ноль")
```

Теперь разные типы ошибок обрабатываются по-разному.

---
## Перехват всех исключений

```python
try:
    number = int(input("Введите число: "))
    result = 100 / number
except Exception as e:
    print("Произошла ошибка:", e)
```

Использование `Exception` перехватывает все исключения. Добавление `as e` позволяет получить доступ к объекту исключения и его описанию.

---
## Блок `else`

Блок `else` выполняется только в том случае, если в блоке `try` **не возникло** исключений:

```python
try:
    number = int(input("Введите число: "))
except ValueError:
    print("Ошибка: введено не число")
else:
    print("Введено число:", number)
```

---
## Блок `finally`

Блок `finally` выполняется **всегда**, независимо от того, возникло исключение или нет:

```python
try:
    number = int(input("Введите число: "))
    print("Введенное число:", number)
except:
    print("Преобразование прошло неудачно")
finally:
    print("Блок try завершил выполнение")
print("Завершение программы")
```

### Пример без `except` (аварийное завершение)
```python
try:
    number = 3 / 0    # генерирует ZeroDivisionError
    print(number)
finally:
    print("Блок try завершил выполнение")
print("Завершение программы")
```

Здесь программа аварийно завершится, так как исключение не обработано, но блок `finally` всё равно выполнится.

---
## Вложенные конструкции `try..except`

```python
try:
    try:
        number = int(input("Введите число: "))
        result = 100 / number
    except ZeroDivisionError:
        print("Деление на ноль во внутреннем блоке")
    print("Результат:", result)
except ValueError:
    print("Ошибка во внешнем блоке: введено не число")
```

Внутренний блок обрабатывает деление на ноль, внешний — ошибку преобразования строки в число.

---
## Генерация исключений с помощью `raise`

Исключение можно сгенерировать вручную:
```python
def check_age(age):
    if age < 0:
        raise ValueError("Возраст не может быть отрицательным")
    print("Возраст:", age)
try:
    check_age(-5)
except ValueError as e:
    print("Ошибка:", e)
```

---
## Создание собственных классов исключений

```python
class MyCustomError(Exception):
    pass
def do_something(value):
    if value < 0:
        raise MyCustomError("Значение не может быть отрицательным")
try:
    do_something(-10)
except MyCustomError as e:
    print("Поймано своё исключение:", e)
```

## Пример: работа с файлом

```python
try:
    file = open("data.txt", "r")
    content = file.read()
    print(content)
except FileNotFoundError:
    print("Файл не найден")
except PermissionError:
    print("Нет прав на чтение файла")
except Exception as e:
    print("Неизвестная ошибка:", e)
finally:
    try:
        file.close()
    except NameError:
        pass  # файл не был открыт
```
