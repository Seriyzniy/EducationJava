## 1. Что такое CSV

**CSV** (Comma Separated Values) — формат текстовых файлов, где каждая строка — это отдельная запись, а столбцы разделены запятыми.

Пример:
```text
Tom,28
Alice,23
Bob,34
```

Для работы с CSV в Python есть ==встроенный модуль== `csv`.
```python
import csv
```

---
## 3. Запись в CSV-файл

### Последовательность действий

1. Открыть файл с режимом `"w"` (перезапись) или `"a"` (дозапись)
    
2. Указать `newline=""` для корректной обработки переносов строк
    
3. Создать объект `writer` через `csv.writer()`
    
4. Записать данные методами `writerow()` или `writerows()`
    

### Параметр `newline=""`

При открытии CSV-файла **обязательно** указывайте `newline=""`:

```python
with open(FILENAME, "w", newline="") as file:
    # ...
```
Это гарантирует корректную работу с переносами строк на разных ОС.

---
### Метод `writerows()` — запись нескольких строк

Принимает список списков (двумерный массив):

```python
import csv

FILENAME = "users.csv"
users = [
    ["Tom", 28],
    ["Alice", 23],
    ["Bob", 34]
]
with open(FILENAME, "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(users)
```

**Результат в файле `users.csv`:**
```text
Tom,28
Alice,23
Bob,34
```

---
### Метод `writerow()` — запись одной строки

Принимает одномерный список:
```python
with open(FILENAME, "a", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Sam", 31])
```

## 4. Чтение CSV-файла

### Последовательность действий
1. Открыть файл с режимом `"r"`
    
2. Указать `newline=""`
    
3. Создать объект `reader` через `csv.reader()`
    
4. Перебрать строки в цикле

```python
import csv

FILENAME = "users.csv"

with open(FILENAME, "r", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row[0], "-", row[1])
```

**Вывод:**
```text
Tom - 28
Alice - 23
Bob - 34
Sam - 31
```

## 5. Работа со словарями

Модуль `csv` позволяет работать с записями как со **словарями**, где ключи — это названия столбцов.

---
### Запись словарей: `csv.DictWriter()`

```python
import csv

FILENAME = "users2.csv"
users = [
    {"name": "Tom", "age": 28},
    {"name": "Alice", "age": 23},
    {"name": "Bob", "age": 34}
]

with open(FILENAME, "w", newline="") as file:
    columns = ["name", "age"]
    writer = csv.DictWriter(file, fieldnames=columns)
    # запись заголовков
    writer.writeheader()
    # запись нескольких строк
    writer.writerows(users)
    # запись одной строки
    writer.writerow({"name": "Sam", "age": 41})
```

**Результат в файле `users2.csv`:**

```text
name,age
Tom,28
Alice,23
Bob,34
Sam,41
```

---
### Чтение словарей: `csv.DictReader()`

```python
with open(FILENAME, "r", newline="") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["name"], "-", row["age"])
```

**Вывод:**
```text
Tom - 28
Alice - 23
Bob - 34
Sam - 41
```

Обращение к значениям происходит по имени столбца: `row["name"]`, `row["age"]`.

---
## Итоговая таблица

|Действие|Функция|Методы|
|---|---|---|
|**Запись списков**|`csv.writer(file)`|`writerow()`, `writerows()`|
|**Запись словарей**|`csv.DictWriter(file, fieldnames)`|`writeheader()`, `writerow()`, `writerows()`|
|**Чтение списков**|`csv.reader(file)`|перебор в цикле `for row in reader`|
|**Чтение словарей**|`csv.DictReader(file)`|перебор в цикле `for row in reader`, доступ по ключам|

---
## Полный пример

```python
import csv

FILENAME = "data.csv"

# Запись списков
data = [
    ["Product", "Price", "Quantity"],
    ["Laptop", 1200, 5],
    ["Mouse", 25, 50]
]
with open(FILENAME, "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(data)
    
# Чтение с DictReader (первая строка — заголовки)
with open(FILENAME, "r", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(f"{row['Product']}: {row['Price']} x {row['Quantity']}")
```

**Вывод:**
```text
Laptop: 1200 x 5
Mouse: 25 x 50
```
