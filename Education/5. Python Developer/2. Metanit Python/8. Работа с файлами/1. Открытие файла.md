### 1. Типы файлов

Python поддерживает два основных типа файлов:

|Тип|Описание|Примеры|
|---|---|---|
|**Текстовые**|Хранят информацию в текстовом виде|`.txt`, `.csv`, `.html`, `.json`, `.py`|
|**Бинарные**|Хранят данные в двоичном виде (байты)|Изображения (`.png`, `.jpg`), аудио (`.mp3`), видео (`.mp4`)|

---

### 2. Последовательность работы с файлами

Работа с файлом всегда состоит из трёх шагов:

1. ОТКРЫТИЕ → 2. ЧТЕНИЕ/ЗАПИСЬ → 3. ЗАКРЫТИЕ

---

### 3. Открытие файла: функция `open()`

```python
open(file, mode)
```

|Параметр|Описание|
|---|---|
|`file`|Путь к файлу (абсолютный или относительный)|
|`mode`|Режим открытия (строка)|

---
### 4. Режимы открытия файлов (`mode`)

|Режим|Описание|
|---|---|
|`"r"`|**Чтение** (read). Файл должен существовать, иначе — `FileNotFoundError`|
|`"w"`|**Запись** (write). Если файла нет — создаётся. Если есть — перезаписывается (старые данные удаляются)|
|`"a"`|**Дозапись** (append). Если файла нет — создаётся. Если есть — данные добавляются в конец|
|`"r+"`|**Чтение и запись**. Файл должен существовать|
|`"w+"`|**Чтение и запись**. Если файла нет — создаётся. Если есть — перезаписывается|
|`"a+"`|**Чтение и запись**. Если файла нет — создаётся. Если есть — данные добавляются в конец|
|`"rb"`|**Чтение бинарного файла** (read binary)|
|`"wb"`|**Запись бинарного файла** (write binary)|

---
### 5. Закрытие файла: метод `close()`

После завершения работы файл **обязательно** нужно закрыть, чтобы освободить ресурсы:

```python

myfile = open("hello.txt", "w")
# ... работа с файлом ...
myfile.close()
```

---
### 6. Обработка ошибок при закрытии

Если при работе с файлом возникает исключение, код может не дойти до `close()`. Поэтому файл нужно закрывать в блоке `finally`:

```python
try:
    myfile = open("hello.txt", "w")
    try:
        # работа с файлом
        pass
    finally:
        myfile.close()
        
except Exception as ex:
    print(ex)
```

---
### 7. Конструкция `with` (рекомендуемый способ)

Конструкция `with` ==автоматически закрывает файл после выхода из блока==, даже если произошло исключение:

```python
with open(file, mode) as переменная:
    # инструкции
```

**Пример:**
```python
with open("hello.txt", "w") as myfile:
    print("Работа с файлом")
# файл автоматически закрыт
```
---
### 8. Примеры

#### Открытие текстового файла на запись

```python
myfile = open("hello.txt", "w")
myfile.close()
```

#### Открытие бинарного файла на чтение

```python
myfile = open("image.png", "rb")
myfile.close()
```
#### Безопасное открытие с `with`

```python
with open("hello.txt", "w") as myfile:
    myfile.write("Hello World!")
# файл автоматически закрыт
```

---
### 9. Итоговая таблица

|Шаг|Действие|Код|
|---|---|---|
|1|Открытие|`file = open("path", "mode")`|
|2|Чтение/запись|`file.read()` / `file.write()`|
|3|Закрытие|`file.close()`|

**Лучшая практика:** всегда использовать `with` для автоматического закрытия:

```python
with open("file.txt", "r") as f:
    data = f.read()
```
