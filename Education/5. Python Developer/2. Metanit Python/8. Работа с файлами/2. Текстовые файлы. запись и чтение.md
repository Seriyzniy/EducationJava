# 1. Запись в текстовый файл

### Режимы для записи

|Режим|Описание|
|---|---|
|`"w"`|Перезапись (файл создаётся заново, старые данные удаляются)|
|`"a"`|Дозапись (данные добавляются в конец файла)|
|`"r+"`|Чтение и запись (файл должен существовать)|
|`"w+"`|Чтение и запись (файл перезаписывается)|

---
### Метод `write()`

Записывает **строку** в файл. Числа и другие типы нужно предварительно преобразовывать в строку через `str()`.

```python
with open("hello.txt", "w") as file:
    file.write("hello world")
```

---
### Метод `writelines()`

Записывает **список строк** в файл.

```python
lines = ["Hello Word\n", "Hello Work\n", "Hello World\n"]
with open("hello2.txt", "a") as file:
    file.writelines(lines)
```

> [!NOTE] Важно: каждая строка в списке должна заканчиваться символом `\n`, чтобы в файле строки были разделены переносами.

---
### Запись через `print()`

Можно использовать стандартную функцию `print()` с параметром `file`:

```python
with open("hello.txt", "a") as myfile:
    print("\nhello metanit.com", file=myfile)
```

# 2. Чтение текстового файла

### Режим для чтения

|Режим|Описание|
|---|---|
|`"r"`|Чтение (файл должен существовать)|

---
### Метод `readline()`

Считывает **одну строку** из файла.

```python
with open("hello.txt", "r") as file:
    str1 = file.readline()
    print(str1, end="")
    
    str2 = file.readline()
    print(str2)
```
---

### Цикл `for` (автоматический построчный перебор)

Самый простой способ прочитать файл построчно:

```python
with open("hello.txt", "r") as file:
    for line in file:
        print(line, end="")
```

> `print(line, end="")` убирает лишний перевод строки, т.к. `line` уже содержит `\n`.

---
### Цикл `while` с `readline()`

```python
with open("hello.txt", "r") as file:
    line = file.readline()
    while line:
        print(line, end="")
        line = file.readline()
```

---
### Метод `read()`

Считывает **весь файл целиком** в одну строку (подходит для небольших файлов):

```python
with open("hello.txt", "r") as file:
    content = file.read()
    print(content)
```

---
### Метод `readlines()`

Считывает **все строки файла в список**:

```python
with open("hello.txt", "r") as file:
    contents = file.readlines()
    print(contents[0], end="")
    print(contents[1], end="")
```

---
### Указание кодировки

Если файл не в ASCII, явно указываем кодировку:

```python
with open("hello.txt", encoding="utf8") as file:
    text = file.read()
```

# 3. Чтение и запись одновременно

### Режимы

|Режим|Описание|
|---|---|
|`"r+"`|Чтение и запись. Файл должен существовать|
|`"w+"`|Чтение и запись. Файл создаётся или перезаписывается|

---
### Метод `seek()`

Перемещает указатель в файле на указанную позицию (в байтах):

```python
with open("hello.txt", "w+") as file:
    file.write("Hello world\n")
    file.seek(6)              # перемещаемся к 6-му байту
    
    content = file.read()     # читаем с 6-го байта
    print(content)            # world
```

> [!WARNING] После записи указатель находится в конце файла. Чтобы прочитать записанное, нужно переместить его в начало с помощью `file.seek(0)`.

## 4. Полный пример: запись и чтение с меню

```python
FILENAME = "messages.txt"
def write():
    message = input("Введите строку: ")
    with open(FILENAME, "a") as file:
        file.write(message + "\n")
        
def read():
    with open(FILENAME, "r") as file:
        for message in file:
            print(message, end="")
    print()
    
while True:
    selection = int(input("1.Запись в файл\t\t2.Чтение файла\t\t3.Выход\nВыберите действие: "))
    match selection:
        case 1: write()
        case 2: read()
        case 3: break
        case _: print("Некорректный ввод")
print("Программа завершена")
```

|Метод|Назначение|
|---|---|
|`write(str)`|Запись строки в файл|
|`writelines(list)`|Запись списка строк|
|`print(str, file=f)`|Запись через `print()`|
|`read()`|Чтение всего файла в строку|
|`readline()`|Чтение одной строки|
|`readlines()`|Чтение всех строк в список|
|`seek(pos)`|Перемещение указателя в файле|
