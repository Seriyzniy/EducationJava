## Форматирование строк

В Python есть несколько способов форматирования строк. Рассмотрим их все.

|Способ|Пример|Когда использовать|
|---|---|---|
|**f-строки**|`f"Hello {name}"`|Современный Python, рекомендуется|
|**`.format()`**|`"Hello {}".format(name)`|Если нужно передавать шаблон как строку|
|**`%`**|`"Hello %s" % name`|Старый код, обратная совместимость|

---
## 1. f-строки (Python 3.6+)

Самый современный и рекомендуемый способ. П**еред строкой ставится `f`, внутри `{}` указываются переменные** или выражения.

```python
first_name = "Tom"
text = f"Hello, {first_name}."
print(text)  # Hello, Tom.

name = "Bob"
age = 23
info = f"Name: {name}\t Age: {age}"
print(info)  # Name: Bob  Age: 23
# Выражения внутри {}

a, b = 5, 3
print(f"{a} + {b} = {a + b}")  # 5 + 3 = 8
```

---
## 2. Метод `format()`

### Именованные параметры
```python
text = "Hello, {first_name}.".format(first_name="Tom")
print(text)  # Hello, Tom.

info = "Name: {name}\t Age: {age}".format(name="Bob", age=23)
print(info)  # Name: Bob  Age: 23
```

### Параметры по позиции (индексы)
```python
info = "Name: {0}\t Age: {1}".format("Bob", 23)
print(info)  # Name: Bob  Age: 23

# Повторное использование
text = "Hello, {0} {0} {0}.".format("Tom")
print(text)  # Hello, Tom Tom Tom.
```

### Смешанный вариант
```python
info = "Name: {name}\t Age: {0}".format(23, name="Bob")
print(info)  # Name: Bob  Age: 23
```

---
## 3. Стиль `%` (старый способ)

```python
info = "Имя: %s \t Возраст: %d" % ("Tom", 35)
print(info)  # Имя: Tom     Возраст: 35

number = 23.8589578
print("%0.2f  - %e" % (number, number))  # 23.86  - 2.385896e+01
```

## Спецификаторы форматирования

### Плейсхолдеры

|Плейсхолдер|Тип|Пример|
|---|---|---|
|`s`|Строка|`"{:s}".format("Hello")` → `"Hello"`|
|`d`|Целое число|`"{:d}".format(123)` → `"123"`|
|`f`|Дробное число|`"{:.2f}".format(3.14159)` → `"3.14"`|
|`%`|Проценты|`"{:.0%}".format(0.123)` → `"12%"`|
|`e`|Экспоненциальная запись|`"{:e}".format(12345)` → `"1.234568e+04"`|

---
### Форматирование целых чисел

```python
# Обычное целое
print("{:d}".format(5))        # 5

# С разделителем тысяч
print("{:,d}".format(5000))    # 5,000

# С указанием ширины
print("{:8d}".format(25))      #       25

# С f-строкой
n = 5000
print(f"{n:,d}")               # 5,000
```

---
### Форматирование дробных чисел

```python
number = 23.8589578

# Количество знаков после запятой
print("{:.2f}".format(number))   # 23.86
print("{:.3f}".format(number))   # 23.859
print("{:.4f}".format(number))   # 23.8590

# С разделителем тысяч
print("{:,.2f}".format(10001.23554))  # 10,001.24

# С указанием ширины
print("{:10.2f}".format(23.8589578))  #     23.86

# С f-строкой
print(f"{number:10.2f}")              #     23.86
```

---
### Форматирование процентов

```python
number = 0.12345
print("{:%}".format(number))      # 12.345000%
print("{:.0%}".format(number))    # 12%
print("{:.1%}".format(number))    # 12.3%

# f-строки
print(f"{number:.0%}")            # 12%
print(f"{number:.1%}")            # 12.3%
```

---
### Экспоненциальная запись

```python
number = 12345.6789
print("{:e}".format(number))      # 1.234568e+04
print("{:.0e}".format(number))    # 1e+04
print("{:.1e}".format(number))    # 1.2e+04

# f-строки
print(f"{number:e}")              # 1.234568e+04
print(f"{number:.0e}")            # 1e+04
```

## Выравнивание и длина строки

|Символ|Описание|
|---|---|
|`<N`|Выравнивание по левому краю, дополнение пробелами справа до `N`|
|`>N`|Выравнивание по правому краю, дополнение пробелами слева до `N`|
|`^N`|Выравнивание по центру, дополнение пробелами слева и справа до `N`|
|`.N`|Точная длина `N`; если строка длиннее — усекается|

```python
text = "Hello World"
print(f"{text:>16}!")   #     Hello World!
print(f"{text:<16}!")   # Hello World    !
print(f"{text:^16}!")   #   Hello World  !
print(f"{text:.16}")    # Hello World!    (без изменений)
print(f"{text:.5}")     # Hello           (усечено до 5 символов)
```

### Спецификаторы в `format()`

```python
text = "Hello World"
print("{:>16}".format(text))   #     Hello World
print("{:<16}".format(text))   # Hello World
print("{:^16}".format(text))   #   Hello World
```

## Комбинирование спецификаторов

```python
# Ширина + точность + разделитель тысяч
number = 12345.6789
print(f"{number:15,.2f}")    #      12,345.68

# Заполнение нулями
print(f"{42:05d}")            # 00042
print(f"{3.14:08.2f}")        # 00003.14
```
