## Основные методы строк

---
### Классификация методов

#### Проверка содержимого строки

|Метод|Описание|Пример|
|---|---|---|
|`isalpha()`|Только буквы|`"Hello".isalpha()` → `True`|
|`isdigit()`|Только цифры|`"123".isdigit()` → `True`|
|`isnumeric()`|Число (включая юникодные цифры)|`"123".isnumeric()` → `True`|
|`islower()`|Все символы в нижнем регистре|`"hello".islower()` → `True`|
|`isupper()`|Все символы в верхнем регистре|`"HELLO".isupper()` → `True`|

```python
string = input("Введите число: ")

if string.isnumeric():
    number = int(string)
    print(number)
```

---
#### Проверка начала/конца строки

|Метод|Описание|Пример|
|---|---|---|
|`startswith(str)`|Начинается с подстроки|`"hello.py".startswith("hello")` → `True`|
|`endswith(str)`|Заканчивается подстрокой|`"hello.py".endswith("py")` → `True`|

```python
file_name = "hello.py"
print(file_name.startswith("hello"))  # True
print(file_name.endswith(".py"))      # True
print(file_name.endswith(".exe"))     # False
```

---
#### Преобразование регистра

|Метод|Описание|Пример|
|---|---|---|
|`lower()`|В нижний регистр|`"Hello".lower()` → `"hello"`|
|`upper()`|В верхний регистр|`"Hello".upper()` → `"HELLO"`|
|`title()`|Первая буква каждого слова — заглавная|`"hello world".title()` → `"Hello World"`|
|`capitalize()`|Первая буква первого слова — заглавная|`"hello world".capitalize()` → `"Hello world"`|

```python
text = "hello world"
print(text.upper())       # HELLO WORLD
print(text.title())       # Hello World
print(text.capitalize())  # Hello world
```

---
#### Удаление пробелов

|Метод|Описание|Пример|
|---|---|---|
|`strip()`|Удаляет пробелы в начале и конце|`" hello ".strip()` → `"hello"`|
|`lstrip()`|Удаляет пробелы в начале (слева)|`" hello ".lstrip()` → `"hello "`|
|`rstrip()`|Удаляет пробелы в конце (справа)|`" hello ".rstrip()` → `" hello"`|

```python
text = "   hello  world!  "
text = text.strip()
print(text)  # "hello  world!"
```

---
#### Выравнивание и дополнение

|Метод|Описание|Пример|
|---|---|---|
|`ljust(width)`|Выравнивание по левому краю, дополнение справа|`"text".ljust(10)` → `"text "`|
|`rjust(width)`|Выравнивание по правому краю, дополнение слева|`"text".rjust(10)` → `" text"`|
|`center(width)`|Выравнивание по центру|`"text".center(10)` → `" text "`|

```python
print("iPhone 7:", "52000".rjust(10))
print("Huawei P10:", "36000".rjust(10))
# iPhone 7:      52000
# Huawei P10:    36000

print("Loading".ljust(20, "."), "100%")  # Loading............. 100%
```

### Поиск в строке: `find()`

```python
find(str)               # поиск с начала
find(str, start)        # поиск с индекса start
find(str, start, end)   # поиск в диапазоне [start, end)
```

**Возвращает:** индекс первого вхождения или `-1`, если подстрока не найдена.

```python
welcome = "Hello world! Goodbye world!"
print(welcome.find("wor"))        # 6
print(welcome.find("wor", 10))    # 21
print(welcome.find("wor", 10, 15)) # -1 (не найдено в диапазоне)
```

### Замена: `replace()`

```python
replace(old, new)           # замена всех вхождений
replace(old, new, num)      # замена первых num вхождений

python

phone = "+1-234-567-89-10"
# Замена дефисов на пробелы
print(phone.replace("-", " "))   # +1 234 567 89 10
# Удаление дефисов
print(phone.replace("-", ""))    # +12345678910
# Только первый дефис
print(phone.replace("-", "", 1)) # +1234-567-89-10
```

### Разделение строк: `split()` и `partition()`

#### `split()` — разбивает на список

```python
split()                    # разделитель — пробел
split(delimeter)           # разделитель — delimeter
split(delimeter, num)      # только первые num разделений
```

```python
text = "Это был огромный, в два обхвата дуб"

# По пробелам
print(text.split())
# ['Это', 'был', 'огромный,', 'в', 'два', 'обхвата', 'дуб']

# По запятым
print(text.split(","))
# ['Это был огромный', ' в два обхвата дуб']

# По первым 5 пробелам
print(text.split(" ", 5))
# ['Это', 'был', 'огромный,', 'в', 'два', 'обхвата дуб']
```

#### `partition()` — разбивает на 3 части (кортеж)

```python
text = "Это был огромный, в два обхвата дуб, с обломанными ветвями"

result = text.partition("дуб")
print(result)
# ('Это был огромный, в два обхвата ', 'дуб', ', с обломанными ветвями')
# Если разделитель не найден:
# ('вся строка', '', '')
```

### Соединение строк: `join()`

```python
words = ["Let", "me", "speak", "from", "my", "heart"]

# Разделитель — пробел
sentence = " ".join(words)
print(sentence)  # Let me speak from my heart

# Разделитель — вертикальная черта
sentence = " | ".join(words)
print(sentence)  # Let | me | speak | from | my | heart

# Строка как последовательность символов
word = "hello"
print("|".join(word))  # h|e|l|l|o
```
