## Строки. Работа со строками

Строка представляет последовательность символов в кодировке Unicode, заключённых в кавычки. Python позволяет использовать как одинарные, так и двойные кавычки:

```python
message = "Hello World!"
print(message)  # Hello World!

name = 'Tom'
print(name)  # Tom
```

---
## Многострочные строки

### Разбивка длинной строки на части (круглые скобки)

```python
text = ("Laudate omnes gentes laudate "
        "Magnificat in secula ")
print(text)  # Laudate omnes gentes laudate Magnificat in secula
```

### Многострочный текст (тройные кавычки)

```python
text = '''Laudate omnes gentes laudate
Magnificat in secula
Et anima mea laudate
Magnificat in secula'''

print(text)
```

> [!NOTE] Комментарии vs строки  
> Если текст в тройных кавычках присваивается переменной — это строка. Если никуда не присваивается — это многострочный комментарий (документация).

---
## Управляющие последовательности (escape-последовательности)

|Последовательность|Описание|
|---|---|
|`\\`|Обратный слеш|
|`\'`|Одинарная кавычка|
|`\"`|Двойная кавычка|
|`\n`|Переход на новую строку|
|`\t`|Табуляция|

```python
text = "Message:\n\"Hello World\""
print(text)
# Message:
# "Hello World"
```

### Сырые строки (префикс `r`)

Если в строке есть символы, которые могут интерпретироваться как управляющие последовательности (например, `\n` в пути к файлу), используйте `r`:

```python
# Обычная строка
path = "C:\python\name.txt"
print(path)  # C:\python
              # ame.txt
              
# Сырая строка (обратные слэши не интерпретируются)
path = r"C:\python\name.txt"
print(path)  # C:\python\name.txt
```

## Вставка значений в строку (f-строки)

```python
userName = "Tom"
userAge = 37
user = f"name: {userName}  age: {userAge}"
print(user)  # name: Tom  age: 37
```

> [!NOTE] f-строки (Python 3.6+)  
> Внутри `{}` можно помещать не только переменные, но и выражения:

```python
a, b = 5, 3
print(f"{a} + {b} = {a + b}")  # 5 + 3 = 8
print(f"Квадрат {a} = {a**2}")  # Квадрат 5 = 25
```

## Обращение к символам строки

Индексация начинается с **нуля**. Отрицательные индексы отсчитывают с конца:

```python
string = "hello world"
print(string[0])   # h
print(string[6])   # w
print(string[-1])  # d (последний)
print(string[-5])  # w (пятый с конца)
# print(string[11])  # IndexError: string index out of range
```

> [!WARNING] Строки неизменяемы  
> Нельзя изменить отдельный символ строки:

```python
string = "hello world"

# string[1] = "R"  # TypeError: 'str' object does not support item assignment
string = "hRllo world"  # ✅ только полная перезапись
```

## Перебор строки (цикл `for`)

```python
string = "hello world"
for char in string:
    print(char)  # каждый символ на новой строке
```

---
## Получение подстроки (срезы)

Синтаксис срезов: `string[start:end:step]`

```python
string = "hello world"

# с 0 до 5 (не включая)
print(string[:5])       # hello

# со 2 до 5 (не включая)
print(string[2:5])      # llo

# с 2 по 9 через один символ
print(string[2:9:2])    # lowr
```

### Примеры с отрицательными индексами

```python
string = "hello world"
print(string[-5:])      # world
print(string[:-5])      # hello
print(string[-5:-2])    # wor
```

## Объединение строк (конкатенация)

```python
name = "Tom"
surname = "Smith"
fullname = name + " " + surname
print(fullname)  # Tom Smith
```

### Строка и число

```python
name = "Tom"
age = 33
info = "Name: " + name + " Age: " + str(age)
print(info)  # Name: Tom Age: 33
```

## Повторение строки (умножение)

```python
print("a" * 3)    # aaa
print("he" * 4)   # hehehehe
print("-" * 20)   # --------------------
```

## Сравнение строк

Сравнение производится **лексикографически** (по символам):

|Правило|Пример|
|---|---|
|Цифра < Буква|`"1a" < "aa"` → `True`|
|Заглавная < Строчная|`"Aa" < "aa"` → `True`|
|По алфавиту|`"aa" < "ba"` → `True`|

```python
str1 = "1a"
str2 = "aa"
str3 = "Aa"
print(str1 > str2)  # False (цифра меньше буквы)
print(str2 > str3)  # True (заглавная меньше строчной)
```

### Сравнение без учёта регистра

```python
str1 = "Tom"
str2 = "tom"
print(str1 == str2)  # False

# Приводим к одному регистру
print(str1.lower() == str2.lower())  # True
print(str1.upper() == str2.upper())  # True
```

## Функции `ord()` и `len()`

```python
# ord() — числовое значение символа в Unicode
print(ord("A"))   # 65
print(ord("a"))   # 97
print(ord("€"))   # 8364

# len() — длина строки
string = "hello world"
print(len(string))  # 11
```

---
## Поиск подстроки: `in` и `not in`

```python
text = "hello world"

# Проверка наличия
print("hello" in text)    # True
print("sword" in text)    # False

# Проверка отсутствия
print("hello" not in text)  # False
print("sword" not in text)  # True
```

## Итоговый конспект

|Операция|Синтаксис|Пример|
|---|---|---|
|**Создание**|`"..."` или `'...'`|`s = "Hello"`|
|**Многострочная**|`'''...'''` или `"""..."""`|`s = '''line1\nline2'''`|
|**Сырая строка**|`r"..."`|`r"C:\path"`|
|**f-строка**|`f"...{var}..."`|`f"name: {name}"`|
|**Доступ по индексу**|`s[i]`|`s[0]` → `'H'`|
|**Срез**|`s[start:end:step]`|`s[1:4]` → `'ell'`|
|**Длина**|`len(s)`|`len("Hello")` → `5`|
|**Конкатенация**|`s1 + s2`|`"Hello" + " " + "World"`|
|**Повторение**|`s * n`|`"Ha" * 3` → `"HaHaHa"`|
|**Сравнение**|`==`, `!=`, `<`, `>`|`"a" < "b"` → `True`|
|**Поиск**|`sub in s`|`"ell" in "Hello"` → `True`|
|**Код символа**|`ord(c)`|`ord('A')` → `65`|
|**Регистр**|`lower()`, `upper()`|`s.lower()`|
