`manage()` — это метод интерфейса `WebDriver`, который возвращает объект типа `Options`. 

Этот объект **предоставляет доступ ко всем настройкам и конфигурациям экземпляра WebDriver.**

Через него вы настраиваете:
- Размер и положение окна
- Таймауты ожидания
- Cookies
- Логи
- И другие параметры браузера

# Структура настройки через manage()
```java
driver.manage()
├── window()       // Управление окном браузера
├── timeouts()     // Управление таймаутами
├── addCookie()    // Добавление cookies
├── getCookies()   // Получение всех cookies
├── getCookieNamed() // Получение cookie по имени
├── deleteCookie() // Удаление cookie
├── deleteCookieNamed() // Удаление cookie по имени
├── deleteAllCookies() // Удаление всех cookies
└── logs()         // Управление логированием
```

## Управление окном браузера — `window()`

Метод `window()` возвращает объект `Window`, который позволяет управлять размерами, позицией и состоянием окна браузера.

|Метод|Описание|Пример|
|---|---|---|
|**`maximize()`**|Разворачивает окно на весь экран|`driver.manage().window().maximize()`|
|**`minimize()`**|Сворачивает окно в панель задач|`driver.manage().window().minimize()`|
|**`fullscreen()`**|Переключает в полноэкранный режим (F11)|`driver.manage().window().fullscreen()`|
|**`setSize(Dimension)`**|Устанавливает точный размер окна|`driver.manage().window().setSize(new Dimension(1024, 768))`|
|**`getSize()`**|Возвращает текущий размер окна|`Dimension size = driver.manage().window().getSize()`|
|**`setPosition(Point)`**|Устанавливает позицию окна на экране|`driver.manage().window().setPosition(new Point(0, 0))`|
|**`getPosition()`**|Возвращает текущую позицию окна|`Point pos = driver.manage().window().getPosition()`|

### Практические примеры работы с окном
```java
import org.openqa.selenium.Dimension;
import org.openqa.selenium.Point;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;

public class WindowExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        driver.get("https://google.com");

        // 1. Максимизация окна
        driver.manage().window().maximize();
        System.out.println("Окно максимизировано");

        // 2. Установка конкретного размера
        Dimension customSize = new Dimension(1280, 720);
        driver.manage().window().setSize(customSize);
        System.out.println(
	        "Размер окна: " + 
	        driver.manage().window().getSize());

        // 3. Получение и вывод текущего размера
        Dimension currentSize = 
	        driver.manage().window().getSize();
        System.out.println(
	        "Ширина: " + currentSize.getWidth() + 
            ", Высота: " + currentSize.getHeight()
        );

        // 4. Установка позиции окна
        Point topLeft = new Point(100, 50);
        driver.manage().window().setPosition(topLeft);
        System.out.println(
	        "Позиция: " + 
	        driver.manage().window().getPosition());

        // 5. Полноэкранный режим
        driver.manage().window().fullscreen();
        System.out.println("Включен полноэкранный режим");

        // 6. Сворачивание окна
        Thread.sleep(2000);
        driver.manage().window().minimize();
        System.out.println("Окно свернуто");

        // 7. Возврат к нормальному размеру
        Thread.sleep(2000);
        driver.manage().window().setSize(new Dimension(1024, 768));

        driver.quit();
    }
}
```

## Управление таймаутами — `timeouts()`

Метод `timeouts()` возвращает объект `Timeouts`, который позволяет настроить время ожидания для различных операций.

### Виды таймаутов

|Метод|Описание|Значение по умолчанию|
|---|---|---|
|**`implicitlyWait(Duration)`**|Время ожидания для всех `findElement()`|0 секунд|
|**`pageLoadTimeout(Duration)`**|Максимальное время загрузки страницы|Не ограничено|
|**`scriptTimeout(Duration)`**|Таймаут для асинхронных скриптов|0 секунд|

### Примеры настройки таймаутов

```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import java.time.Duration;
public class TimeoutsExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        // 1. Неявное ожидание (Implicit Wait)
        // WebDriver будет ждать до 10 секунд при каждом поиске элемента
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));
        
        // 2. Таймаут загрузки страницы
        // Если страница не загрузится за 30 секунд - бросит исключение
        driver.manage().timeouts().pageLoadTimeout(Duration.ofSeconds(30));
        
        // 3. Таймаут для асинхронных JavaScript скриптов
        driver.manage().timeouts().scriptTimeout(Duration.ofSeconds(5));
        
        // Теперь можно работать с драйвером
        driver.get("https://google.com");
        
        // Сброс таймаутов к значениям по умолчанию
        // driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(0));
        
        driver.quit();
    }
}
```

### Важные нюансы по таймаутам

#### 1. Implicit Wait — работает глобально
```java
// Установка implicit wait
driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));
// Теперь ВСЕ findElement() будут ждать до 10 секунд
driver.findElement(By.id("element1")); // будет ждать до 10 сек
driver.findElement(By.id("element2")); // будет ждать до 10 сек
driver.findElement(By.id("element3")); // будет ждать до 10 сек
// Сброс implicit wait
driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(0));
```

#### 2. Комбинирование с Explicit Wait
```java
// Implicit wait - глобальный
driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(5));
// Explicit wait - для конкретного элемента
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
WebElement element = wait.until(
    ExpectedConditions.elementToBeClickable(By.id("button"))
);
// ⚠️ ВНИМАНИЕ: общее время ожидания может быть 5 + 10 = 15 секунд!
// При комбинировании будьте осторожны!
```

### Рекомендации по таймаутам

|Тип таймаута|Рекомендуемое значение|Когда использовать|
|---|---|---|
|**Implicit Wait**|5-10 секунд|Для простых страниц с предсказуемой загрузкой|
|**Page Load Timeout**|30-60 секунд|Для тяжелых страниц с большим контентом|
|**Script Timeout**|5-10 секунд|При работе с асинхронными скриптами|

## Управление Cookies

### Основные методы

|Метод|Описание|Возвращает|
|---|---|---|
|**`addCookie(Cookie)`**|Добавляет новый cookie|`void`|
|**`getCookies()`**|Возвращает все cookies|`Set<Cookie>`|
|**`getCookieNamed(String)`**|Возвращает cookie по имени|`Cookie`|
|**`deleteCookie(Cookie)`**|Удаляет указанный cookie|`void`|
|**`deleteCookieNamed(String)`**|Удаляет cookie по имени|`void`|
|**`deleteAllCookies()`**|Удаляет все cookies|`void`|

### Практические примеры с cookies

```java
import org.openqa.selenium.Cookie;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import java.util.Set;

public class CookiesExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        driver.get("https://example.com");
        
        // 1. Создание и добавление cookie
        Cookie userCookie = new Cookie("username", "john_doe");
        driver.manage().addCookie(userCookie);
        
        // Cookie с дополнительными параметрами
        Cookie sessionCookie = 
        new Cookie
	        .Builder("session_id", "abc123")
                .domain(".example.com")
                .path("/")
                .expiresOn
	                (new Date(
		                // 24 часа
		                System.currentTimeMillis() + 86400000)) 
                .isHttpOnly(true)
                .isSecure(false)
                .build();
                
        driver.manage().addCookie(sessionCookie);
        
        
        // 2. Получение всех cookies
        Set<Cookie> cookies = driver.manage().getCookies();
        System.out.println("Все cookies:");
        for (Cookie cookie : cookies) {
            System.out.println(
            "  " + cookie.getName() + "=" + cookie.getValue() +
            " (домен: " + cookie.getDomain() + ")");
        }
        
        
        // 3. Получение конкретного cookie
        Cookie specificCookie = 
	        driver.manage().getCookieNamed("username");
	        
        if (specificCookie != null) {
            System.out.println(
	            "Cookie 'username': " 
	            + specificCookie.getValue());
        }
        
        // 4. Удаление cookie по имени
        driver.manage().deleteCookieNamed("username");
        System.out.println("Cookie 'username' удален");
        
        // 5. Удаление всех cookies
        driver.manage().deleteAllCookies();
        System.out.println("Все cookies удалены");
        driver.quit();
    }
}
```

### Продвинутый пример: работа с авторизацией через cookies
```java
public class CookieAuthExample {
    private WebDriver driver;
    
    @BeforeMethod
    public void setUp() {
        driver = new ChromeDriver();
    }
    
    @Test
    public void testLoginViaCookies() {
        // 1. Авторизуемся обычным способом
        driver.get("https://example.com/login");
        driver.findElement(By.id("username")).sendKeys("testUser");
        driver.findElement(By.id("password")).sendKeys("testPass");
        driver.findElement(By.id("loginBtn")).click();
        
        // 2. Сохраняем cookies после авторизации
        Set<Cookie> authCookies = driver.manage().getCookies();
        System.out.println("Сохранено " + authCookies.size() + " cookies");
        
        // 3. Выходим из системы
        driver.quit();
        
        // 4. Создаем новый экземпляр драйвера
        WebDriver newDriver = new ChromeDriver();
        
        // 5. Открываем страницу и восстанавливаем cookies
        newDriver.get("https://example.com");
        for (Cookie cookie : authCookies) {
            newDriver.manage().addCookie(cookie);
        }
        
        // 6. Обновляем страницу - теперь мы авторизованы!
        newDriver.navigate().refresh();
        
        // 7. Проверяем, что мы авторизованы
        WebElement userMenu = newDriver.findElement(By.id("userMenu"));
        Assert.assertTrue(userMenu.isDisplayed(), "Пользователь не авторизован");
        
        newDriver.quit();
    }
}
```

|**Тестирование корзины**|Добавить cookies с товарами в корзине|

## Управление логами — `logs()`

### Основные методы

|Метод|Описание|Пример|
|---|---|---|
|**`logs().get(String type)`**|Получает логи указанного типа|`driver.manage().logs().get(LogType.BROWSER)`|
|**`logs().getAvailableLogTypes()`**|Возвращает доступные типы логов|`driver.manage().logs().getAvailableLogTypes()`|

### Примеры работы с логами

```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.logging.LogEntries;
import org.openqa.selenium.logging.LogEntry;
import org.openqa.selenium.logging.LogType;

public class LogsExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        driver.get("https://google.com");
        
        // 1. Получение доступных типов логов
        Set<String> logTypes = driver.manage().logs().getAvailableLogTypes();
        System.out.println("Доступные типы логов: " + logTypes);
        // Обычно: [browser, client, driver, server]
        
        // 2. Получение логов браузера
        LogEntries browserLogs = driver.manage().logs().get(LogType.BROWSER);
        System.out.println("Логи браузера (" + browserLogs.getAll().size() + " записей):");
        for (LogEntry entry : browserLogs.getAll()) {
            System.out.println("  [" + entry.getLevel() + "] " + 
                             entry.getMessage());
        }
        
        // 3. Получение логов драйвера
        LogEntries driverLogs = driver.manage().logs().get(LogType.DRIVER);
        for (LogEntry entry : driverLogs.getAll()) {
            System.out.println(entry.getMessage());
        }
        driver.quit();
    }
}
```

### 🎯 Когда использовать логи

|Сценарий|Тип логов|
|---|---|
|**Отладка JavaScript ошибок**|`LogType.BROWSER`|
|**Отладка проблем с драйвером**|`LogType.DRIVER`|
|**Отладка проблем с сервером**|`LogType.SERVER`|
|**Отладка клиентской части**|`LogType.CLIENT`|
