Ожидания (waits) необходимы для обработки асинхронного поведения веб-приложений, гарантируя, что элементы готовы к взаимодействию до того, как тест продолжит выполнение. 

Эта глава посвящена **различным типам ожиданий** в Selenium

- явным (explicit) 
- и гибким (fluent)

*Ожидания критически важны **для избежания "flaky" тестов, которые возникают при попытке взаимодействия с элементами, которые еще не доступны***. Давайте рассмотрим, как эффективно использовать эти ожидания для обеспечения надежных и стабильных автоматизированных тестов. Глава охватывает отличительные особенности каждого типа ожиданий, помогая вам понять, какое ожидание выбрать для конкретных сценариев тестирования.

## Необходимость ожиданий

Вам нужно тестировать веб-приложение и получать точные результаты; следовательно, вы используете ожидания в автоматизации тестирования. Существуют весомые причины для использования ожиданий в тестовых скриптах.

---
### Динамическая загрузка контента

Современные веб-страницы часто требуют времени для загрузки всех динамических элементов с использованием JavaScript или Ajax. В течение этого времени тестовый скрипт пытается взаимодействовать с элементами, которые еще не доступны, что приводит к возникновению исключения. Чтобы избежать таких ситуаций, вы используете ожидания, чтобы убедиться, что страница полностью загружена и соответствующий элемент доступен для взаимодействия с тестовым скриптом.

---
### Сетевая задержка и вариации производительности

Сетевая задержка и время ответа сервера могут вызывать вариации во времени загрузки веб-страницы. Ожидания помогают обрабатывать эти вариации, позволяя тестовому скрипту делать паузу в ожидании доступности веб-элементов или выполнения действий.

---
### Синхронизация

Состояние тестового скрипта и веб-приложения синхронизируются с помощью ожиданий. Эта синхронизация критически важна для устойчивости и надежности тестового скрипта.

---
### Уменьшение нестабильности (Flakiness)

Тестовые скрипты без правильных ожиданий могут быть нестабильными, так как они могут проходить иногда, а иногда падать. Использование ожиданий делает тестовый скрипт более последовательным.

---
### Непредсказуемый ввод пользователя

Иногда, когда пользователь предоставляет неожиданный ввод, возникают ситуации, когда скрипт не может взаимодействовать с веб-элементом до тех пор, пока не будет выполнено определенное условие. Использование ожиданий гарантирует, что указанное условие будет успешно выполнено перед взаимодействием с веб-элементом.

---
# Типы ожиданий

В Selenium **ожидания являются важной функцией для обработки асинхронного поведения веб-приложений**.

Существует в основном три типа ожиданий: 
- неявные (implicit), 
- явные (explicit) 
- и гибкие (fluent). 

Давайте рассмотрим каждый тип более подробно.

---
## Неявные ожидания (Implicit Waits)

> [!NOTE] Ожидание доступности по ТАЙМАУТУ
> При использовании неявных ожиданий вы **задаете период времени, в течение которого WebDriver будет ожидать доступности элемента в DOM** (Document Object Model), чтобы избежать выброса `NoSuchElementException`. 

Это ожидание у*станавливается на весь срок жизни объекта WebDriver.* Время ожидания **ПО УМОЛЧАНИЮ — НОЛЬ СЕКУНД**.

Вы устанавливаете период ожидания в тестовом скрипте, чтобы определенный веб-элемент стал доступен на данной странице. В течение этого периода WebDriver не будет продолжать выполнение дальнейших команд и избежит выброса исключения. WebDriver ожидает в течение указанного времени ожидания. 

Если веб-элемент не доступен или не виден в течение этого периода, выбрасывается `NoSuchElementException`. Когда веб-элемент загружается и находится после установленного времени ожидания, WebDriver выполняет последующие команды в скрипте.

Концепция неявных ожиданий вдохновлена инструментом Watir.

---
### Пример неявного ожидания

```java
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.firefox.FirefoxDriver;
import java.time.Duration;
public class SeleniumFirefoxExample {
    public static void main(String[] args) {
        System.setProperty("webdriver.gecko.driver", "путь/к/geckodriver");
        
        WebDriver driver = new FirefoxDriver();
        
        // Установка неявного ожидания
        driver.manage()
	        .timeouts()
		        .implicitlyWait(Duration.ofSeconds(10));
        
        driver.get("http://example.com");
        
        WebElement elementToTypeIn = 
	        driver.findElement(By.id("elementId"));
        elementToTypeIn.sendKeys("Hello, World!");
        
        driver.quit();
    }
}
```

***В этом примере*** неявного ожидания *вы используете 10-секундный период для поиска веб-элемента по ID*. Период времени определяется тестировщиком в зависимости от сценария и требований тест-кейса. 

**В течение заданного периода WebDriver ожидает, пока элемент будет найден.** Когда элемент найден, введенный текст отправляется, и затем браузер закрывается. Если веб-элемент не найден в течение периода, выбрасывается `NoSuchElementException`.

> **Примечание:** Неявное ожидание используется для веб-элементов, которые не доступны мгновенно.

---
## Явные ожидания (Explicit Waits)

Как вы видели, неявные ожидания заставляют WebDriver ждать в течение определенного времени. Веб-элемент становится доступным на веб-странице после истечения указанного времени. Однако неявные ожидания нельзя использовать для всех веб-элементов, потому что время выполнения тест-кейса становится больше. Это приводит к использованию явных ожиданий, которые являются улучшенной версией неявных ожиданий.


> [!NOTE] Ожидание доступности ПО УСЛОВИЮ в течении определенного ВРЕМЕНИ
> Явные ожидания определяют `ExpectedConditions` вместе с `WebDriverWait`. 
> **WebDriver ожидает выполнения определенного условия в течение установленного периода времени.** 
> 
> Когда условие выполнено или время истекло, тестовый скрипт продолжает выполнение последующих действий, определенных в скрипте.


> **Примечание:** *Частота опроса по умолчанию для явных ожиданий составляет 0,5 секунды* и не может быть изменена.

Основное различие между неявными и явными ожиданиями заключается в том, что явные ожидания продолжают выполнение кода, когда определенное условие выполнено, и не ждут до истечения всего времени. Явные ожидания обеспечивают более точный контроль и предотвращают бесконечное ожидание, гарантируя плавное продолжение тестового скрипта.

---
### Пример явного ожидания

```java
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.firefox.FirefoxDriver;
import org.openqa.selenium.support.ui.ExpectedConditions;
import org.openqa.selenium.support.ui.WebDriverWait;
import java.time.Duration;
public class SeleniumTest {
    public static void main(String[] args) {
        System.setProperty("webdriver.gecko.driver", "путь/к/geckodriver");
        
        WebDriver driver = new FirefoxDriver();
        driver.get("http://example.com");
        
        WebDriverWait wait = new WebDriverWait(
	        driver, 
	        Duration.ofSeconds(10)
	    );
        
        WebElement dynamicElement = wait.until(
            ExpectedConditions.visibilityOfElementLocated(By.id("dynamicElementId"))
        );
        
        dynamicElement.sendKeys("Текст для ввода");
        driver.quit();
    }
}
```

Приведенный выше код определяет условие ожидания, пока указанный веб-элемент не станет видимым на странице. Время ожидания установлено на 10 секунд.

Когда вы не можете предсказать время ожидания веб-элемента, вы используете явные ожидания, что обеспечивает лучший способ обработки асинхронной природы современных веб-приложений. Ожидаемые условия (ExpectedConditions) важны для определения явных ожиданий. Это известные условия, которые обсуждаются в следующей теме.

---
### Часто используемые ExpectedConditions в Java-классе

Для более эффективного взаимодействия с веб-элементами вы можете использовать класс `ExpectedConditions`, доступный в Selenium WebDriver для Java, который содержит коллекцию предопределенных условий. Ниже приведены некоторые из часто используемых ExpectedConditions с их описанием, причиной сбоя и выбрасываемым исключением.

---
### `elementToBeClickable(By locator)`

Ожидает, пока веб-элемент станет видимым и включенным на странице, чтобы можно было выполнить клик.

- **Сбой:** Если веб-элемент не кликабелен (не доступен для взаимодействия).
    
- **Исключение:** `ElementNotInteractableException`
    

```java
WebDriverWait wait = new WebDriverWait(
	driver, 
	Duration.ofSeconds(10)
);
WebElement element = 
	wait.until(
		ExpectedConditions.elementToBeClickable(
			By.id("someId")
		)
	);
element.click();
```

---
### `elementToBeClickable(WebElement element)`

Ожидает, пока конкретный WebElement станет кликабельным (видимым и включенным).

- **Сбой:** Если WebElement не кликабелен в течение заданного времени.
    
- **Исключение:** `ElementNotInteractableException`

```java
WebElement myElement = 
	driver.findElement(By.id("clickableElement"));
	
WebDriverWait wait = new WebDriverWait(
	driver, 
	Duration.ofSeconds(10)
);

WebElement clickableElement = 
	wait.until(
		ExpectedConditions.elementToBeClickable(myElement)
	);
clickableElement.click();
```

---
### `elementToBeSelected(By locator)`

**Ожидает, пока элемент станет выбранным**. *Обычно используется для чекбоксов или радиокнопок.*

- **Сбой:** Если элемент не выбран или не существует.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isSelected = wait.until(ExpectedConditions.elementToBeSelected(By.id("checkboxId")));
```

---
#### `elementToBeSelected(WebElement element)`

Ожидает, пока конкретный WebElement станет выбранным.

- **Сбой:** Если веб-элемент не выбран.
    
- **Исключение:** `StaleElementReferenceException` или `TimeoutException`
    

```java
WebElement checkbox = driver.findElement(By.id("checkboxId"));
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isSelected = wait.until(ExpectedConditions.elementToBeSelected(checkbox));
```

---
### `presenceOfElementLocated(By locator)`

**Ожидает появления веб-элемента в DOM** (не обязательно видимого).

- **Сбой:** Если веб-элемент отсутствует в DOM.
    
- **Исключение:** `NoSuchElementException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
WebElement element = wait.until(ExpectedConditions.presenceOfElementLocated(By.id("someId")));
```

---
### `presenceOfAllElementsLocatedBy(By locator)`

Ожидает, пока все соответствующие веб-элементы, указанные локатором, появятся в DOM.

- **Сбой:** Если не все соответствующие элементы присутствуют.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
List<WebElement> elements = wait.until(
    ExpectedConditions.presenceOfAllElementsLocatedBy(By.className("someClass"))
);
```

---
### `visibilityOfElementLocated(By locator)`

Ожидает, **пока веб-элемент появится в DOM и станет видимым.** 
> *Видимость означает, что элемент не только отображается, **но и имеет высоту и ширину больше 0.***

- **Сбой:** Если элемент присутствует, но не видим.
    
- **Исключение:** `ElementNotVisibleException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
WebElement element = wait.until(ExpectedConditions.visibilityOfElementLocated(By.id("someId")));
```

---
#### `visibilityOf(WebElement element)`

Ожидает, **пока конкретный WebElement станет видимым**.

- **Сбой:** Если WebElement не видим в течение заданного времени.
    
- **Исключение:** `ElementNotVisibleException`
    

```java
WebElement myElement = driver.findElement(By.id("visibleElement"));
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
WebElement visibleElement = wait.until(ExpectedConditions.visibilityOf(myElement));
```

---
### `visibilityOfAllElementsLocatedBy(By locator)`

Ожидает, **пока все веб-элементы, указанные локатором, станут видимыми на странице.**

- **Сбой:** Если какой-либо из элементов не видим.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
List<WebElement> elements = wait.until(
    ExpectedConditions.visibilityOfAllElementsLocatedBy(By.className("someClass"))
);
```

---
### `visibilityOfAllElements(List<WebElement> elements)`

Ожидает, пока все элементы в предоставленном списке станут видимыми.

- **Сбой:** Если не все элементы в списке видимы.
    
- **Исключение:** `TimeoutException`
    

```java
List<WebElement> elements = driver.findElements(By.className("someClass"));
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
List<WebElement> visibleElements = wait.until(
    ExpectedConditions.visibilityOfAllElements(elements)
);
```
---
### `textToBePresentInElementLocated(By locator, String text)`

Ожидает **появления конкретного текста в указанном элементе.**

- **Сбой:** Если текст отсутствует в указанном элементе.
    
- **Исключение:** `TimeoutException`

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isTextPresent = wait.until(
    ExpectedConditions.textToBePresentInElementLocated(
	    By.id("someId"), 
	    "Ожидаемый текст"
	)
);
```
---
### `textToBePresentInElement(WebElement element, String text)`

Ожидает **появления конкретного текста в предоставленном WebElement.**

- **Сбой:** Если указанный текст отсутствует в элементе.
    
- **Исключение:** `TimeoutException`
    

```java
WebElement myElement = driver.findElement(By.id("textElement"));
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isTextPresent = wait.until(
    ExpectedConditions.textToBePresentInElement(myElement, "Ожидаемый текст")
);
```
---
### `textToBePresentInElementValue(By locator, String text)`

Ожидает **появления конкретного текста в атрибуте** `value` элемента, найденного по локатору.

- **Сбой:** Если текст отсутствует в значении элемента.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isTextPresent = wait.until(
    ExpectedConditions.textToBePresentInElementValue(By.id("inputId"), "Ожидаемое значение")
);
```

---
### `titleIs(String title)`

Ожидает, пока заголовок страницы точно совпадет с предоставленной строкой.

- **Сбой:** Если заголовок отличается.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isTitle = wait.until(ExpectedConditions.titleIs("Ожидаемый заголовок"));
```

---
### `titleContains(String title)`

Ожидает, пока заголовок страницы будет содержать определенный текст.

- **Сбой:** Если заголовок не содержит указанный текст.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean doesTitleContain = wait.until(
    ExpectedConditions.titleContains("Часть заголовка")
);
```

---
### `alertIsPresent()`

**Проверяет наличие всплывающего окна (alert) в течение заданного периода времени.** Если оно присутствует, возвращает объект Alert.

- **Сбой:** Если предпринята попытка переключиться на несуществующий alert.
    
- **Исключение:** `NoAlertPresentException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Alert alert = wait.until(ExpectedConditions.alertIsPresent());
alert.accept();
```

---
#### `frameToBeAvailableAndSwitchToIt(String frameLocator)`

Ожидает **доступности фрейма и затем переключается на него**.

- **Сбой:** Если фрейм не найден.
    
- **Исключение:** `NoSuchFrameException`
    

```java
WebDriverWait wait = new WebDriverWait(
	driver, 
	Duration.ofSeconds(10)
);

driver = wait.until(
	ExpectedConditions.frameToBeAvailableAndSwitchToIt(
		"frameName"
	)
);
```

---
### `frameToBeAvailableAndSwitchToIt(By locator)`

Ожидает доступности фрейма и переключается на него. Эта вариация использует локатор для идентификации фрейма.

- **Сбой:** Если фрейм недоступен или не найден.
    
- **Исключение:** `NoSuchFrameException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
driver = wait.until(ExpectedConditions.frameToBeAvailableAndSwitchToIt(By.id("frameId")));
```

---
### `frameToBeAvailableAndSwitchToIt(int frameLocator)`

Ожидает доступности фрейма по указанному индексу и переключается на него.

- **Сбой:** Если фрейм по указанному индексу недоступен.
    
- **Исключение:** `NoSuchFrameException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
driver = wait.until(ExpectedConditions.frameToBeAvailableAndSwitchToIt(0)); // индекс 0 для первого фрейма
```

---
### `invisibilityOfElementLocated(By locator)`

Ожидает, **пока элемент станет невидимым или исчезнет из DOM.**

- **Сбой:** Если элемент видим.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isInvisible = wait.until(
    ExpectedConditions.invisibilityOfElementLocated(By.id("someId"))
);
```

---
### `invisibilityOfElementWithText(By locator, String text)`

Ожидает, пока элемент с указанным текстом станет невидимым или исчезнет из DOM.

- **Сбой:** Если элемент с указанным текстом остается видимым.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean isInvisible = wait.until(
    ExpectedConditions.invisibilityOfElementWithText(By.id("elementWithText"), "Текст для исчезновения")
);
```
---
### `numberOfElementsToBe(By locator, int number)`

Ожидает, **пока определенное количество элементов появится в DOM.**

- **Сбой:** Если количество элементов не соответствует ожидаемому.
    
- **Исключение:** `TimeoutException`
    

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean correctNumber = wait.until(
    ExpectedConditions.numberOfElementsToBe(By.className("someClass"), 5)
);
```

---
### `numberOfElementsToBeMoreThan(By locator, int number)`

Ожидает, пока количество элементов в DOM станет больше указанного числа.

- **Сбой:** Если количество элементов не больше указанного.
    
- **Исключение:** `TimeoutException`

```java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
Boolean moreThanNumber = wait.until(
    ExpectedConditions.numberOfElementsToBeMoreThan(By.className("someClass"), 3)
);
```

---
### `numberOfElementsToBeLessThan(By locator, int number)`

Ожидает, пока количество элементов в DOM станет меньше указанного числа.

- **Сбой:** Если количество элементов не меньше указанного.
    
- **Исключение:** `TimeoutException`

### `refreshed(ExpectedCondition<T> condition)`

==Ожидает выполнения условия после обновления страницы==, часто используется для элементов, которые могут стать устаревшими.

- **Сбой:** Если условие не выполняется после обновления *СТРАНИЦЫ ИЛИ ЭЛЕМЕНТА*.
    
- **Исключение:** `TimeoutException`
    

```java
WebElement myElement = driver.findElement(By.id("dynamicElement"));

// Выполнение действия, вызывающего обновление
WebDriverWait wait = new WebDriverWait(
	driver, 
	Duration.ofSeconds(10)
);

WebElement refreshedElement = wait.until(
    ExpectedConditions.refreshed(
	    ExpectedConditions.visibilityOf(myElement)
	)
);
```
