`switchTo()` — это метод интерфейса `WebDriver`, который возвращает объект типа `TargetLocator`. 

Этот объект **предоставляет доступ к переключению контекста WebDriver между различными элементами страницы.**

Через него вы можете:
- Переключаться между окнами и вкладками браузера
    
- Переключаться между iframe
    
- Переключаться на всплывающие окна (alerts)
    
- Переключаться на активный элемент на странице

---
## Полная структура `switchTo()`

```java
driver.switchTo()
├── window(String windowHandle)     // Переключение на окно по его ID
├── frame(int index)                // Переключение на iframe по индексу
├── frame(String nameOrId)          // Переключение на iframe по имени/ID
├── frame(WebElement frameElement)  // Переключение на iframe как WebElement
├── parentFrame()                   // Переключение на родительский iframe
├── defaultContent()                // Возврат на главную страницу (выход из iframe)
├── alert()                         // Переключение на всплывающее окно (alert)
└── activeElement()                 // Получение элемента в фокусе
```

## Переключение между окнами и вкладками — `window()`

Метод `window()` переключает контекст WebDriver на указанное окно или вкладку браузера.

### Важные понятия

| Термин                 | Описание                                           |
| ---------------------- | -------------------------------------------------- |
| **Window Handle**      | Уникальный **идентификатор окна**/вкладки (String) |
| **getWindowHandle()**  | Возвращает **handle текущего окна**                |
| **getWindowHandles()** | Возвращает **все handle'ы** (`Set<String>`)        |

### Базовый пример

```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import java.util.Set;

public class SwitchToWindowExample {

    public static void main(String[] args) {
    
        WebDriver driver = new ChromeDriver();
        driver.get("https://google.com");
        
        // 1. Получение handle текущего окна
        String mainWindow = driver.getWindowHandle();
        System.out.println("Основное окно: " + mainWindow);
        
        // 2. Открытие новой вкладки (через JavaScript)
        JavascriptExecutor js = (JavascriptExecutor) driver;
        js.executeScript("window.open('https://youtube.com', '_blank')");
        
        // 3. Получение всех handle'ов
        Set<String> allWindows = driver.getWindowHandles();
        System.out.println("Всего окон: " + allWindows.size());
        
        // 4. Переключение на новое окно
        for (String handle : allWindows) {
            if (!handle.equals(mainWindow)) {
                driver.switchTo().window(handle);
                break;
            }
        }
        System.out.println(
	        "Текущий URL: " + driver.getCurrentUrl());
        
        // Ожидаемый результат: https://youtube.com
        // 5. Возврат на основное окно
        driver.switchTo().window(mainWindow);
        System.out.println(
	        "Текущий URL: " + driver.getCurrentUrl());
        // Ожидаемый результат: https://google.com
        driver.quit();
    }
}
```

```java
public class MultiTabExample {
    @Test

                driver.findElement(

            } else if

	                By.name("q")).submit();
            }
            
            tabIndex++;

    }

    }
```

### 💡 Утилитный метод для переключения на новое окно

```java
public class WindowUtils {
    
    // Переключение на новое окно (последнее открытое)
    public static String switchToNewWindow(WebDriver driver) {
        String currentHandle = driver.getWindowHandle();
        Set<String> allHandles = driver.getWindowHandles();
        
        for (String handle : allHandles) {
            if (!handle.equals(currentHandle)) {
                driver.switchTo().window(handle);
                return handle;
            }
        }
        return currentHandle;
    }
    
    // Переключение на окно по части URL
    public static void switchToWindowContainingUrl(WebDriver driver, String urlPart) {
        Set<String> handles = driver.getWindowHandles();
        for (String handle : handles) {
            driver.switchTo().window(handle);
            if (driver.getCurrentUrl().contains(urlPart)) {
                return;
            }
        }
        throw new RuntimeException("Окно с URL содержащим '" + urlPart + "' не найдено");
    }
    
    // Закрытие всех окон, кроме основного
    public static void closeAllWindowsExceptMain(WebDriver driver) {
        String mainHandle = driver.getWindowHandle();
        Set<String> handles = driver.getWindowHandles();
        
        for (String handle : handles) {
            if (!handle.equals(mainHandle)) {
                driver.switchTo().window(handle);
                driver.close();
            }
        }
        driver.switchTo().window(mainHandle);
    }
}


// Использование
@Test
public void testWithUtils() {
    WebDriver driver = new ChromeDriver();
    driver.get("https://example.com");
    
    // Открываем новое окно
    driver.findElement(By.linkText("Open in new window")).click();
    
    // Переключаемся на новое окно
    WindowUtils.switchToNewWindow(driver);
    System.out.println("Новое окно: " + driver.getCurrentUrl());
    
    // Переключаемся на окно по части URL
    WindowUtils.switchToWindowContainingUrl(driver, "google");
    
    // Закрываем все лишние окна
    WindowUtils.closeAllWindowsExceptMain(driver);
    
    driver.quit();
}
```

## Переключение на iframe — `frame()`

Метод `frame()` переключает контекст WebDriver на указанный iframe

> Iframe - документ HTML внутри html. Можно в страницу добавить: видео, гиф, и прочие ресурсы
> [[7. Глава 7. Iframe и текстовые поля]]

### Способы переключения на iframe

|Способ|Описание|Пример|
|---|---|---|
|**По индексу**|Переключение по порядковому номеру (с 0)|`driver.switchTo().frame(0)`|
|**По имени/ID**|Переключение по атрибуту name или id|`driver.switchTo().frame("frameName")`|
|**Как WebElement**|Переключение на найденный элемент|`driver.switchTo().frame(frameElement)`|

### Базовый пример с iframe

```java
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;
public class SwitchToFrameExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        driver.get("https://example.com/with-frame");
        // 1. Переключение по индексу (первый iframe)
        driver.switchTo().frame(0);
        System.out.println("Переключились на первый iframe");
        // 2. Работа с элементами внутри iframe
        WebElement element = driver.findElement(By.id("frameElement"));
        element.click();
        // 3. Возврат на главную страницу
        driver.switchTo().defaultContent();
        System.out.println("Вернулись на главную страницу");
        // 4. Переключение по имени/ID
        driver.switchTo().frame("iframeName");
        System.out.println("Переключились по имени");
        // 5. Переключение как WebElement
        WebElement iframeElement = driver.findElement(By.id("iframeId"));
        driver.switchTo().frame(iframeElement);
        System.out.println("Переключились как WebElement");
        // 6. Выход из iframe
        driver.switchTo().defaultContent();
        driver.quit();
    }
}
```

### Продвинутый пример: работа с вложенными iframe

```java
public class NestedFramesExample {
    @Test
    public void testNestedFrames() {
        WebDriver driver = new ChromeDriver();
        driver.get("https://example.com/nested-frames");
        // HTML структура:
        // <html>
        //   <frame id="topFrame">      (первый уровень)
        //     <frame id="leftFrame">   (второй уровень)
        //     <frame id="rightFrame">  (второй уровень)
        //   </frame>
        // </html>
        
        // 1. Переключение на главный фрейм
        driver.switchTo().frame("topFrame");
        System.out.println("Переключились на topFrame");
        // 2. Переключение на левый фрейм (вложенный)
        driver.switchTo().frame("leftFrame");
        WebElement leftElement = driver.findElement(By.id("leftContent"));
        System.out.println("Левый фрейм: " + leftElement.getText());
        // 3. Возврат на parent фрейм (topFrame)
        driver.switchTo().parentFrame();
        System.out.println("Вернулись на parentFrame (topFrame)");
        // 4. Переключение на правый фрейм
        driver.switchTo().frame("rightFrame");
        WebElement rightElement = driver.findElement(By.id("rightContent"));
        System.out.println("Правый фрейм: " + rightElement.getText());
        // 5. Возврат на главную страницу (выход из всех фреймов)
        driver.switchTo().defaultContent();
        System.out.println("Вернулись на главную страницу");
        driver.quit();
    }
}
```

### Иерархия работы с фреймами

```java
Главная страница (defaultContent)
    │
    ├── switchTo().frame("topFrame")
    │   │
    │   ├── switchTo().frame("leftFrame")   // Вложенный фрейм
    │   │   └── parentFrame() → Возврат на topFrame
    │   │
    │   └── switchTo().frame("rightFrame")  // Вложенный фрейм
    │       └── parentFrame() → Возврат на topFrame
    │
    └── defaultContent() → Возврат на главную страницу
```
### Когда использовать разные методы переключения

|Метод|Когда использовать|Пример|
|---|---|---|
|**По индексу**|Когда iframe не имеют уникальных атрибутов|`frame(0)`, `frame(1)`|
|**По имени/ID**|Когда iframe имеют понятные идентификаторы|`frame("mainFrame")`|
|**Как WebElement**|Когда нужно сначала найти iframe по сложному локатору|`frame(driver.findElement(By.xpath("..."))`|

### ⚠️ Важные нюансы при работе с iframe

```java
public class FrameBestPractices {

    private WebDriver driver;
    private WebDriverWait wait;
    
    @BeforeMethod
    public void setUp() {
        driver = new ChromeDriver();
        wait = new WebDriverWait(driver, Duration.ofSeconds(10));
    }
    
    @Test
    public void testWithFrame() {
        // 1. ВСЕГДА проверяйте наличие iframe перед переключением
        WebElement iframe = wait.until(
            ExpectedConditions.presenceOfElementLocated(
	            By.tagName("iframe"))
        );
        
        // 2. Переключение с явным ожиданием
        wait.until(
	        ExpectedConditions.frameToBeAvailableAndSwitchToIt(
		        By.id("mainFrame")
		    )
		);
        
        // 3. Работа с элементами внутри iframe
        WebElement element = wait.until(
            ExpectedConditions.visibilityOfElementLocated(
	            By.id("insideFrame")
	        )
        );
        element.click();
        
        
        // 4. ВСЕГДА возвращайтесь на главную страницу после работы с iframe
        driver.switchTo().defaultContent();
    }
    
    
    @Test
    public void testFrameExceptionHandling() {
        try {
            // Попытка переключиться на несуществующий iframe
            driver.switchTo().frame("nonExistentFrame");
        } catch (NoSuchFrameException e) {
            System.out.println(
	            "Iframe не найден: " + e.getMessage());
            // graceful recovery
        }
        // Проверка перед переключением
        List<WebElement> frames = 
	        driver.findElements(By.tagName("iframe"));
        if (frames.size() > 0) {
            driver.switchTo().frame(frames.get(0));
        } else {
            System.out.println("Нет iframe на странице");
        }
    }
}
```

## Работа с всплывающими окнами (Alerts) — `alert()`

Метод `alert()` переключает контекст WebDriver на всплывающее окно браузера (JavaScript alert, confirm, prompt).

### Типы алертов

|Тип|Описание|Методы|
|---|---|---|
|**Alert**|Простое окно с сообщением и кнопкой OK|`accept()`|
|**Confirm**|Окно с сообщением и кнопками OK/Отмена|`accept()`, `dismiss()`|
|**Prompt**|Окно с полем ввода и кнопками OK/Отмена|`sendKeys()`, `accept()`, `dismiss()`|

### Методы работы с алертами

```java
import org.openqa.selenium.Alert;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.support.ui.ExpectedConditions;
import org.openqa.selenium.support.ui.WebDriverWait;
import java.time.Duration;

public class AlertExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        driver.get("https://example.com/with-alerts");
        
        // 1. Вызов JavaScript alert
        JavascriptExecutor js = (JavascriptExecutor) driver;
        js.executeScript("alert('Привет, мир!')");
        
        // 2. Переключение на alert
        Alert alert = driver.switchTo().alert();
        
        // 3. Получение текста алерта
        String alertText = alert.getText();
        System.out.println("Текст алерта: " + alertText);
        
        // 4. Нажатие OK (accept)
        alert.accept();
        System.out.println("Alert закрыт (OK)");
        
        // 5. Демонстрация confirm
        js.executeScript("confirm('Подтвердите действие?')");
        Alert confirm = driver.switchTo().alert();
        confirm.dismiss(); // Нажатие "Отмена"
        System.out.println("Confirm закрыт (Отмена)");
        
        // 6. Демонстрация prompt
        js.executeScript("prompt('Введите ваше имя:', 'Гость')");
        Alert prompt = driver.switchTo().alert();
        prompt.sendKeys("Иван Петров"); // Ввод текста
        prompt.accept(); // Подтверждение
        System.out.println("Prompt закрыт с введенным текстом");
        
        // 7. Ожидание появления алерта
        WebDriverWait wait = new WebDriverWait(
	        driver, Duration.ofSeconds(10));
	        
        wait.until(ExpectedConditions.alertIsPresent());
        
        Alert delayedAlert = driver.switchTo().alert();
        delayedAlert.accept();
        driver.quit();
    }
}
```

### Продвинутый пример: обработка алертов

```java
public class AlertHandlingExample {
    private WebDriver driver;
    private WebDriverWait wait;
    
    @BeforeMethod
    public void setUp() {
        driver = new ChromeDriver();
        wait = new WebDriverWait(driver, Duration.ofSeconds(10));
    }
    
    @Test
    public void testAlertHandling() {
        driver.get("https://example.com/with-alerts");
        // 1. Клик по кнопке, вызывающей alert
        driver.findElement(By.id("alertButton")).click();
        // 2. Ожидание появления алерта и переключение
        Alert alert = wait.until(ExpectedConditions.alertIsPresent());
        
        // 3. Проверка текста алерта
        String alertMessage = alert.getText();
        Assert.assertTrue(alertMessage.contains("Успешно"), "Сообщение алерта некорректно");
        
        // 4. Закрытие алерта
        alert.accept();
        // 5. Проверка, что алерт закрыт
        try {
            driver.switchTo().alert();
            Assert.fail("Alert должен быть закрыт");
        } catch (NoAlertPresentException e) {
            System.out.println("Alert корректно закрыт");
        }
    }
    @Test
    public void testMultipleAlerts() {
        // Обработка последовательности алертов
        for (int i = 0; i < 3; i++) {
            driver.findElement(By.id("showAlert")).click();
            
            Alert alert = wait.until(ExpectedConditions.alertIsPresent());
            System.out.println("Alert #" + (i+1) + ": " + alert.getText());
            
            alert.accept();
        }
    }
    
    @Test
    public void testAlertWithInput() {
        driver.findElement(By.id("promptButton")).click();
        
        Alert prompt = wait.until(ExpectedConditions.alertIsPresent());
        
        // Ввод текста
        String inputText = "Тестовый ввод";
        prompt.sendKeys(inputText);
        prompt.accept();
        
        // Проверка, что текст был передан в приложение
        WebElement result = driver.findElement(By.id("promptResult"));
        Assert.assertTrue(result.getText().contains(inputText), 
            "Введенный текст не отображается");
    }
    // Утилитарный метод для безопасной работы с алертами
    private boolean isAlertPresent() {
        try {
            driver.switchTo().alert();
            return true;
        } catch (NoAlertPresentException e) {
            return false;
        }
    }
}
```

```java
public class AlertBestPractices {
    
    // 1. ВСЕГДА проверяйте наличие алерта
    public boolean isAlertPresent(WebDriver driver) {
        try {
            driver.switchTo().alert();
            return true;
        } catch (NoAlertPresentException e) {
            return false;
        }
    }
    
    // 2. Безопасное закрытие алерта
    public void safeAcceptAlert(WebDriver driver) {
        try {
            if (isAlertPresent(driver)) {
                driver.switchTo().alert().accept();
            }
        } catch (Exception e) {
            System.out.println("Ошибка при закрытии алерта: " + e.getMessage());
        }
    }
    
    // 3. Ожидание алерта с таймаутом
    public Alert waitForAlert(WebDriver driver, int seconds) {
        WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(seconds));
        return wait.until(ExpectedConditions.alertIsPresent());
    }
    
    // 4. Очистка после теста
    @AfterMethod
    public void cleanUp() {
        // Закрыть все непредвиденные алерты
        if (isAlertPresent(driver)) {
            try {
                driver.switchTo().alert().dismiss();
            } catch (Exception e) {
                // ignore
            }
        }
    }
}
```

## Переключение на активный элемент — `activeElement()`

Метод `activeElement()` **возвращает элемент**, который в данный момент **находится в фокусе на странице.**

### Пример использования

```java
public class ActiveElementExample {

    }
}
```

## Полная схема `switchTo()`

```java
driver.switchTo()
       │
       ├── window(String handle)     // Переключение на окно/вкладку

       │   └── getWindowHandles()    // Получить все handle'ы

       │   ├── accept()         // Нажать OK
       │   ├── dismiss()        // Нажать Отмена
       │   └── sendKeys(String) // Ввести текст (для prompt)
       │
       └── activeElement()  // Получить элемент в фокусе
```

## Исключения при работе с switchTo()

|Исключение|Когда возникает|Решение|
|---|---|---|
|**`NoSuchWindowException`**|Указанное окно не существует|Проверить handle перед переключением|
|**`NoSuchFrameException`**|Указанный iframe не существует|Проверить наличие iframe перед переключением|
|**`NoAlertPresentException`**|Alert не отображается|Проверить наличие alert перед переключением|
|**`NoSuchContextException`**|Контекст не существует|Используется в мобильном тестировании|

### Обработка исключений

```java
public class SwitchToExceptionHandling {
    
    @Test
    public void handleWindowExceptions() {
        try {
            driver.switchTo().window("nonExistentHandle");
        } catch (NoSuchWindowException e) {
            System.out.println("Окно не найдено: " + e.getMessage());
            // Восстановление - например, вернуться на основное окно
            driver.switchTo().window(driver.getWindowHandle());
        }
    }
    
    @Test
    public void handleFrameExceptions() {
        try {
            driver.switchTo().frame("nonExistentFrame");
        } catch (NoSuchFrameException e) {
            System.out.println("Фрейм не найден: " + e.getMessage());
            // Игнорируем или ищем другой фрейм
            List<WebElement> frames = driver.findElements(By.tagName("iframe"));
            if (!frames.isEmpty()) {
                driver.switchTo().frame(frames.get(0));
            }
        }
    }
    
    @Test
    public void handleAlertExceptions() {
        try {
            driver.switchTo().alert().accept();
        } catch (NoAlertPresentException e) {
            System.out.println("Alert не найден: " + e.getMessage());
            // Продолжаем выполнение без алерта
        }
    }
}
```
