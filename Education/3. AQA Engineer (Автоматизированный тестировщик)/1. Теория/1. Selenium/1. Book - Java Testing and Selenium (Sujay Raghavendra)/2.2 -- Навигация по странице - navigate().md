`navigate()` — это метод интерфейса `WebDriver`, который возвращает объект типа `Navigation`. 

Этот объект **предоставляет доступ К УПРАВЛЕНИЮ ИСТОРИЕЙ БРАУЗЕРА и НАВИГАЦИЕЙ МЕЖДУ СТРАНИЦАМИ.**

Через него вы можете:
- Переходить на новые страницы
    
- Возвращаться назад и вперед по истории
    
- Обновлять текущую страницу

---
## Структура `navigate()`
```java
driver.navigate()
├── to(String url)      // Переход по URL (аналог driver.get())
├── back()              // Возврат на предыдущую страницу (←)
├── forward()           // Переход на следующую страницу (→)
└── refresh()           // Обновление текущей страницы (⟳)
```

---
## Переход по URL — `to(String url)`
Метод `to()` переходит по указанному URL-адресу. 

Он работает аналогично `driver.get()`, но является частью цепочки навигации.
```java
driver.navigate().to("https://example.com");
// или
driver.navigate().to(new URL("https://example.com"));
```

### Отличия `navigate().to()` от `driver.get()`

|Характеристика|`driver.get()`|`driver.navigate().to()`|
|---|---|---|
|**Назначение**|Основной метод для открытия страниц|Часть цепочки навигации|
|**История браузера**|Очищает историю навигации перед переходом|Сохраняет историю|
|**Ожидание загрузки**|Ждет полной загрузки страницы|Ждет полной загрузки страницы|
|**Использование**|Для первого перехода на страницу|Для навигации в рамках теста|

### Пример использования

```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
public class NavigateExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        
        // 1. Первый переход через get()
        driver.get("https://google.com");
        System.out.println("Текущий URL: " + driver.getCurrentUrl());
        
        // 2. Переход через navigate().to()
        driver.navigate().to("https://youtube.com");
        System.out.println("Текущий URL: " + driver.getCurrentUrl());
        
        // 3. Переход через URL объект
        try {
            driver.navigate().to(new URL("https://github.com"));
            System.out.println("Текущий URL: " + driver.getCurrentUrl());
        } catch (MalformedURLException e) {
            e.printStackTrace();
        }
        
        // 4. Относительный переход (с помощью JavaScript)
        // Не работает напрямую через navigate()
        // Нужно использовать executeScript()
        JavascriptExecutor js = (JavascriptExecutor) driver;
        js.executeScript("window.location.href = '/about'");
        
        driver.quit();
    }
}
```

## Навигация назад — `back()`

Метод `back()` имитирует **нажатие кнопки "Назад" в браузере** и возвращает на предыдущую страницу в истории.

### Синтаксис
```java
driver.navigate().back();
```

### Пример использования
```java
public class BackExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        
        // 1. Переход на первую страницу
        driver.get("https://google.com");
        System.out.println("Страница 1: " + driver.getCurrentUrl());
        
        // 2. Переход на вторую страницу
        driver.navigate().to("https://youtube.com");
        System.out.println("Страница 2: " + driver.getCurrentUrl());
        
        // 3. Переход на третью страницу
        driver.navigate().to("https://github.com");
        System.out.println("Страница 3: " + driver.getCurrentUrl());
        
        // 4. Возврат на вторую страницу (YouTube)
        driver.navigate().back();
        System.out.println("После back(): " + driver.getCurrentUrl());
        // Ожидаемый результат: https://youtube.com
        
        // 5. Возврат на первую страницу (Google)
        driver.navigate().back();
        System.out.println("После back(): " + driver.getCurrentUrl());
        // Ожидаемый результат: https://google.com
        
        driver.quit();
    }
}
```

### Когда использовать `back()`

|Сценарий|Описание|
|---|---|
|**Проверка истории**|Тестирование кнопки "Назад" в приложении|
|**Проверка состояния**|Проверка, что при возврате на страницу сохраняется состояние|
|**Тестирование форм**|Проверка, что данные формы не теряются при возврате|

### Продвинутый пример: тестирование кнопки "Назад" в приложении

```java
@Test
public void testBackButtonFunctionality() {
    // 1. Переход на главную страницу
    driver.get("https://example.com");
    
    // 2. Клик по ссылке "О нас"
    driver.findElement(By.linkText("О нас")).click();
    Assert.assertEquals(driver.getCurrentUrl(), "https://example.com/about");
    
    // 3. Проверка, что кнопка "Назад" работает
    driver.navigate().back();
    Assert.assertEquals(driver.getCurrentUrl(), "https://example.com");
    
    // 4. Проверка, что страница сохранила состояние
    WebElement searchField = driver.findElement(By.id("search"));
    Assert.assertTrue(searchField.isDisplayed(), "Поисковое поле должно отображаться");
}
```

## Навигация вперед — `forward()`

Метод `forward()` имитирует нажатие кнопки "Вперед" в браузере и переходит на следующую страницу в истории.

### Синтаксис
```java
driver.navigate().forward();
```

### Пример использования

```java
public class ForwardExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        
        // 1. Переход на первую страницу
        driver.get("https://google.com");
        System.out.println("Шаг 1: " + driver.getCurrentUrl());
        
        // 2. Переход на вторую страницу
        driver.navigate().to("https://youtube.com");
        System.out.println("Шаг 2: " + driver.getCurrentUrl());
        
        // 3. Переход на третью страницу
        driver.navigate().to("https://github.com");
        System.out.println("Шаг 3: " + driver.getCurrentUrl());
        
        // 4. Возврат назад на YouTube
        driver.navigate().back();
        System.out.println("Шаг 4 (back): " + driver.getCurrentUrl());
        // Результат: https://youtube.com
        
        // 5. Возврат назад на Google
        driver.navigate().back();
        System.out.println("Шаг 5 (back): " + driver.getCurrentUrl());
        // Результат: https://google.com
        
        // 6. Переход вперед на YouTube
        driver.navigate().forward();
        System.out.println("Шаг 6 (forward): " + driver.getCurrentUrl());
        // Результат: https://youtube.com
        
        // 7. Переход вперед на GitHub
        driver.navigate().forward();
        System.out.println("Шаг 7 (forward): " + driver.getCurrentUrl());
        // Результат: https://github.com
        
        driver.quit();
    }
}
```

### Когда использовать `forward()`

|Сценарий|Описание|
|---|---|
|**Проверка навигации**|Тестирование полного цикла навигации (вперед-назад)|
|**Тестирование многошаговых форм**|Проверка, что данные сохраняются при переходе вперед|
|**Тестирование кнопки "Вперед"**|Проверка функциональности кнопки "Вперед" в приложении|

### Продвинутый пример: тестирование навигации в корзине интернет-магазина

```java
@Test
public void testCartNavigation() {
    // 1. Переход на страницу товара
    driver.get("https://shop.example.com/product/123");
    
    // 2. Добавление товара в корзину
    driver.findElement(By.id("addToCart")).click();
    Assert.assertTrue(driver.findElement(By.id("cartBadge")).isDisplayed());
    
    // 3. Переход в корзину
    driver.findElement(By.id("cartLink")).click();
    Assert.assertEquals(driver.getCurrentUrl(), "https://shop.example.com/cart");
    
    // 4. Проверка, что товар в корзине
    WebElement cartItem = driver.findElement(By.className("cart-item"));
    Assert.assertTrue(cartItem.isDisplayed());
    
    // 5. Возврат на страницу товара (назад)
    driver.navigate().back();
    Assert.assertEquals(driver.getCurrentUrl(), "https://shop.example.com/product/123");
    
    // 6. Снова переход в корзину (вперед)
    driver.navigate().forward();
    Assert.assertEquals(driver.getCurrentUrl(), "https://shop.example.com/cart");
    
    // 7. Проверка, что товар все еще в корзине
    cartItem = driver.findElement(By.className("cart-item"));
    Assert.assertTrue(cartItem.isDisplayed());
}
```

## Обновление страницы — `refresh()`

Метод `refresh()` имитирует нажатие кнопки "Обновить" в браузере и перезагружает текущую страницу.

### Синтаксис
```java
driver.navigate().refresh();
```

### Пример использования
```java
public class RefreshExample {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();
        driver.get("https://example.com");
        
        // 1. Получение данных до обновления
        String beforeTitle = driver.getTitle();
        String beforeUrl = driver.getCurrentUrl();
        System.out.println("До обновления: " + beforeTitle);
        
        // 2. Обновление страницы
        driver.navigate().refresh();
        System.out.println("Страница обновлена");
        
        // 3. Проверка после обновления
        String afterTitle = driver.getTitle();
        Assert.assertEquals(afterTitle, beforeTitle, "Заголовок должен сохраниться");
        
        // 4. Проверка URL
        String afterUrl = driver.getCurrentUrl();
        Assert.assertEquals(afterUrl, beforeUrl, "URL должен сохраниться");
        
        driver.quit();
    }
}
```

### Когда использовать `refresh()`

|Сценарий|Описание|
|---|---|
|**Обновление данных**|Проверка, что данные обновляются после refresh|
|**Тестирование кэширования**|Проверка, что кэш работает корректно|
|**Сброс состояния**|Сброс состояния страницы к исходному|
|**Проверка уведомлений**|Проверка, что уведомления появляются после обновления|

### Продвинутый пример: проверка обновления данных

```java
@Test
public void testDataRefresh() {
    // 1. Переход на страницу с курсами валют
    driver.get("https://exchange.example.com");
    
    // 2. Получение текущего курса
    WebElement rateElement = driver.findElement(By.id("usdRate"));
    String oldRate = rateElement.getText();
    System.out.println("Курс до обновления: " + oldRate);
    
    // 3. Ожидание обновления данных (имитация)
    try {
        Thread.sleep(5000);
    } catch (InterruptedException e) {
        e.printStackTrace();
    }
    
    // 4. Обновление страницы
    driver.navigate().refresh();
    System.out.println("Страница обновлена");
    
    // 5. Получение нового курса
    WebElement newRateElement = driver.findElement(By.id("usdRate"));
    String newRate = newRateElement.getText();
    System.out.println("Курс после обновления: " + newRate);
    
    // 6. Проверка, что данные обновились (или не обновились)
    // Если курс должен измениться:
    // Assert.assertNotEquals(newRate, oldRate, "Курс должен обновиться");
    
    // Если курс не должен меняться (стабильный):
    Assert.assertEquals(newRate, oldRate, "Курс должен остаться прежним");
}
```
