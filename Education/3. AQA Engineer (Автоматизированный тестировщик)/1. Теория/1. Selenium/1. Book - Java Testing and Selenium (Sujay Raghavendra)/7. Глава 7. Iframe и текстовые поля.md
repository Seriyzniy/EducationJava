В тестировании веб-приложений два элемента постоянно требуют внимания — это **iframe** и **текстовые поля**. Iframe позволяют встраивать содержимое из одного источника в другой, функционируя как отдельное окно внутри веб-страницы. Текстовые поля, в свою очередь, являются важными полями ввода, захватывающими данные пользователя для различных целей.

Эта глава начинается с iframe и исследует техники их поиска и эффективного взаимодействия. После того как вы освоите iframe, внимание переключится на текстовые поля — механизмы точного взаимодействия и извлечения данных. К концу главы у вас будет полное понимание этих двух важнейших веб-элементов и способов работы с ними в задачах автоматизации.

# Iframe

**Iframe** — это **HTML-документ, встроенный в другой HTML-документ на сайте**. 
> Элемент `<iframe>` часто используется для добавления содержимого из разных источников. 

В частности, **iframe используется для встраивания одного документа в другой, изолируя встроенный документ от основной страницы.** Эта изоляция помогает предотвратить вмешательство стороннего контента в DOM или JavaScript-среду главной страницы.

Вы **можете встраивать такие документы, как видео (например, YouTube), PDF-файлы, виджеты сторонних разработчиков и многое другое.** 

Для автоматизации тестирования критически важно знать, что содержимое внутри iframe существует в отдельном документе. Это означает, что веб-элементы внутри iframe хранятся отдельно от элементов главной страницы.

> **Примечание:** Ранее в HTML использовались теги `<frameset>`, похожие на современные iframe, но они разделяли окно браузера на различные секции с разными URL-адресами. Каждое из таких разделенных окон называлось фреймом и отображало разные документы. В отличие от iframe, теги `<frameset>` нельзя размещать в любом месте страницы, и из-за меньшей гибкости их использование сократилось. Однако iframe остались неотъемлемой частью современной веб-разработки.

---
## Пример iframe
```html
<!DOCTYPE html>
<html>
<head>
    <title>Пример Iframe</title>
</head>
<body>
    <p>Это содержимое главной страницы.</p>
    <!-- Встраивание другого документа с помощью iframe -->
    <iframe src="https://www.selenium.dev/" id="iframe0" 
            name="selenium_java" width="500" height="300"></iframe>
    <p>Еще содержимое главной страницы.</p>
</body>
</html>
```

В этом примере сайт `https://www.selenium.dev/` встроен в iframe. Для iframe заданы высота и ширина. Параметр `src` содержит URL сайта, отображаемого внутри iframe.

На странице iframe выглядит как "окно внутри окна". В сценарии тестирования он считается отдельным документом. Перед взаимодействием с содержимым внутри iframe необходимо **переключиться** на это окно.

## Переключение на iframe
Когда вы хотите протестировать веб-элемент или функциональность, встроенные в iframe, сначала *необходимо найти и переключиться на этот конкретный iframe.*

Так как веб-элементы внутри iframe недоступны напрямую, вы должны сначала найти и переключиться на этот iframe. После переключения вы можете находить элементы внутри iframe так же, как описано в главе 4.

---
### Переключение по ID

Используйте атрибут `id` iframe для переключения:
```java
driver.switchTo().frame(driver.findElement(By.id("iframe0")));
```

После переключения на iframe вы ограничены его веб-элементами и можете выполнять операции (поиск элементов, взаимодействие с ними), пока не вернетесь на главную страницу или другой iframe.

---
### Переключение по Name
Аналогично ID, можно переключиться на iframe по атрибуту `name`:
```java
driver.switchTo().frame("selenium_java");
```

---
### Переключение по индексу
Атрибуты ID или Name могут отсутствовать или быть неуникальными. В таких случаях используется индекс iframe.

Индекс представляет позицию iframe на веб-странице, начиная с **0** (ноль). Первый iframe имеет индекс 0, второй — 1 и так далее.

**Пример с несколькими iframe:**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Несколько Iframe</title>
</head>
<body>
    <p>Это содержимое главной страницы.</p>
    <!-- Первый Iframe -->
    <iframe src="iframe1.html"></iframe>
    <!-- Второй Iframe -->
    <iframe src="iframe2.html"></iframe>
    <!-- Третий Iframe -->
    <iframe src="iframe3.html"></iframe>
    <p>Конец содержимого главной страницы.</p>
</body>
</html>
```

**Переключение по индексам:**
```java
// Переключение на первый iframe (индекс 0)
driver.switchTo().frame(0);
// Переключение на второй iframe (индекс 1)
driver.switchTo().frame(1);
// Переключение на третий iframe (индекс 2)
driver.switchTo().frame(2);
```

Если указан несуществующий индекс, возникает ошибка `NoSuchFrameException`.

## Иерархия при переключении iframe

Рассмотрим вложенные iframe (nested iframes). Понимание иерархии необходимо для взаимодействия с элементами, так как каждый уровень требует правильного объявления контекста WebDriver.

**Пример иерархии iframe:**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Главный документ</title>
</head>
<body>
    <p>Это содержимое главной страницы.</p>
    <!-- Iframe первого уровня -->
    <iframe src="first_level.html" id="firstLevelIframe">
        <p>Это содержимое iframe первого уровня.</p>
        <!-- Вложенный iframe (второй уровень) -->
        <iframe src="second_level.html" id="secondLevelIframe">
            <p>Это содержимое вложенного iframe второго уровня.</p>
        </iframe>
    </iframe>
    <p>Еще содержимое главной страницы.</p>
</body>
</html>
```

**Иерархия:**
- **Главная страница** — верхний уровень.
    
- **Iframe с `id="firstLevelIframe"`** — первый уровень (встроен в главный документ).
    
- **Вложенный iframe с `id="secondLevelIframe"`** — второй уровень (встроен в iframe первого уровня).
    

---
### Навигация по иерархии iframe

**Контекст главной страницы:**  
При загрузке веб-страницы главный документ устанавливается как контекст WebDriver по умолчанию. Переключаться на него не нужно.

**Доступ к iframe первого уровня:**
```java
driver.switchTo().frame(driver.findElement(By.id("firstLevelIframe")));
```

**Доступ к iframe второго уровня (вложенному):**
```java
driver.switchTo().frame(driver.findElement(By.id("secondLevelIframe")));
```
WebDriver не может напрямую обратиться к вложенному iframe — требуется последовательная навигация по уровням.

**Возврат на первый уровень (родительский iframe):**
```java
driver.switchTo().parentFrame();
```

**Возврат на главную страницу (с любого уровня):**
```java
driver.switchTo().defaultContent();
```

---
### Переключение как на элемент

При работе с динамическими страницами, где iframe не имеют фиксированных атрибутов или их позиция может меняться, их можно найти как обычные веб-элементы.

```html
<iframe class="dynamicIframe" src="iframe_content.html"></iframe>
```

**Поиск и переключение:**
```java
// Находим iframe как WebElement по классу
WebElement iframeElement = driver.findElement(By.className("dynamicIframe"));
// Переключаемся на iframe
driver.switchTo().frame(iframeElement);
```

Этот метод дает больше гибкости и точности, особенно в современных веб-приложениях, где iframe могут динамически создаваться, удаляться или менять атрибуты через JavaScript.

## Iframe с ожиданиями (Waits)

Для надежных тестов необходимо дожидаться загрузки iframe перед переключением.

```html
<iframe id="dynamicLoadingFrame" src="some_content.html"></iframe>
```

**Использование явного ожидания (Explicit Wait):**
```java
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.support.ui.ExpectedConditions;
import org.openqa.selenium.support.ui.WebDriverWait;
// Явное ожидание с таймаутом 10 секунд
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
// Ожидание доступности iframe и автоматическое переключение
wait.until(ExpectedConditions.frameToBeAvailableAndSwitchToIt(
    By.id("dynamicLoadingFrame")));
// Теперь вы внутри iframe — можно выполнять операции
// ...
// Возврат на главную страницу
driver.switchTo().defaultContent();
```

Если iframe не становится доступным в течение 10 секунд, возникает ошибка `TimeoutException`.

# Текстовые поля (Textboxes)
Текстовые поля — важные элементы веб-форм, обеспечивающие ввод данных: от простых поисковых запросов до сложных записей.

---
## Однострочное текстовое поле (Single Line Textbox)

Поле ввода с типом `text`, используемое для коротких записей: имя пользователя, поисковый запрос, email-адрес.

**HTML-пример:**
```html
<h1>Однострочное текстовое поле</h1>
<label for="book">Название книги:</label>
<input type="text" id="book_name" name="book_query">
```

**Поиск элемента:**
```java
WebElement bookTextbox = driver.findElement(By.id("book_name"));
```

**Ввод значения:**
```java
bookTextbox.sendKeys("Python Testing with Selenium");
```

**Получение введенного значения:**
```java
String bookName = bookTextbox.getAttribute("value");
System.out.println("Введенное название книги: " + bookName);
```

---
## Многострочное текстовое поле (Multiline Textbox)

Используется для ввода многострочного текста: комментарии, описания, отзывы. Создается с помощью тега `<textarea>`.

**HTML-пример:**
```html
<h1>Многострочное текстовое поле</h1>
<label for="description">Описание:</label>
<textarea id="description" name="description" rows="4" cols="50"></textarea>
```

**Поиск элемента:**
```java
WebElement descriptionTextarea = driver.findElement(By.id("description"));
```

**Ввод значения (с переносом строки):**
```java
descriptionTextarea.sendKeys("Это пример описания.\nОно занимает несколько строк.");
```
`\n` — это escape-последовательность в Java, имитирующая нажатие Enter.

**Получение введенного значения:**
```java
String descriptionText = descriptionTextarea.getText();
System.out.println("Введенное описание: " + descriptionText);
```

# 📌 Резюме главы

|Тема|Ключевые моменты|
|---|---|
|**Iframe**|Отдельный документ внутри страницы. Требует переключения контекста.|
|**Способы переключения**|По ID, по Name, по индексу, как WebElement.|
