Фреймворк - программная среда предоставляющая структуру и инструменты для разработки приложений и ПО

## Что необходимо учесть в написании фреймворка для автоматизации?
- Единственная глобальная точка доступа к экземпляру Web Driver (вспоминаем паттерн Singleton) (**НИГДЕ НЕ ХРАНИМ В ПОЛЯХ ДРАЙВЕР, всегда через getInstace()**)
- Реализация классов для работы со страницами (паттерн Page Object)
- Реализация классов для работы с элементами страницы
- Реализация утилитных классов и методов
- Реализация работы с тестовыми данным/конфиг-файлами (чтение, парсинг)
- Базовые классы для страниц/элементов/тестов (подробнее на следующем слайде)
- Грамотная композиция всех классов/директорий
- Реализация логирования шагов (**ЛОГИРОВАНИЕ ДО ВЫПОЛНЕНИЕ ШАГА**)

## Частые ошибки
- Методы страниц не должны возвращать веб-элементы
- В тесте недопустима работа напрямую с элементами
- Конструктор класса страницы не должен иметь входных параметров (ничего не передаем)
